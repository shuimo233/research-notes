# 两两都可能，为什么已经能行动？

2026-11-21 · 推理框架 0.2.0 · 计算研究笔记

四台副本的编号是 00、01、10、11，已知恰好一台停机。诊断接口每次只能读停机编号的一位，两次读数中至多错一次。假设先后读到 0 和 1：停机副本可能是 00、01 或 11，却不可能是 10，因为把 10 读成 01 要错两次。**现在就能把任务交给 10。**

有意思的是，在这两次查询开始之前，任意两个停机假设都有可能产生同一份记录。用“至少分开一对候选”作保证，要问 3 次；固定安排查询、坚持找出停机的是哪一台，要问 6 次。真正需要的行动只用 2 次，一次不够。这个四点几何反例有明确先例。它促使我们把框架的计划核验从“两两比较”改成“检查一组解释能否同时成立”。[安装和调用](../../packages/stateful-identification/README.md) · [实际实现](../../packages/stateful-identification/stateful_id/action.py)

## 框架现在证明什么

每个候选规则 $i$ 给出每项二元实验的预测、允许错读的剩余次数 $r_i$，以及在它之下正确的动作集合 $A_i$。每次实验从同一初态开始。假设真实规则在候选表里。给定一份固定实验清单，把规则 $i$ 的无错回答依次写成比特串 $c_i$。该规则能解释的全部实测记录，恰是以 $c_i$ 为中心、半径 $r_i$ 的汉明球。

先找出所有按包含关系极小的候选组 $F$，使组内动作没有交集。**清单能保证选对行动，当且仅当每一个这样的组都不可能共同解释一份记录**，即相应球的交集为空。理由很直接：若一组仍可同时成立，而它们没有共同动作，这条记录就不能安全交付；若某条记录不能安全交付，它的存活候选中必然包含一个这样的极小组。这个判据允许各候选有完全不同的错读额度，也允许所有候选之间没有公共回退动作。它沿用了已有的决策区域思想。[Javdani 等，AISTATS 2014](https://proceedings.mlr.press/v33/javdani14.pdf)

困难在于，重复 $N$ 次二元实验有 $2^N$ 份原始记录，列举全部记录很快就行不通。我们关心两个量：能用多少条候选证明某一组不可能同时成立，以及核验是否一定要展开全部重复次数。

## 按实验结构给出证据大小

固定一个候选组。把实验视为列，候选视为行；在这个组里，两列若出现 00、01、10、11 全部四种组合，就称它们**交叉**。忽略常量列，把等同或互补的列合并并保留重复次数。将剩余列分成 $d$ 组，每组内部没有交叉；这相当于给交叉图作一次正常着色。能给出一种着色即可使用下列上界。

**命题。** 对有限二元预测表、任意正整数列重复次数和逐行非负整数错读余量，如果一组候选无法共同解释记录，那么其中至多 $2^d$ 条就足以证明这件事。对允许 $d$ 组的整个实例类，这个界可以取到。它限定的是“无法同时成立”所需的证据行数；取出的行自身可以仍有共同动作。

**第一步，把记录放到树上。** 每组互不交叉的列对应一族相容分裂，可以用一棵树实现。将边按列的重复次数细分，每走一条单位边翻转一个原始读数位。由此得到的树顶点代表合法的比特记录，中心之间的树距正是这些列上的汉明距离。反方向也需要证明：对任意实际记录，取它到各行的实际距离作为该色的半径。由三角不等式，这些树球成对相交；树的子树满足 Helly 性，故树上有一个顶点，到每行的距离都不超过实际记录的距离。对各色分别做这件事再相加，原记录可行当且仅当在 $d$ 棵整数树的顶点积中存在可行点。树积使用各因子距离之和。[Buneman 的相容分裂树](https://www.research.ed.ac.uk/en/publications/the-recovery-of-trees-from-measures-of-dissimilarity/) · [Chepoi 与 Hagen 的交叉图及树积表示](https://arxiv.org/abs/1107.0863)

**第二步，在树积中找小证据。** 取一个按包含关系极小的空交球族。此后保持空交，把各球的整数半径尽量放大，直至任何一个半径再加 1 都会产生公共点。这个过程能结束：删掉任一球后都有交点，且树积有限，故每个半径都有上限。对球 $i$，记单独再放大 1 后出现的点为 $y_i$。它到第 $i$ 个中心的距离等于当前半径加 1，到其余中心的距离都在相应半径内。

每棵树按顶点深度的奇偶分两色，每个 $y_i$ 因而有一个 $d$ 位奇偶串。如果球数超过 $2^d$，必有两个点的奇偶串完全相同。它们在每棵树上的距离都是偶数，沿各树最短路取中点，得到一个整顶点。树上到固定中心的距离在中点处至多等于两端距离的平均值，各色相加仍成立。对任一球，两个端点至多有一个超出半径 1，所以中点至多超出半径 $1/2$。距离是整数，中点实际属于每个球，与空交矛盾。这个论证使用了格点 Helly 证明中熟悉的奇偶思想；当树都是路径时，格点 Helly 理论本身已经给出上界。[Doignon，1973](https://doi.org/10.1007/BF01949705)

**取等与先例。** 用全部 $d$ 位签名作中心，半径都取 $d-1$。每个球恰好遗漏其中心的逐位补码，少任何一个球就有公共点。因此 $2^d$ 行均不可少。这个立方体构造已有发表记录。Alon、Jin 与 Sudakov 已证明按共同半径 $t$ 控制的紧界 $2^{t+1}$，其论文也讨论了有界异半径。这次推导改用列交叉结构控制证据大小，可在重复次数和半径都很大时仍给出小界。更具体地说，任意 $d$ 棵非平凡有限单位树的顶点积，整数距离球的空交 Helly 数恰为 $2^d$：上界如上，每棵树选一条边可得到上述立方体；积外的任何顶点逐树投影到所选边，都只会缩短到立方体中心的距离。[Raman、Subedi 与 Tewari 的立方体构造](https://proceedings.mlr.press/v247/raman24b/raman24b.pdf) · [Alon、Jin 与 Sudakov 的半径定理](https://arxiv.org/abs/2405.10275)

## 实现怎样避免枚举记录

框架逐个处理没有共同动作的极小组。全部列相容时，直接比较各对距离和半径和。接近一棵树时，保留少数例外列：若某列重复 $n$ 次，只需一个整数 $z$ 表示这 $n$ 次中有几次读到 1。它对预测 0 的行消耗 $z$ 次额度，对预测 1 的行消耗 $n-z$ 次。扣掉消耗后，剩余树上的球仍只需成对检查。

具体地，对每对行 $i,j$ 加上一条不等式：两行在树列上的距离，加上它们对例外列各自消耗的额度，不得超过 $r_i+r_j$。也检查 $i=j$ 以保证剩余额度非负。这组整数不等式是充要条件。只有一至两种例外列时，合并相同方向的不等式后，只需对 $x,y,x+y,x-y$ 的整数界作消元。大数只以二进制整数参与运算。通用异半径 Closest String 的整数规划、四串的组合算法及整数八边形消元都已有先例。[非均匀 Closest String 的形式化](https://drops.dagstuhl.de/storage/00lipics/lipics-vol325-itcs2025/html/LIPIcs.ITCS.2025.83/LIPIcs.ITCS.2025.83.html) · [Boucher 等的四串研究](https://doi.org/10.1007/978-3-540-89097-3_26)

对可用两色、但删两列仍无法变成单树的组，我们采用了**更早、更快的已知结果**。两树之积是无三维立方体的中位图；在这个二分图的任一侧，半球满足两两相交即整体相交。以一个中心为基点，分别假设公共点的总距离奇偶为 0 或 1，将每个半径向下调整到该侧所需的奇偶性。若有一侧的半径均非负、所有成对距离都不超过调整后半径和，则有公共点。实现只需计算一次中心距离矩阵，再做两轮成对比较。这个低维判据及相应的四球界可以由已有理论推出。[Bandelt、Dählmann 与 Schütte，1987](https://www.sciencedirect.com/science/article/pii/0166218X87900588) · [Ducoffe，第 2 节定理 1](https://arxiv.org/abs/2101.03574)

其他结构采用精确的计数搜索。0.2.0 的计划搜索仍可能随候选、探针种数和预算组合爆炸。压缩大重复数的收益针对**给定清单的核验**，没有推导出任意大规模任务的快速最优规划器。

## 同一预算下的结果

| 任务及错误条件 | 保证能采取行动的最短固定清单 | 保证辨认具体机制的最短固定清单 |
| --- | ---: | ---: |
| 四台副本，最多一次错读 | 2 | 6 |
| SQLite 五种冲突策略，每种均须准确回答 | 2 | 4 |
| SQLite 五种冲突策略，每种均容许一次错读 | 6 | 12 |

副本任务的两两分离方案需要 3 次，因为任意两次询问所得的两串距离至多为 2，尚不足以分开两个半径 1 的球；连续三次询问同一位即可分开一对。对联合方案，四种停机位置、无错或任一位置错一次的 12 个情形均实际跑过。同一方块还可把每列重复 1,000,001 次，容许 1,000,001 次错读。清单核验只传入两个计数：总计 2,000,002 次足够，减掉末列一次就不够。这是数学清单的核验，未执行两百万次外部测量。

SQLite 沿用[上一轮的四个读数和三种修复动作](../action-before-identification/README.md)，取消了预先产生的冲突历史，五种候选具有相同错误预算。这次没有对五种策略都有效的回退动作。最短行动清单还用逐字串穷举独立重算。五种真实数据库策略，无错档 5 次运行、有错档 35 次运行，分别实际执行了返回的 SQL 修复，最终表全部准确。早停时，安排在停止之后的错读与无错可产生同一条实际记录，因此这里按运行数报告。

**对计算结论的反证检查。** 对两位签名的 1,296 个次数与异半径组合、4,802 个动作与错误组合以及固定种子的 600 个小表，用独立穷举器核对所有可达回答串。另取两条路径之积和两棵分叉树之积，检查 200 组异半径的两色实例，137 组可保证行动，63 组仍有共同记录。对三叉星树与单边的积，直接枚举 8 个顶点上的 23 个不同球，得 82 个二球极小空交、27 个四球极小空交。立方体上分别验证了 2、4、8、16 行的不可删证据。测试有限；任意维数的结论依赖前面的证明。[完整数据](evidence.json) · [复现代码](check.py) · [检验口径](PROTOCOL.md)

**单独检查三棵分叉树。** 为避免只在路径或两棵树上检验高维推导，另取三棵三叉星树。对 512 组固定种子的异半径球族，直接比较树积的 64 个顶点和环境中全部 512 个九位记录。两种穷举都判定 369 组空交、143 组有交；逐组结果相同。对人造紧例，8 个球在整个分枝树积中没有公共顶点，而删去任何一个都能找到。这项追加检查验证了从读数空间转到树积空间的一步，任意维数仍依赖证明。

## 哪一部分还值得作为研究结果

这次可以复用的成果有两个：**一是按列交叉图着色、对任意逐行错读额度成立的空交证据界及其分枝树积证明；二是把这些结构判据接到行动规划器里，让调用方得到可复核的结论。** 低维四球界、两两相交却整体空交的例子、汉明球的半径界都有直接先例。对于三棵及以上分枝树的一般公式，我们在已核对的原文中尚未找到相同陈述。检索覆盖图论、离散几何、共识串及编码理论，未完成 MathSciNet、zbMATH 的穷尽式引文核查，不能据此确认全球优先权。
