# 核验口径

先固定核验矩阵，再运行。测量目标是同一有限候选集、同一逐次错误预算和同一复查费用下，固定查询清单是否保证最终有可用动作。逐问可变的计划另计。

- 对两个二元探针的全部四个签名，枚举每个签名独立取 0、1、2 的错读额度，两个探针各重复 0 至 3 次。逐字串核对“所有四条规则能否解释同一记录”。对同一表再枚举每条规则在三个动作上的全部非空允许集合，分别取统一错读额度 0、1，用两个探针各查询一次核对可行动性。
- 对三位全立方体和四位全立方体验证证据大小以及删掉其中任何一个中心后的结果。另用固定种子，取 3 至 6 列、4 至 9 行、不同错读预算的小表，比较计数方法和所有回答串穷举。
- 对“仅一台副本停机、选一台可用副本”的两位任务，比较同预算下的联合证书、两两分离的充分条件及完整辨识。另将两列分别重复 1,000,001 次检验压缩输入，不在该规模尝试逐字串穷举。
- 用 SQLite 成功执行且最终行表正确来验收动作。在五种真实冲突策略下都保留错读余量，不指定对全部策略都有效的回退动作。固定清单最优值由独立穷举复算。对最优清单上的每个受允错误位置，实际执行终止时给出的动作。

这是项目内核验计划，未做第三方预注册。

## 追加检验

推导中得到一个更强的着色界。为分开检验树上分叉、两色判定分支及证书紧性，补做四乘四格点的两色例子，并在三叉星树与单边的积上，用顶点集合直接枚举所有包含极小的空交球族。紧性测试扩大到一至四维立方体。

确认二树情形已有半球定理后，追加两色奇偶分支的 200 组随机核对，并在三棵分叉树上比较 64 个树积顶点和环境的 512 个二元记录。后一项另检验嵌入小立方体的 8 球不可删例。以上均属追加分析。
