# 本轮验收口径

在运行新计时前确定以下检验。目标是让带异质错读额度的二元行动规划器核验高重复数清单，并构造可以独立检查的证据。

1. 对相互补的预测行仅有一列相同的情形，推导该列正读数的整数上下界。检验扣掉已确定的正负读数后，原计数盒与剩余计数盒之间的可行点是否逐点对应。单独处理重复行、空区间、缺少一侧界、缩减后变量消失及删行提证。
2. 用 16 个分片的四位地址构造非均匀探针次数和逐行半径。证明某些输入中 16 条原始行缺一不可，并以整数 Helly 定理限定能够排除的三维模型。普通整格 Helly 下界以及植入单位盒的专用公式须单独列作已知或显然可利用的对照。
3. 用独立枚举比较小预算随机表，另用公共整数规划器核验不规则、缺行及高重复数的输入。公开固定种子、两种可行性结论、未解样本与原始计时。分别计量完整判定与反例/冲突证据提取。旧版本使用提交 621f118 的同一输入，设置每档超时，超时档不报加速比。
4. 在真实 SQLite 写锁上验证 16 个锁位置及其模型允许的所有小清单读数。大重复数只做压缩计算。公开可执行包、测试、原文先例与边界。没有跨机器或真实线上故障率数据，实测结论限于所列输入。

初步文献检索找到了 2011 年两行共享位置界的直接先例，增加四行对照。在线性聚合仅限一次、最多四行且不使用变量盒的条件下，检验最强单坐标界是否一定来自两行或等权四行。用独立有理数线性代数枚举小表的全部候选支撑集。加入六位偶校验表和非仿射行预算扰动；偶校验表上两行方法没有任何单坐标界。比较整数规划、已有核验器中的行对传播、两行压缩及等权四行压缩，并单列规则实例的专用直接解。以上增项发生在正式计时之前。

预跑发现，部分缺行非仿射实例能迅速判定，但为证明每一行都不可删，重新求解删行子集需要数十秒。追加单独的行动保证声明，显式放弃证据的删行极小性，保持同一行动保证和独立核验。完整报告同时保留原有极小性耗时和新模式耗时。一个有固定预算的整数投影预处理试验未解决这一慢例，未纳入发布版本。旧版和两行消融每个计时样本上限两秒。非仿射的 18 张表使用固定种子，完整提证允许跑完，慢例计入原始记录。
