
# 冻结协议：两实况的分组能否安全用于三个实况？

采用 Stanford SNLI 测试集的固定 Parquet 文件。源版本 cdb5c3d5eed6ead6e5a341c8e56e669bb666725b，文件 SHA-256 为 4696deda851c4d2385f26b58f2e13f9ed9f08ea7b42a3f4c2b97a9d08448878c。模型与运行环境沿用固定 INT8 DistilBERT CPU ONNX 及八档最小右补齐宽度 0、16、24、32、48、64、96、128。

## 选题与门控

仅保留同一前提下蕴含、中立、矛盾三个标注都出现的题。取每种标注在 Parquet 原始文件中首次出现的假设。按 SHA-256 对 multiworld/v1/ 加前提排序，取最前 480 个前提，每八个组成一个目录。每个前提的三个方向按标签编号 0、1、2 排列，以哈希末字节除以三的余数做循环移位，分给三个实况。每个方向都真实执行八档，并存储 float32 位模式。相同有效宽度允许复用一次前向计算。

使用三分类中最高分与次高分之差。最高分须唯一、标签须与参考答案相同、分差须达到对应门槛，才通过模型分支。门槛固定为 0、1/4、1/2、1、2、4。保留逐项的辅助抽签，1/20 固定拒绝、1/20 经标注核对后答复，9/10 采用模型门控。因此条件拒绝率为 1/20 或 19/20。参考标签是实验环境的验证器代理。

## 主要比较

三个实况共用同一档位分布，逐项独立分支比例为 1/2。另半批次组内共用、组间独立，分组预先固定。要求对任意共同档位分布，所有窗口和所有实况的归一全拒绝率一致。共有 360 个预定目录和门槛组合。

- 按头两个实况的精确旧分组编排，加入第三个实况后独立检查。只有找到具体的二项冲突和允许档位分布才计为失效。报告失效数及在等权基础上最多四分之一可变份额下的见证。
- 对三实况直接求最少分组。对照是任一实况内两项若都随档位变化，就强制分开的最优保守策略。报告两种方法的组数及等权时配置种数期望。若两种方法结果相同，保留零改进结果。
- 报告相对于逐项独立的收益和新增实况带来的分组数变化。主要验收门槛是全部 360 个三实况分组和下界通过独立检查，且至少一个两实况分组在加入第三实况后有反例。

以独立整数格点核对全部兼容对。用小请求数全分区枚举及完整概率表检验更广的输入。给出一个五实况、两个档位的五环输入，要求三组并证明最大冲突团只有二项。最小组数须有独立可验的匹配下界。该构造用于验证数学边界，不计入模型实验。
