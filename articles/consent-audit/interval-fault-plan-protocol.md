# 可信补核渠道有限时，最坏需要花多少？

在规划器计分及合成比较前冻结。所有任务只需判定一个定向阈值，可以提前停止。每种渠道的回复是准确的差值，选用前知道费用。目标本身不能作为直接补核。问完一个渠道可以根据答复选择后续渠道。主优化量为所有允许世界中费用和的最大值。

- NOAA 沿用已冻结的 2025 站日组。有一条错报的场景按单错报协议注入，有两条错报时按双错报协议注入。六条原差值均为目标，门槛为 1.0°C。
- BART 沿用已有样本和 300 秒可信区间。双错报场景沿用上一协议的图和注入规则。单错报场景只使用原图中按顶点编号序列字典序最早的六边简单环；若无则使用最早的四边环。环从最小原顶点出发，字典序比较包含可选定向；按选中序列把节点编号为零起始位置。报告顺环定向，目标为全部环边差值是否达到 180 秒。注入规则对 `<原档案 ID>/1` 作 SHA-256，顺序用前三字节选环边、从 `[60,180,300]` 选偏移幅度及定符号，奇正偶负。无四边或六边简单环的档案另计。
- 每案将所有无序顶点对按升序定向。现有报告渠道均可独立复核，费用为 `1 + 哈希第2字节 mod 4`。其他渠道只有当第 1 字节模 3 为零时才可用，费用为 `3 + 哈希第2字节 mod 4`。哈希文本固定为 `<原档案 ID>/<预算>/probe/<u>/<v>`。预算为 1 或 2。费用是模拟访问价格，源数据的数值是真实天气或计划时刻。

单错报使用此前路径给出的世界顺序和探针区间，比较结构化最坏费用规划器与任意顺序的精确有限状态求解。两错报只在图上最少修复数恰为二的档案上构造有限世界和精确策略，将其余条件记为未进入该模型。对每项任务另求在询问前就必须定好全部渠道的最便宜固定方案，完整计入该方案费用。对渠道全问仍无法保证判定的任务，保留两个真实可行、目标标签相反且所有可用答复相同的世界。付费答复按原始真实读数回放，同时在所有相容世界逐条核验策略结论和最坏费用。记录已知、无法保证、可行、可行且至少两问、最坏及真值重放费用。对 BART 不同图和费用、天然断连等排除条件分别计数。 [单错报口径](interval-fault-cut-protocol.md) · [双错报口径](interval-fault-delta-protocol.md)

按预登记的可核验性条件，至少有 50 项起初歧义的任务可用可用渠道定案，且所有策略成本和拒答证据获独立精确核验，才认为有限渠道下的方法具有效用。若所有起初歧义且可判任务的最坏总费用比最优固定方案低至少 5%，才说自适应取得预设的成本改善。分预算和来源报告，保留未通过的条件。

合成比较固定以 `Random(881709)` 生成 600 项小实例，世界数为 2 至 11，标签由一段真区间生成，同时随机加入无可判实例。任意探针报告其区间内外，费用为 1 至 8。独立任意问法的决策树求解核对全部最优值，固定方案也独立重算。另对 16、32、64、128 个位置的链，为唯一的末端正例提供全部负侧单点和前缀询问，前缀和单点费用均为一。实际测量结构化状态个数，报告逐问版本集合算法可产生的状态数下界，不用该下界冒称实测耗时。另公布可逐项复算的严格自适应改善反例，即使数据回放没达门槛也保留。
