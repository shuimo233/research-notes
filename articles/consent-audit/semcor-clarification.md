# 推理器什么时候可以少问一个词义？

有一处真实语料，family 和 person 在同一句出现。词典把 family 列出八种候选义项。知道这里的 family 指“父母与子女组成的家庭”以后，即使还不知道 person 的具体义项，也能确定：在 WordNet 这两个名词义项之间，没有任一方向的严格上位链，也不是同一义项。换成 figure 和 person，语料里确实有前者的义项属于后者的例子，这时只问一个往往无法定论。这是一个可以逐格核查的问题。确定当前两个词义的词典关系，并不要求两个词在原句中构成主谓关系。[逐词记录和来源位置](semcor-clarification-ledger.tsv) · [WordNet 的词义组织](https://wordnet.princeton.edu/)

**预登记的策略没有胜过简单对照。** 对 254 次真实同句共现，如果机械地问清每个多义词，共需揭示 506 次词义。依据词典关系表挑先问的一端，在剩余解释都给出同一关系时停止，共需 350 次。让同样会提前停止的服务总是先问义项更多的词，只需 347 次。两种方法都准确重放了全部 254 个关系。数据支持给推理器设置“什么时候可以停止”的条件；这项实验没有给采用更复杂的询问顺序提供依据。[查分前的方案](https://github.com/shuimo233/research-notes/blob/0c655a440d054674ec766df04ad0983c15be825a/articles/consent-audit/semcor-clarification-protocol.md) · [全部指标](semcor-clarification-results.json)

## 怎么衡量一次询问

选词沿用先前公开的 208 个双向词对。从词形出发，这些词对在词典中各能找到朝向相反的上下位证据。遍历 SemCor 全部 352 篇文档、37,176 句，要求两个名词在同一句中出现且均有可映射到 WordNet 3.0 的单一标注义项。符合条件的是 101 篇文档、160 个句子、63 个不同词对，共 254 个位置组合。同一个词在句中重复出现按不同位置计数。这里采用标注 lemma，包括语料给专名或多词单位指定的 lemma。语料中的义项由原有标注映射而来，每一对义项的关系再由固定词典导出。[已发布的选词依据](wordnet-conflict.md) · [SemCor 的版本与标注来源](https://github.com/globalwordnet/semcor)

把甲词义项排成行、乙词义项排成列。每格填四个答案之一：同义项、甲是乙的严格下位、乙是甲的严格下位、均非。若已知行的所有格都相同，无论对端词义是什么，询问也无法改变答案。列同理。主策略先选“揭示哪个词更可能一次就能停止”，计算时给该词每个候选义项相同权重。运行前不用 SemCor 标注拟合权重。单义端本来就已知，所有策略均可免费使用。每次询问模拟获得一次准确的词义揭示，实际界面中辨认八个义项和辨认两个义项的耗时可能不同。[可复用的逐步询问接口](sense_inquiry.py) · [主动选择测试以确定决策等价类的先例](https://papers.neurips.cc/paper/2010/hash/1e6e0a04d20f50967c64dac2d639a577-Abstract.html)

| 先问哪一端 | 254 次共现的总询问数 | 63 个词对等权，每次共现的平均询问数 |
| --- | ---: | ---: |
| 按关系表中可提前确定的比例 | 350 | 1.4254 |
| 义项较多的一端 | **347** | 1.4274 |
| 按字母序先问甲 | 364 | 1.5101 |
| 随机选甲或乙，各半（精确期望） | 411 | 1.5735 |
| 按字母序先问乙 | 458 | 1.6369 |
| 义项较少的一端 | 472 | 1.6878 |
| 两端多义词全部问清 | 506 | 1.9841 |

160 个位置组合的成本取决于先问哪一端。按词对等权后，关系表策略比“义项更多优先”略低；预先登记的主要指标按实际出现次数计。重复组合、文档及义项分布会影响顺序优劣。这里报告固定语料上的完整计数。[逐条核对成本](semcor-clarification-ledger.tsv)

## 省下的询问用在了哪里

| 两个已用义项的关系 | 位置组合 | 问清全部多义端 | 按关系表顺序并准许提前停止 | 省下 |
| --- | ---: | ---: | ---: | ---: |
| 两个方向均无严格上位关系，且义项不同 | 209 | 418 | 262 | **156** |
| 甲是乙的严格下位 | 27 | 52 | 52 | 0 |
| 乙是甲的严格下位 | 17 | 34 | 34 | 0 |
| 同一义项 | 1 | 2 | 2 | 0 |

这是框架设计上最有用的发现。如果界面负责筛除不合适的上下位候选，在这批语料中确实可以省下一部分词义标注。如果用户需要一条肯定的分类依据，按同一策略得到的 44 个严格上下位判断一个也没省。一个系统完全可能在总询问数上好看，同时没有减轻确认正向关系的工作量。[按关系分层的完整计数](semcor-clarification-results.json)

看到这个分布后，我们另做了一个登记之外的检查。208 个原始词对中有 204 对的两端都确有多种义项。直接枚举每一行和每一列，发现 **2,144** 个“揭示一个义项便可断定均非”的情形，分布在 203 个词对；也有 **7** 个“揭示一个义项便可断定严格下位”的情形，分布在 7 个词对。因而语料中正例节省为零既不应写成逻辑定律，也不应被总均值掩盖。此处计数单位是“词对、揭示哪端、揭示哪个义项”，每一项对另一端全部候选义项成立。[独立枚举结果](semcor-clarification-checks.json)

## 试用与复核

在本目录运行以下命令。第一条列出需要澄清的词、候选词义编号和释义。第二条采用前述已标注的 family 义项，直接返回 `neither`。命令只需 Python 标准库和锁定的词典，可换成其他名词。输出描述同义项和严格上下位关系，使用前须核对这一关系是否足以回答业务问题。[查询工具](wordnet_sense_query.py) · [WordNet 授权](wordnet-LICENSE.txt)

```sh
python -I -B wordnet_sense_query.py wordnet-3.0-nltk.zip family person
python -I -B wordnet_sense_query.py wordnet-3.0-nltk.zip family person --left-sense 07970406
```

以下命令可取得两份内容锁定的语料，在新目录中重建结果。核验器另用 Expat 解析文档、用 NLTK 读取 WordNet，并沿词典路径独立计算每个可能的关系。它重新找到相同的 254 个位置组合，核对 1,270 条确定性策略轨迹，检查主策略停止时剩下的全部 766 个义项组合。输出账本、总表和核查记录都与公开文件比较。[重建入口](semcor_clarification.py) · [独立核验器](semcor_clarification_check.py)

```sh
uv run --no-project --python 3.13 --with nltk==3.9.2 -- python -I -B semcor_clarification.py wordnet-3.0-nltk.zip semcor-3.0-nltk.zip fresh-semcor --fetch --check-release
```

本轮形成了可核验的同句词义普查、比较顺序失败的实证结果、按关系分层的成本与一个能返回下一次询问的工具。主动取证与词义消歧都有直接先例。词对来自依据义项标注频次挑选的常见词，SemCor 和 WordNet 的标注来源有关联；这是对固定词典、固定语料的研究。公开材料可用来复核这一项具体结果，尚不足以主张首次提出一般推理原理，或宣称已测过人工标注时间。[相关工作的事前记录](semcor-clarification-protocol.md) · [基于 WordNet 的词对消歧与蕴含研究](https://aclanthology.org/2023.findings-emnlp.615/)

得到结果后，又以 SemCor、hypernymy、polysemy、early stopping、clarification cost 和 lexical entailment 的组合检索了既有论文。邻近工作包括对 WordNet 多义性及上下位结构的全局统计，以及用 SemCor 和上下位知识对共现词做消歧。在此次检索可核实的来源中，尚未找到对同一双向词对集合按关系分层报告精确询问成本的既有结果。这个范围限定的是文献比对所支持的归属。[WordNet 的网络统计](https://pmc.ncbi.nlm.nih.gov/articles/PMC122261/) · [SenseLearner 的词义消歧研究](https://web.eecs.umich.edu/~mihalcea/papers/mihalcea3.senseval04.pdf)
