# 用一条时间差证词，补足公开最优性证明

审阅者有旧档案、已披露的精确时刻和新版报告。原来的读数足够确定报告，但公开材料可能还容许一份原始记录，在那份记录上，用更少的读数也能确定报告。这里检验能否只公开一条较粗的比较，例如“事件 5 比事件 9 晚至少 13 分钟”，就确认原证书已经最短。

在此前确认存在信息缺口的 **35 项任务**中，**21 项**只需一条分钟格点比较，并且所有此前不确定的时刻仍有至少两个可能值，达到事前登记的门槛。在有界整数差分模型中，原证书最少需要两项时，存在唯一最大的安全补证区域，也就是能保留最多相容实况的区域。最少需要三项时，唯一性可能消失。[预登记](https://github.com/shuimo233/research-notes/blob/6ec9db974b13e7a7ed90e9da7a604c4ab2924ed7/articles/consent-audit/attested-optimality-protocol.md)

## 证词缩小实况范围

旧档案 A 固定。现有公开读数把实际记录限制在差约束区域 C。将 C 里可以从 A 出发、用少于原证书项数就证明报告的记录收集为集合 M。新增比较只缩小 C。衡量替代证书的代价时，继续使用原来的 A。审阅者接受比较为数据保管方的证词，再独立判断 C 中还有没有满足比较的 M 成员。

对一个有向差值 `x[v]−x[u]`，取 M 中能达到的最大值 H。能在这个方向排除 M 的最宽松整数比较是 `x[v]−x[u] ≥ H+1`，还须核对它与实际记录一致。格距为 60 时，把阈值改成严格超过 H 的下一个整分钟。若实际记录落在 M 的最小差约束包围域内，每个方向上都有坏实况达到至少同样大的差值，单条比较就无法排除 M。[差约束包围域](https://arxiv.org/pdf/cs/0703073) · [最弱充分条件](https://www.sciencedirect.com/science/article/pii/S0004370201000704)

多条比较可以排除不同的坏实况。保管方只需从每个方向的最强真实格点出发，因为更弱的同方向比较所排除的记录是其子集。每找到一份坏实况，记录哪些真实比较能排除它。这些记录成为最小击中集的约束。候选比较排除全部坏实况时，已收集的反例证明其条数达到最小。确定条数后，程序逐条放宽阈值，并再次核验。新增比较条数的最优性是在保管方知道实况、能判定哪些候选为真时建立的。公开核验器直接验证的是原证书的最优性。[已有的隐式击中集方法](https://arxiv.org/abs/1604.08229) · [公开核验量词](attested-optimality-prior.md)

## 两项和三项之间的边界

若原始最少证书是两项，只需排除所有一项替代证书。对任一位置 i，求各条错误报告在这个位置上的投影，并取这些整数区间的并 Rᵢ。若某个候选实况的 i 坐标落在 Rᵢ 外，单读该位置就能排除所有错误报告。若所有坐标都落在各自的 Rᵢ 内，就没有这样的一项证书。

对实际记录的每个坐标，取 Rᵢ 中包含它的最大连续整数段 Jᵢ。C 与全部 Jᵢ 的交集，是包含实际记录并能证明原最优性的**唯一最大差约束区域**。原因是任何可接受差约束区域在单个坐标上的投影都是连续整数区间，其中没有允许一项替代的点，因此每个投影都必须落在相应的 Jᵢ 中。在这个最大区域中已经唯一确定的时刻，必然会被任一成功的差约束补证锁定。

原证书需要三项时，可以有两种不相互包含的安全证词，而包含二者的任意差约束区域又允许一份更短的证书。独立程序穷举了一个布尔档案的全部 2,048 种赋值，验证了四份公开相容记录的最小证书数依次为 3、3、3、2。真实回放的原证书规模为三至八项。二项情形是单独验证的理论结果。[证明与紧边界](attested-optimality-prior.md) · [穷举核验](attested_optimality_boundary_check.py)

## 35 个已知信息缺口

预登记输入是此前 BART 的 34 项和 GitHub Actions 的 1 项，均已找到公开相容的更短证书。独立程序重新证明实际原证书确为最小，并用原始不等式穷尽替代名单，核验三种字典的补证、最少条数、不可行反例和新增可推断的精确位置。[BART 原实验](transit-optimality.md) · [CI 原实验](public-optimality.md)

| 比较允许的格距 | 找到有效补证 | 只需一条 | 一条且未新增可推断的精确时刻 |
| --- | ---: | ---: | ---: |
| 1 秒 | 35 / 35 | 33 | 33 |
| 60 秒 | 34 / 35 | 32 | 21 |
| 300 秒 | 25 / 35 | 24 | 9 |

33 项可用直接再披露一个原始读数修复。60 秒字典下，除 32 项单条修复外，另外两项分别需要两条、三条。唯一的 CI 案例有一秒格点修复，但满足所有真实分钟格点比较的相容记录中，仍有一份允许更短证书。BART 任务 180 的公开包需要证明原来的六项读数已经最少，仅补充“事件 5 比事件 9 晚至少 780 秒”即可通过核验，审阅者不能据此唯一推出此前不确定的任何一个时刻。这些数字衡量比较数和精确值可推出性，其他属性的不确定性也可能受比较影响。[汇总](attested-optimality-results.json) · [只含公开资料的修复包](attested-optimality-packets.json.gz)

## 复算与使用

从本文目录用 Python 3.13 执行。第一条命令只需要公开包，索引 8 正是 BART 任务 180。其他命令重算比较选择、结果和理论边界。

```text
python -I -B attested_optimality_inquiry.py attested-optimality-packets.json.gz --index 8
python -I -B attested_optimality_run.py attested-optimality-cases.json.gz reproduced
python -I -B attested_optimality_check.py attested-optimality-cases.json.gz reproduced
python -I -B attested_optimality_boundary_check.py
```

还可以用 `python -I -B attested_optimality_prepare.py . rebuilt-cases.json.gz` 从冻结的上轮文件重建研究输入。公开包中每条三元组 `[u,v,c]` 表示 `x[v]−x[u]≥c`。位置 0 是已知原点。公开工具接收单项 JSON 或压缩的列表，成功时返回核验的原读数数目以及新增可推出的精确位置。

差约束包围域、最弱充分条件、隐式击中集都有直接先例。本次检索尚未找到以最少原读数的公开核验为目标、给出二项与三项分界的相同定理。35 项回放是从已知困难个案中选出的条件实验，首创性与对其他任务的适用率仍待独立核查。[先例核对](attested-optimality-prior.md)
