# 归档规则改变后，哪些原始温度必须重新读取？

本协议在生成归档标签和新版计分前登记。使用已冻结的 NOAA 观测，模拟只留粗温度区间与历史报告、原始精确读数须按站调取的复核合同。原始值始终是同一历史观测。衡量读取次数与证书正确性。

## 输入与目标

使用 `station-tmax-through-2025.csv.gz`，Git blob `6f05e7ea0d8945d9b7a8b5f8cad647a6671a488f`。沿用[旧实验](station-query-protocol.md)的站点、质控、2000–2017 年月中位数和宽度 20 的离散区间。2025 年中两地区分别保留本组五站都有值的每一天。该快照已用于此前不同问题；这是对新复核合同的预登记运行。

旧档案给出每组当日站点的五个粗区间和六对报告标签。六对沿用旧实验的中心至 A、B、C、D，以及 A–B、C–D。温差以 0.1°C 为单位，在 `d <= -10`、`-10 < d < 10`、`d >= 10` 上分别报告低、近、高。方向是后一站减前一站。新版报告要求全部十对，分别独立回放两个版本，容差改为 8 或 12。这个修改用于测试规则更新时的重读；容差是事前规定的实验参数。精确值只在查询请求后交给策略。所有与旧报告和区间一致的整数温度同时属于候选支持，不设置先验概率。

## 机制与比较

从温度区间和旧标签建立整值差分约束图。每个新版标签都可以用差分上下界复核。用同一报告蕴含的固定温差合并站点，并计算在看见任何追加读数前、保证所有相容实况都能产生全部新版标签的最小固定读取集合。代表按旧实验的 H、A、B、C、D 顺序选最靠前的站。若用原点表示绝对温度，已知固定值的组件无需重新读取。验证候选定理要求保证对候选支持的每个世界都有效。

对照包括全读、从区间单独重做（读取仍有歧义的边的全部非固定端点）、以及逐边应用同一条旧报告标签后读取歧义边的端点。逐边方法对新增的四条关系只使用区间。另计算独立的最小实际读取证书，以及一个在线策略：在固定方案之外，可选任何尚未知的站作第一问，枚举该站所有可行读数并计算剩余的最小固定方案。如果一问加上最坏分支仍严格少于固定方案，采用最小最坏分支候选，平局取顺序靠前的站。观察首站以后使用对应的固定方案。这个规则衡量在不增加最坏预算的前提下能否利用自适应；整轮实际最多花费其登记上界。

用独立差分可行性程序实现两份相容世界：两份世界在同一读取子集上相等，某个新版温差阈值两侧分别成立。枚举所有小任务中固定读取子集或逐个构造必要性反例，以比对最少固定集合。另检查冻结回放上的每个返回标签、整个查询证书，以及固定、动态方案的最坏界。用独立的显式可行世界枚举验证小合成问题，覆盖固定偏移、同时更新约束、不可行的读数、负温度、阈值跳变和不同原点相对读数。

## 通过条件

主判据同时要求至少 500 个完整的日期与地区组合、全部新版标签和证书正确、固定计划通过必要性与充分性核验，以及相对逐边应用旧标签的回放读取至少减少 5%。公布两个容差分别和汇总的各策略计数。自适应策略比较另行如实报告实际和最坏预算，不计入主门槛。人工遮蔽下的读数节省不折算成部署速度或费用。[NOAA 数据说明](https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily)
