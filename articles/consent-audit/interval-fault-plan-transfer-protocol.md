# 目标未归档、部分渠道不可用时的补核复验

本补充在看到主回放的费用相等结果后、运行新合同前冻结。当前假说是，单错报、原报告目标的特殊结构会让固定方案与自适应方案的最坏费用相同。另测试目标变化以及减少可用渠道后的表现。本轮只使用前一协议的单错报图、可信区间和已冻结的错报注入。

NOAA 逐案只审查未报告的无序站点对，由编号小者向大者，门槛仍为 1.0°C。BART 只审查原始候选换乘关系中两端都属于选中环、却未被选为环报告的关系，保留其原到达→出发方向与 180 秒门槛。原始价格仍按上一协议。先沿用上一协议确定库存，再从每个可用渠道的同一哈希中取第 3 字节。模 3 为零的渠道在本轮关闭，已有报告和额外渠道都适用。每个需判断的目标仍不能用其直接渠道核实。

逐项验证固定、自适应的最坏费用及真实重放费用。渠道不足时核对一对目标标签相反、所有可用渠道答复相同的完整可行修复。只要至少有 50 个起初歧义的目标可被判定、至少 20 个起初歧义的目标取得并核验无法判定的双世界证据，便达到本轮的工程验证门槛。仅在全部起初歧义且可判任务的总费用比最优固定方案低至少 5% 时，声称部署情景中的自适应成本优势。严格改进的个例、总效用和拒答证据分开报告。
