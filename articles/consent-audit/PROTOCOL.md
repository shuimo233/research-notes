# 同意原则的行为审计 · 验收口径

2026-11-23，在拟合模型与运行对照前记录。研究对象是代理发出的二元请求。所有实验只处理合成标识，执行闸对未经同意的请求一律拒绝。结果限于所列任务和候选行为规则。

- 若有同意且收益为正，两类规则均请求。无同意时，绝对规则拒绝，补偿规则在整数收益严格大于固定阈值时请求。阈值为非负整数，不设先验上限。不同试次的真实收益各自可在记录的闭区间内取值。允许最多 f 条完整的试次日志出错，同一条日志的请求位和效果位合并计错。受保护部署允许的收益为 1 到 B。
- 工具应给出全部相容阈值区间、绝对规则是否相容，以及部署内的结论。若尚有歧义，须在有限、可用次数有上限的采样菜单中，找到总成本最低的固定追加计划，或报告菜单不足。追加采样也在部署范围内，并计入同一个总误差额度。小问题用独立枚举验证阈值、最优费用以及允许后续日志是否真的相交。
- 在相同训练样本和相同两个输入特征上，分别训练决策树和带标准化的逻辑回归。无同意训练收益为 1–4，有同意为 3–6，各训练样本的标签等于同意位。收益区间 1–20 用于逐点检查实际预测。无调参。若学习到的模型不在候选族内，如实报告。分别采集执行效果和闸前请求，真实 SQLite 授权回调保护本地发件箱，比较两种可观察量。学习器使用合成示范，没有接入人的私人数据或使用语言模型。
- 先例核查分别覆盖词典序效用、偏好识别、运行时屏蔽、错读纠正与覆盖优化。一般哲学命题、已有数学技巧、项目实现和本次新测得的经验结果分别归属。未获得全球优先权证据时不称首创。

看到学习器在原训练区间外可能分歧后，增加撤销单调性假设的敏感性对照。对于同一历史、同一总错误额度和同一未来菜单，比较全部稳定确定的按价响应函数。事先导出单点例外所需的精确报价配额，再用穷举所有响应函数与所有菜单子计划核对充分性和最优性。该推导在独立穷举之前记录。它只对部署范围内的有信息历史且全拒绝基线相容时给出精确最优计划。
