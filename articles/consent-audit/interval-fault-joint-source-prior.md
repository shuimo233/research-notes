# 共锚来源的联合核验与复杂度先例

## 从异结论世界对变成相邻边界

把每个来源的完整答复视作一个向量坐标，容许至多 $r$ 份来源错答时，对结论向量不同的候选世界，所购来源必须在至少 $2r+1$ 个坐标上预测不同。汉明距离大于 $2r$ 排除共同答复。距离至多 $2r$ 时，可在相异坐标上分别采用两个候选的值，制成双方均在预算内可产生的答复。Fawzi 等给出了按整个传感器轨迹计错的支持条件，Laifenfeld 与 Trachtenberg 已将鲁棒识别码写成 $(2r+1)$ 重覆盖。经典 Test Cover 的覆盖对象是所有需区分的点对，本文只需区分结论向量不同的点对。 [Fawzi 等，命题 2](https://arxiv.org/pdf/1205.5073) · [Laifenfeld、Trachtenberg，第六节](https://doi.org/10.1109/TIT.2008.928263) · [Crowston 等，Test Cover 定义](https://arxiv.org/abs/1204.4368)

如果每个来源在一条共同线序上的**每个等值答复类都连续**，上述全部约束恰可由结论向量发生变化的相邻位置替代。必要性来自相邻点对本身。对于任意异结论两端点，中间至少有一个这种边界。在该边界上给出不同答复的每个来源也一定区分两端点，因为若两端同答，其整个中间段都会同答。这个推理亦适用于候选世界为树的顶点、每个答复类在树上连通的情形。相邻边界换成树上结论变化的边即可。Kelk 与 Stamoulis 研究的凸性状使用了类似的连通同值类。Foucaud 等使用有序的相邻点对来证明识别码下界，但一般区间邻接并不提供这里的相邻约束充要性。 [Kelk、Stamoulis 原稿](https://arxiv.org/abs/1508.02598) · [Foucaud 等，区间与排列图的识别码原论文](https://perso.limos.fr/ffoucaud/Publications/Papers/J21_ID-interval-permut-1-bounds_TCS_2017.pdf)

要识别更宽的适用范围，可把每个来源的每个等值类各写成一个布尔行，候选世界作为列。存在共同连续序当且仅当该矩阵可重排为行内连续一，已可用 Booth–Lueker 的 PQ 树识别。一旦有这种顺序，一个来源至多贡献其不同答复数减一的边界。这也使数据检验得到一个独立于物理锚点的充分条件。本文的共锚结构则直接产生一个这样的顺序。 [Booth–Lueker 原论文](https://doi.org/10.1016/S0022-0000(76)80045-1)

## 为什么共锚差值图满足连续性

沿单错报修复的圆周，顶点 $v$ 附着在边界 $p(v)$，任一成对差值的两个答复类由其端点的附着边界分隔。对每个连通来源，取其一个附着在公共位置的顶点作参考。沿该来源图中的路径求和可恢复其中任意顶点对参考顶点的差，反之这些参考差也确定全部来源答复。把修复顺序转到公共位置之后开始，每个参考差的两个答复类就由一处阈值分开。若该来源整个答复在两个位置相等，则所有参考差在两位置相等，它们在中间也全相等。删除不相容的修复位置仍保有这性质。一个包含 $k$ 条比较的连通来源至多有 $k+1$ 个顶点。除参考边界以外的每个顶点至多贡献一个变化位置，所以至多有 $k$ 个变化位置。超边跨度、圆周连续一及来源内的路径和各自都有先例。 [上轮来源跨度与成组计错](interval-fault-source-bundle-prior.md) · [Tucker 原论文，定理 1](https://msp.org/pjm/1971/39-2/pjm-v39-n2-p13-s.pdf)

公共位置不能直接从原始圆周约束中省掉。用四点环，路径 $0,1,2,3$ 的报告为零，弦 $0\to3$ 报告为 1。以切点 0 表示删弦，依次以切点 1 至 3 表示删路径边。目标分别为 $x_3-x_0\ge1$ 和 $x_2-x_1\ge1$，四个目标向量为 $(0,0),(1,0),(1,1),(1,0)$。令三份来源复核 $0\to1$，另三份来源复核 $2\to3$。所有圆周相邻对都被三份来源区分，但切点 0 和 2 对全部来源同答，结论却不同。复核探针与两个原报告目标均不同。本例中任何采购都无法定案，原圆周的相邻条件仍会误判可行。更一般的库存可重新检验是否另有连续线序，或回到所有异结论对逐项检查。 [切点模型](interval-fault-cut.md)

## 两项比较的匹配归约

在已验证的共同线序上，把每个需要区分的相邻边界当成一个顶点，每个来源是覆盖这些顶点的集合。若每个来源只涉及至多两个所需边界，就将其写为一条边。一个边界的来源可接到其私有的虚拟端点。空来源可舍弃。同覆盖集合的两个来源仍是不同边。从所有来源出发，在真实顶点 $v$ 上至多可以删掉 $\deg(v)-(2r+1)$ 条关联边，因此最大化删掉的总价格是带边单位容量的最大权 $b$-匹配。Khan、Pothen 与 Ferdous 已明确给出同一个互补公式。Fitzsimmons 与 Hemaspaandra 第 2.2 节引理 1 和定理 2 用 Tutte 构造处理加权完美 $b$-匹配及重边。 [Khan 等，第 III-B 节](https://www.cs.purdue.edu/homes/apothen/Papers/IPDPS2018.pdf) · [Fitzsimmons、Hemaspaandra 原文](https://arxiv.org/pdf/2305.16889) · [Tutte 原文](https://doi.org/10.4153/CJM-1954-033-3)

一个直接的非完美加权版本是为每份可删来源建立两个端点节点。每个边界建立按可删容量计数的副本，端点节点只连到对应容量副本。单边界来源的另一个端点有一个私有副本。设 $B$ 大于任何价格，来源端点之间以内边权 $2B$ 表示保留。两端各向外接一个副本的权合计为 $2B+c$，其中 $c$ 是删掉该来源可省的价格。逐端外边可分配为 $B+c$ 和 $B$。最大权匹配不会只外接一端，因为用内边替代会升高权重且释放容量。内边与双外接两种方式对应任意合法的保留和删减决策。这一步采用已有匹配工具，新增条件来自具体差值合同为何能映射成这些边界。 [Khan 等的互补模型](https://www.cs.purdue.edu/homes/apothen/Papers/IPDPS2018.pdf)

## 三项比较的近似困难性

Alimonti 与 Kann 的定理 3.1 给出最大度三图上的最少顶点覆盖 APX 困难性。以每条原图边做一个元素，每个原图顶点的关联边集合至多有三个元素，于是普通一重覆盖和顶点覆盖的代价及解都一致。把这些原元素与每个元素私有的护卫位置排成一列，共 $n$ 个原元素与 $n$ 个护卫，取 $M=2n+1$。构造顶点 $0,\ldots,M$ 的路径，所有路径报告均为零，再加弦 $(0,M)$ 报告 1。各顶点的可信区间是 $[0,1]$。允许修正恰一条报告，所有删边切点均相容。只选路径切点 2 至 $M-1$ 对应的边作为目标，各以差值至少 1 为真。以顶点 0 为公共锚时，线序为切点 $1,\ldots,M,0$。仅切点 $1\to2,\ldots,M-1\to M$ 需区分，探针 $(0,j)$ 恰对应其中第 $j$ 个。切点 $M$ 与 0 的目标向量都为假，免除了末端不可见的额外需求。原元素和护卫位置可任意指定在这 $M-1$ 个所需边界上。 [Alimonti–Kann 原论文，定理 3.1](https://doi.org/10.1016/S0304-3975(98)00158-3) · [作者书目与原稿](https://www.csc.kth.se/~viggo/papers.php) · [单错报环的坐标构造](interval-fault-plan.md)

对每种原覆盖集合，买一次来源就得到至多三条共锚探针。对每个元素 $u$，加两份分别覆盖 $\{u,g_u\}$ 的来源，以及一份只覆盖护卫 $g_u$ 的来源。所有费用为一。护卫只能由这三份来源区分，容许一次来源错答便迫使三份全买。每个原位置已有两重覆盖，余下问题是原一重覆盖。任一共锚探针都避开目标边。新最优值等于原最优值加 $3n$，故至多放大十倍，因为每份原集合最多覆盖三项。删去所有护卫来源保持解超过最优值的加性差，形成 L 归约。这样，即使来源全部是共锚的星、单位价格，每份来源最多三条比较时也 APX-hard。 [最少顶点覆盖的原始困难性](https://doi.org/10.1016/S0304-3975(98)00158-3)

## 查新边界

已核对的原文覆盖成组耐错距离、测试覆盖、相邻点对的识别码下界、连通同值类、连续一识别、带权匹配及三元素覆盖困难性。待独立核对的新候选，是如何在同一个单错报、共锚来源、禁止直接核实目标的物理差值合同下，证明联合目标只需相邻的异结论边界，并同时实现每份来源两项比较可精确求解、三项比较近似困难的分界。有限查阅尚未定位到相同的物理合同及结论，发表优先权仍待更完整检索。 [上一轮单目标限制](interval-fault-source-bundle-prior.md) · [已知匹配理论](https://arxiv.org/pdf/2305.16889)
