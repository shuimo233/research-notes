# 两种请求共用私有记录时的联合发布

输入冻结为 25 个 BART 公开目录，`denial-odds-policies.json.gz` 的 Git blob 为 `6a2816703f9a7569cce1c98f061fa5bc5fb5321b`。不读取真实时间表。对每个目录，列出每个非锚点事件所参与的证词。按参与条数降序、事件编号升序排列，取首个非空清单及随后首个与之不同的非空清单。两份清单分别对应“给关于该事件的一条真实比较”的请求，允许共用条目。若没有两份不同的清单即报告并跳过。

按上一轮规则为每份清单分别求最低成功率为 $1/2$ 的最优随机策略，单条真比较的概率下限为 $1/(2k)$，$k$ 是该清单的条数。固定逐实况的两份边缘分布，包括拒绝概率。使用同一场景中两次独立抽签所产生的实际最坏联合赔率比 $R_I$ 作为主对照。另记录两份边缘赔率比的较大值 $R_M$。研究只计算同一明确的部分消息或完整消息在允许它的世界间的概率比。

联合策略必须在每个公开可行世界精确保留两份边缘分布。每种兼容输出对的概率不得低于独立策略在它的所有兼容世界中的最低概率的一半。这样，每种本来可兼容的输出对仍然可能。试验上界为 $(R_I+R_M)/2$；当 $R_I>R_M$ 且能达到此上界时记为主改善。另检测是否能达到 $R_M$。对达到的项给出可复算的完整有理数概率表，对无法达到的项给出公开可复算的不可行证书。两个目标相同也只计一次可行性核验。

主判据为至少五个目录达到主改善，且所有目录的两项目标均有可以独立验证的证书。另比较两类较简单的共享随机方案。一个用同一均匀随机数决定是否回答，另一个用互为补数的随机数决定是否回答，两者回答后独立选择各自证词。分别与独立策略各混合一半的概率，保留正概率和规定的概率下限。这些对照不改变主判据。

独立核验从公开差约束重建合法模式和输出对，再在有理数上核对所有边缘概率、联合赔率和证书。受限的网络流归约需要与直接使用各世界联合概率的线性规划在小实例上交叉核验。原型用同一份持久结果服务两种请求，任何一方只获取自己请求的分量；完整结果的保管与对外投递是两个不同角色。实验仅评价同一记录、同一对请求各一次抽样的公开输出。
