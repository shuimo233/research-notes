# 最小错报预算下，温差取值界和补核的先例

## 报告图的已知模型

有向边上的精确差值是整数加法群的 gain。反向边取负值，任一环的定向和为零时，该环平衡。Zaslavsky 的 gain graph 已包含这一表示。Gottstein 与 Zaslavsky 的 Lemma 2.2 与 3.3–3.5 给出平衡子图与各连通分量上的势函数模全局平移的对应。删去最少报告以使剩余报告平衡，就是已知的 Group Feedback Edge Set（GFES）。Guillemot 用这个名称明确给出可以禁止删除某些边的问题。用一条矛盾环作为删边分支的必要集合，直接来自所有不平衡环必须被击中。 [Zaslavsky 1989](https://people.math.binghamton.edu/zaslav/Tpapers/bg1.jctb1989.pdf) · [Gottstein 与 Zaslavsky](https://people.math.binghamton.edu/zaslav/Tpapers/rsb.pdf) · [Guillemot 2011](https://doi.org/10.1016/j.disopt.2010.05.003)

Dabrowski 等的 SODA 2023 / ACM TALG 扩展论文给出更一般的二元线性方程删减算法。论文在相关工作中把 GFES 写为删除最少的 `x·γ=y` 等式，在第 2 节给出边删减的 rooted biased graph cleaning，并用重要平衡子图支配族找可行解。该族保存的是覆盖范围与删边成本的支配关系，论文明确区分这种支配族和全部同成本解。即使只有一条矛盾环，也可能每条边各有一个最小修复。由此不能直接把用于找一个修复的图压缩解释为保持每个定向阈值的所有可能取值。 [Dabrowski 等，SODA 2023](https://epubs.siam.org/doi/10.1137/1.9781611977554.ch121) · [扩展论文第 2.2–2.3 节及定理 5](https://pure.royalholloway.ac.uk/files/67086005/Accepted_Manuscript.pdf)

Arrigoni、Fusiello 等直接把整数节点值、边差、环一致性和 GFES 相连。Chen、Suh 与 Goldsmith 用最小割与信道区分度分析成对测量的唯一恢复。Lerman 与 Shi 的无噪声对抗性污染模型也使用连通的真实好边子图和环一致性，并在特定坏环条件下恢复真值。它们为坏报告模型和路径累加提供了直接技术背景，文中相关结果重点在估计真实解及证明何时能恢复。此处的查询是给定一份可能不唯一的档案，核对所有预算内解在指定差值上的分歧。 [Arrigoni 等，第 1、4–5 节](https://openreview.net/pdf?id=TjIWMgAg5B) · [Chen、Suh 与 Goldsmith](https://arxiv.org/abs/1504.01369) · [Lerman 与 Shi，第 2、3.1 节](https://link.springer.com/article/10.1007/s10208-021-09532-w)

## 同成本修复中的有限取值

记参考势为 $x^0$，报告 $a_e$ 的非零残差为 $d_e=a_e-(x^0_v-x^0_u)$，支持集大小为 $r$。对任一候选修复，若探针的两个端点仍连通，沿其保留边中的简单路径相加，每条参考非零残差边至多被顺向或逆向使用一次。探针值是参考差加上一项 $\sum_{e\in F}\sigma_e d_e$，其中 $\sigma_e\in\{-1,0,1\}$。于是同一个探针在这些修复中至多有 $3^r$ 个值。候选和可能重合，也可能没有可实现的势。要计算可实现的联合探针值，仍须按同一修复核查，尤其不能分别取目标和探针的边际后做笛卡尔积。

在原报告图连通、忽略可信单点区间所得最小错报数恰为预算 $k$ 时，每份预算内修复的保留图连通。否则原图存在一条跨两个保留分量的报告边，平移其中一个分量即可恢复这条边，同时保留其余所有原先相容的边，得到少删一条的纯报告修复。取一个最小修复当参考即有 $r=k$。公开区间只过滤这些候选，不能增加可行差值。因此计数界无需限制绝对读数或区间宽度。这个结论也适用于预算有余量但任一可行修复都令指定探针对连通的情形。纯报告模型里，只要某个允许的修复分离了探针对，两个分量可独立平移，任何整数差值都可行。单边零差报告配预算一已经展示这种边界。在一些预算有余量的实例中，边连通度大于预算即足以排除分离。

串联 $k$ 个仅在连接节点相交的三角形。在第 $i$ 个三角形中，两边路径之和为零，直接边报告为 $2^i$。任一修复要在每个三角形至少删一条；每个三角形删一条足够。首尾探针可独立选零或 $2^i$ 的局部差，因此达到 $2^k$ 个值。故上界的指数依赖有实际必要，尚无依据把底数 3 称为最优。单条错报已有更细的两值结论。 [此前的单条错报与路径结构](interval-fault-cut.md)

从查新的角度，势函数与简单路径求和是既有原理。值得单独核对的是精确差值报告下这个与图大小无关的定量投影界，以及如何将它用于保留阈值与可信补核的联合关系。检索覆盖 gain graph、GFES、balanced subgraph、robust synchronization、sparse outliers、list decoding 和修复可辨识性。已核对的原文没有给出同一个定量界及其补核压缩用途。这个有限检索不足以确立发表优先权。 [GFES 和换势背景](https://openreview.net/pdf?id=TjIWMgAg5B) · [最小修复的既有图压缩](https://pure.royalholloway.ac.uk/files/67086005/Accepted_Manuscript.pdf)

对纯报告问题，可以直接复用 GFES 求解器核对候选列表。对每个候选差值，给两端添加一条该差值的报告边，询问最小错报数是否仍为原来的 $k$。原档案至少耗去 $k$ 个错报，所以在预算内新边必须满足。联合探针可一次加入全部候选等式。原始 GFES 的禁删边也能表达同一要求，适用于预算还有余量的图。因而 $3^k$ 界把纯报告的任意整数探针枚举化为一个有限的判定问题；公开区间仍需独立支持。 [允许禁删边的 GFES 定义](https://doi.org/10.1016/j.disopt.2010.05.003)

## 两条错报与一次补核

当图上最小错报数确为二时，固定一条矛盾环 $C$。任一双边修复至少删去一条 $e\in C$。删除 $e$ 不会断开原图。删后的报告仍不一致，因为否则原图一条错报便可修复。于是每个分支可直接用已核验的单错报路径求剩余可行修复。给定两个探针，各自的两值分组都是该路径上可行位置的一个连续排名区间及其补集。只需检查两区间相交、包含或补集是否有剩余，就能取出这个分支实际可同时出现的值对。这一步不能由两边的边际集合替代。合并所有分支，若同一补核读数无法同时支持目标为真与为假，便得到一次补核保证。路径分支适用于精确到两条的承诺，遇到余量需要另外检查，不能沿用连通性证明。

这一停止判据已有决策区域判定和等价类判定先例。历史诊断文献也利用额外测量筛选多个相容故障解释。把依预算删除报告得到的可行域看作多个差分约束分支，其投影采用时间约束网络的已知做法。两条错报的窄候选是借助单错报区间直接保留同一修复中的数值联动，避免逐个重建候选势，再去核验是否能裁决指定阈值。 [Javdani 等](https://proceedings.mlr.press/v33/javdani14.html) · [Golovin、Krause 与 Ray](https://arxiv.org/abs/1010.3091) · [Reiter 的诊断理论](https://www.cs.ru.nl/~peterl/teaching/KeR/reiter.pdf) · [差分约束与单错报查新](interval-fault-cut-prior.md)

## 用生成树与参考错边导出更紧的界

在纯报告最小错报数等于预算的条件下，取一个最小修复作参考，令 $F$ 为参考错边，$H=G-F$，再固定 $H$ 的生成树 $T$。若参考非零残差的任一非空带符号子集和都不为零，则另一份最小修复保留的参考错边把 $H$ 的若干剩余连通分量连成树。在每个分量内，新旧两势之差是常量。若这些分量之间形成一个环，沿环累加各常量的差即为零，也就构成了一个被排除的带符号子集和。

如果这份修复保留了 $s$ 条参考错边，它恰好从 $H$ 删了 $s$ 条边，上述树有 $s+1$ 个分量。因此从 $H$ 删下的每条边原本都是桥。若某条原本不是桥，先删这一条仍保持连通，再删剩下的 $s-1$ 条，总分量数不可能超过 $s$。桥全在 $T$ 内，故这一修复在 $T+F$ 上仍留下连通的生成树。

给定相同两端点，$T+F$ 的简单路径按路径中包含的参考错边集合唯一确定。两条路径若含有相同的非树边，则它们的边集对称差是完全落在 $T$ 上的偶度子图，只能是空集。这是经典基本环空间的直接用法，给出 $2^k$ 个可能值。前述串联三角形的二次幂差值满足没有非空带符号零和，确立该类的紧界。已知环空间结论计数的是固定图路径。用于所有最小修复的关键条件，还需要上面的分量树论证。已核对的最小删边和成对测量论文没有找到这条条件化的取值紧界。 [Diestel《Graph Theory》第 1.9 节，基本环空间](https://webhomes.maths.ed.ac.uk/~v1ranick/papers/diestel1.pdf) · [已知最小删边算法](https://pure.royalholloway.ac.uk/files/67086005/Accepted_Manuscript.pdf)

对于 $k=2$，两个参考残差绝对值不同时，上述无零和条件成立。绝对值同为 $d>0$ 时，若另一份修复只保留零条或一条参考错边，投影相对参考只可能为 $0$ 或 $\pm d$。若两条都保留，删去两条参考好边后可以有两个或三个分量。两分量情形只有一级非零偏移，仍只产生 $0$ 或 $\pm d$。三分量情形的两条删边都是 $H$ 的桥，修复保留 $T+F$ 的一棵生成树。要取得 $+2d$ 或 $-2d$，路径必经过两条参考错边。给定端点与这两个非树边的集合，路径及其方向是固定的，所以只能实现两个极端中的一个。由此得到统一的四值上界，串联两个三角形即取等。没有找到已发表的同构四值定理。这里的查新覆盖图的基本环计数、双环结构、GFES 和整体恢复；这还不足以确认首次公开。 [基本环空间](https://webhomes.maths.ed.ac.uk/~v1ranick/papers/diestel1.pdf) · [双环图的已知结构](https://onlinelibrary.wiley.com/doi/10.1155/2014/785084)

等幅残差下，固定 $T+F$ 的路径有时会漏掉一个可行差值。取顶点 $0,1,2,3,4$，参考好边 $03,04,12,13,14$ 都报告零，参考错边 $0\to1,0\to2$ 都报告一。两个无共同边的矛盾环 $0,1,3,0$ 与 $0,2,1,4,0$ 证明至少错两条。选 $T=\{03,04,12,13\}$ 后，查询 $x_4-x_0$ 在 $T+F$ 的路径中只得到零，因为 $4$ 通过唯一边 $04$ 接到 $0$。但原图删去 $03,04$ 时，可以取 $x_0=0$ 且其余全为一。此时查询值一成立，且仍恰有两条错报。
