# 两层非对称合同编译核验预案

本预案在完成主预案结果后、运行直接编译器前冻结。主预案的两个采购成本门槛与原记录继续独立报告。这里检验的是求解方法等价性。

- 直接编译器把每对目标标签不同的候选世界写成一组可选的正计数条件，使用现有采购覆盖求解器。
- 在主预案全部 236 个配置上比较逐反例求解、直接编译和独立穷举。等价性门槛是三者的可行性和最优价格在每个配置完全一致。最优组合允许并列。独立核验以枚举每个世界允许的故障集合及其两两并集为依据。
- 在种子 11307 的 120 个生成两层合同上另检验每个差异集合的计数条件，规模为 3 至 8 个源，根与子组容量从 0 至 3 独立取值。要求与故障并集枚举逐集合一致。
- 对每个惰性采购约束检查见证分区、可行性及最大性。复核两个强度不同的保守基线的成本、以及其采购组合是否在真实合同下安全。
- 记录生成的结构化条件数与惰性约束数。两类约束的单次求解成本不同，本轮没有运行时间优越性门槛。
