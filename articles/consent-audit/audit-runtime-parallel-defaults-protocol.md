
# 补充冻结：与原有默认线程设置再做一次测量

在主实验完成后登记。主试验两个会话都关闭了空闲自旋，本补充使用原有的默认四线程会话作为对照。新执行方式保持主试验的均衡任务、单线程会话和四工作线程设置。分别在独立进程加载会话，隔离空闲自旋。两轮交替先后顺序，第一轮先默认对照，第二轮先均衡任务。
