# 一条理由撤回后，推理器还会给出同一个判断吗？

上一轮做 MoNLI 否定句时，遇到一对棘手的词。按器材理解，baseball 是一种 ball。按运动理解，WordNet 也收录了用 ball 指棒球运动的义项，词典里的路径朝向相反。只显示一条证明，读者会以为方向已经确定。换一个问法就可以检验这一区别：让服务保留原判决规则，逐项撤回来源，再看判断能否重放。[WordNet 的词义和指针](https://wordnet.princeton.edu/documentation/wndb5wn) · [上一轮的语境与回退模型](monli-scope.md)

我们先公开选词、计数和失败标准，再枚举词对。取 WordNet 3.0 中按名词义项标注次数排序的前 2,000 个小写英文字母词形，平手按字母顺序。用名词形态还原找到所有候选义项，沿普通上位和实例上位指针查找至少一步的路径。1,999,000 个无序词对共有 34,831 个成立的有向词项关系，其中 208 对在两个方向上都有证据。每对各试两种回退方向，得到 416 项策略。词对没有句子，我们只计算策略行为。另用前次留存的 596 道有金标的实际 MoNLI 否定题和固定模型输出做核对。已知的 ball/baseball 例子在登记时已披露。[查分前的公开方案](https://github.com/shuimo233/research-notes/blob/93c403c0a27100eba4245a62b232a52fd5de3d35/articles/consent-audit/wordnet-conflict-protocol.md) · [原始 MoNLI 任务](https://aclanthology.org/2020.blackboxnlp-1.16/) · [冻结的逐题输入](monli-scope-ledger.tsv)

表中一条边是一个可单独撤回的“子义项 → 父义项”来源指针，同一指针跨题只算一次。第一列边数已经剔除了包含其他证明的冗余路径。假设是每条边都可独立存亡、义项入口固定、新证据不加入。最小值衡量要读取的独立来源状态数；题目索引、常量、规则和回退值仍需随服务存储。[完整计数](wordnet-conflict-results.json) · [208 对词的证明与撤回见证](wordnet-conflict-ledger.jsonl) · [逐题结果](wordnet-conflict-context.tsv)

**双向集合几乎没有压缩空间。** 唯一例外是 man/men。形态还原后，两向极小证明恰好是同一条边。边在时两向都成立，边撤回时两向都消失，两种状态都会回退。其余 207 对的两向极小路径所用的边完全分开，每条都能在某种撤回情形下改变至少一个判断。若打包时只保留支持偏离回退的那一侧，416 项策略中有 414 项甚至在完整词典上的回答就已被改变。预登记要求至少一项策略严格节省，结果只在同一个词形现象的两种回退方向上达到这个门槛。[主集合账本](wordnet-conflict-ledger.jsonl)

**在实际题上，多数词典证明的方向本来就和模型回退相同。** 496 道训练划分的冻结题中，17 道两向都无路径，双向有路径的为零，完整服务答对 494 道。100 道测试划分的冻结题中，两道有双向路径，都涉及 ball/baseball，完整服务答对 100 道。79 个来源位加上逐题规则就能保持 596 道题在每种删边情形下的输出。594/596 是先前服务在完整词典上的正确数；压缩前后相同。对新题、新模型回退或改动后的词义入口，需要重新求依赖。撤回后的答案没有另行标注金标。MoNLI 的构造本身用过 WordNet，这批题也不能单独证明对其他知识库的泛化。[596 题编译包](wordnet-conflict-package.json) · [499 个不同词对的原始证明](wordnet-conflict-context-proofs.jsonl)

## 动手撤回一条证据

在本目录运行以下三条命令即可，服务只需 Python 标准库。第 173 号记录里，两条边都在时答 `forward`。撤回器材义项的边后，只剩运动义项的路径，映射到否定句得到 `reverse`。连运动义项的边也撤回后，服务再度调用已冻结的回退值，答 `forward`。全过程不用下载模型或联网。这使维护者可以核查来源编辑会影响哪些现有接口回答。[运行代码](conflict_package.py) · [逐题记录](wordnet-conflict-context.tsv)

```sh
python -I -B conflict_package.py wordnet-conflict-package.json nmonli_test/173
python -I -B conflict_package.py wordnet-conflict-package.json nmonli_test/173 --withdraw '02799071>02778669'
python -I -B conflict_package.py wordnet-conflict-package.json nmonli_test/173 --withdraw '02799071>02778669' '00474568>00471613'
```

## 怎样知道少一条就不行

把题目和回退固定。设 $X$ 表示至少一条支持改变回答的路径完整，$Y$ 表示至少一条支持回退方向的路径完整。服务恰在 $X\land\neg Y$ 时改变回答。一条边是必需输入，当且仅当存在两个只差这一条边的世界，服务给出的答案不同。任何忽略它的程序都会把这两个世界看成同一输入。反过来，如果某条边在每一种状态都改不了判断，逐个消去这类边就能得到唯一最小来源集合。这是经典的布尔本质变量判据。两向都有证据或都缺证据时折回同一个回答，也有明确的四值信息状态与可废止推理背景。[本质变量与数据库先例](wordnet-conflict-prior.md)

这里还可直接从极小证明给出见证。先取一条支持改变回答的路径 $P$。若它本身已含完整反向路径，它无法单独触发偏离。对余下的 $P$，它的每条边都能在只保留 $P$ 时提供正向见证。对每条反向路径去掉已在 $P$ 中的边，得到一族剩余集合，保留包含意义下极小的那些。任一剩余集合补齐的最后一条边，都能把已经偏离的决定变回回退。两类边取并集即所求。若问从全图出发要撤回几条，则需在保住某个可行 $P$ 的条件下击中每一种反向证明，再对 $P$ 取最小值。路径总数和最小击中集的求解成本可能很大。[完整公式、证明与相邻文献](wordnet-path-algebra-prior.md) · [求解器](conflict_evidence.py)

## 复现与原创性边界
