# 同一采集根可在多处错报时，哪些证据足以区分两个行为

核查日期为 2026-11-23。对照[按证据来源计错的验证口径](source-protocol.md)。情境有稳定的二元真值，健康采集根必须如实报告。至多 f 个根可以任意作答，且历史和未来共用这组根。给同一根的两份导出换名不会新增独立证据。问题是判定真值是否全零，无须指出具体哪个根失信。

**根块距离与“两种世界有共同记录就无法判别”已有直接先例。** Fawzi、Tabuada 与 Diggavi 的命题 2 允许同一组传感器在多个时刻任意失真，把不同时刻的差异传感器取并集，并证明纠正 q 个传感器错误要求该并集大小严格大于 2q。Malkhi 与 Reiter 对屏蔽式拜占庭仲裁系统的 M-Consistency 条件也要求，在两种可容许故障集合的并集之外仍有共同见证者。本次较窄的结果是，**给定精确但可能整体失信的历史，根本不必枚举坏根集合，只需检查单点和历史中报过 1 的根所确定的正支持并集，并且这个与菜单无关的显式候选数界在最坏历史上可取到**。关键特化条件是健康根的每条记录只固定一个坐标，且反方只需有一个 1。[Fawzi 等，命题 2 及其必要性证明](https://arxiv.org/pdf/1205.5073) · [Malkhi 与 Reiter，第 3 节](https://users.ece.cmu.edu/~reiter/papers/1998/DC.pdf)

## 给定两种行为时，如何使用历史中的矛盾

对两个候选真值 x、y，令 Hₓ、Hᵧ 分别为与历史有至少一次矛盾的根集。同一根漏报十次也只占一个根。先排除 |Hₓ|>f 或 |Hᵧ|>f 的候选。令 D 为完整追加菜单里，在任一 x、y 真值不同的坐标有观测的根集。两种候选存在共同的整份菜单答复，当且仅当

```text
|D ∖ (Hₓ ∪ Hᵧ)| ≤ (f − |Hₓ|) + (f − |Hᵧ|).
```

历史已强制失信的根可以在该世界返回任意位。其余差异根，每个都须在至少一边失信；两边尚未使用的额度可以分摊这些根。分摊完后，由双方均健康的根报告共同真值，单方健康的根遵循健康一方，双方都坏的根任取，即得同一未来记录。这个历史版本是对经典块距离证明作强制集合扣减。不能只比较初始额度、只比较两侧剩余额度而忽略已覆盖的差异根，也不能把同一根的多份菜单项计作多根。[Fawzi 等，命题 2 的“分成两个支撑”论证](https://arxiv.org/pdf/1205.5073) · [Malkhi 与 Reiter，M-Consistency](https://users.ece.cmu.edu/~reiter/papers/1998/DC.pdf)

## 全零与“存在一个 1”的一侧枚举

设基线真值全零，A 为历史中至少报过一次 1 的根。若 |A|>f，基线已被历史排除，仍须检查是否至少有一种其他规则与历史相容，才能据此报告存在风险。对仍存活的基线可如下检查完整菜单。

1. 只枚举非零一侧的坏根集 F，|F|≤f。删掉 F 的历史，剩余报告若对同一情境既报 0 又报 1，这个 F 无法解释历史。否则，将剩余报告固定为 1 的情境记作 P，固定为 0 的记作 Z，其余自由。换言之，每一组 F 对应布尔立方体中某些坐标被固定的一张面。历史里的根若自行在同一情境报过两个相反位，它必须属于 F。对于来自不同根的冲突陈述，至少须删去两根之一，这也给出 Reiter 冲突命中解释的直接特例。[Reiter，定理 4.4](https://cse.sc.edu/~mgv/csce580f11/gradPres/reiter-diagnosis.pdf)
2. 候选非空支持 X 要包含 P 并避开 Z。若 P 非空，只试 X=P；若 P 为空，只试未被固定为零的情境各自构成的单点。令 D(X) 为完整菜单中任一 X 内情境可读取的根集。对该 F 和 X，能配对的最小基线坏根集恰为 A∪(D(X)∖F)。其大小不大于 f，就能按上节方法输出两个世界、两边的坏根和逐项相同的完整菜单答复。
3. 此缩减充要。所有 X 都必须包含同一组被强制为 1 的情境，从任何可行 X 删掉自由的 1，只会缩小 D(X)，不会增加基线所需的坏根。完全没有强制 1 时，保留可行 X 中任一元素就够。枚举的坏根集数至多为 Σₖ₌₀ᶠ C(r,k)，其中 r 为不同根数、k≤r。每个 F 至多检查情境数那么多组 X，无须枚举所有真值组合或另枚举基线坏根集。这个界属于**完整菜单的可判定性检查**，不能当作求最优付费树的总时间界。

从决策树角度看，若完整菜单都存在共同答复，则任何自适应顺序只能读到它的前缀或子序列，两种真值始终可沿同一分支。若没有共同答复，全买菜单已足以分类；要给出最小最坏费用，仍须比较首项价格加上可行子分支中的最大剩余费用，直到所有可行解释属于同一类。失信根可在同一树路径内反复给不同结果。把每根预设成永远翻转同一位、或为每次读数重新恢复 f 个可疑根，都改变了这个最优问题。[Cicalese 等，带价分类树](https://proceedings.mlr.press/v32/cicalese14.html) · [Fawzi 等，跨观测共用故障支撑](https://arxiv.org/pdf/1205.5073)

## 进一步免去坏根枚举，及其精确的显式清单界

设域大小为 n，A 是曾在历史中报过 1 的根，Pᵤ 为根 u 报过 1 的情境集合。在全零基线相容时 a=|A|≤f。建立与未来菜单无关的行为候选清单，收录 n 个单点以及 A 的每个非空子集 T 给出的正支持并集 ∪ᵤ∈ᵀ Pᵤ，去掉重复后不超过 **n+2ᵃ−1** 项。对每个候选直接求出与历史矛盾的根，并使用前述根块距离式，就可检查是否有与基线共用完整菜单记录的相反行为。这个上界涉及已经报过正值的根数，其他根再多也不用枚举其故障子集。

证明可从任意非空证人 X 出发。令 Hₓ 是被 X 的历史强制为坏的根。把 Hₓ 外各根的正支持全部取并，记作 Y。若 Y 为空，任选 X 内一个点作为 Y。由 Y⊆X，所有原先健康的根的正记录仍然保留，负记录仍在 Y 之外。因此 Hᵧ⊆Hₓ 且 D(Y)⊆D(X)。沿用原来两种世界的坏根集合，仍然有共同记录，具体记录可按新的 Y 重建；无需与 X 的那一份逐位相同。该推论的对象是**当前历史下存在某个共同结局**。在顺序树上新增读数后，更新后的 A 和 Pᵤ 可能已改变，不能从最初的清单直接删除全树其他真实行为。

**最坏显式清单下界。** 固定 f≥1、n≥2f，取 f 个彼此不交、各含两个情境的块。历史正根 Aᵢ 在且仅在自己的二点块上各报告一个 1，不记录其他位。另备 f+1 个无历史的新根 B。基线必将所有 Aᵢ 判为坏，所有 B 在基线世界都必须报告 0。以下两类菜单共用同一历史，每个都留下唯一非零支持可以匹配基线。

1. 对任一坐标 j，向所有 f+1 个新根查询 j 之外的每个坐标，不查 j。任何包含另一点的 X 都要让全部 f+1 个新根失信才能共用基线读数。单点 {j} 本身可行，至多 f 个历史根与它矛盾。所得 n 个单点各自不可从通用清单中删除。
2. 对任一非空块子集 T，记 t=|T|，在这些块的并集 U 内每一位都查询相同的前 t 个新根，U 外所有坐标查询全部 f+1 根。任何相容非零的 X 都只能在 U 内。只要 X 有一个 1，前 t 个新根就全部须坏。U 外的 f−t 个历史正根也必坏，故预算已耗尽，T 内每个历史正根必须健康。这又强制 U 中每一点均为 1，唯一可能为 X=U；让上述 t 个新根和 f−t 个历史根失信即可实现。各块含两点，2ᶠ−1 个非空并集互异，也都不同于单点。

因此，若清单只能显式列出完整的反方行为支持，必须在读到菜单前一次生成，且对这一历史上的**所有菜单**保留至少一个可行证人，在该构造上恰需 n+2ᶠ−1 个条目。对于给定菜单只需返回其中一个证人。这个下界不限制隐式表示大小、按菜单即时合成证人、运行时间、采购数量或最优付费树深。

数据库溯源文献早已讨论一个结果的替代见证和见证集合，模型诊断也早已有多个最小解释。它们说明“同一结论有多个来源组合”及见证枚举的思想已有先例，但数据库见证通常是能够推导既定查询结果的输入片段；在本题，条目是必须适配未来任意菜单的反方行为真值。安全传感器文献的 2f 块距离涵盖最后的双世界检查，却没有直接给出这份仅由历史正根构成的支持清单。此次检索未发现已对该定义的清单给出上式及匹配的二点块构造。[Buneman、Khanna 与 Tan，Why and Where](https://homepages.inf.ed.ac.uk/opb/papers/ICDT2001.pdf) · [Reiter，诊断和冲突的刻画](https://cse.sc.edu/~mgv/csce580f11/gradPres/reiter-diagnosis.pdf) · [Fawzi 等，命题 2](https://arxiv.org/pdf/1205.5073)

## 单点鉴别不能脱离故障解释单独使用

取 f=1，两个根 A、B 对每个情境分别报 1 和 0。全零世界允许 A 坏，全一世界允许 B 坏；任何既有 0 又有 1 的世界都要求两根同时坏。因而最小存活非零支持可包含全部 n 个情境，n 任意。若追加菜单只来自 A、B，则一份完整共同答复是继续令 A 总报 1、B 总报 0。两组相反行为的坏根不同，且在各自整个历史与未来中保持固定。这示出“先把单点行为全排除，就能认证全零”的失效条件。

也可要求真的有单点留待检查。在前两个情境保留上述冲突，增加无历史记录的第三个情境，仅在此处安排一个新根 C，前两处未来仍只查 A、B。单点 {3} 存活，它与基线都已强制 A 坏，于是 C 在两边都必须健康，查它就能排除一方。单点 {1} 和 {2} 已被历史排除。但非零支持 {1,2} 与全零仍能共享整份菜单，C 在第三处诚实地报告 0。因此“能区分所有存活单点”也不能替代一侧故障集合枚举。这些例子与经典故障解释的观察等价原理一致，体现了按根计错与逐行计错的区别。[Reiter，观察与多故障解释](https://cse.sc.edu/~mgv/csce580f11/gradPres/reiter-diagnosis.pdf) · [Fawzi 等，命题 2](https://arxiv.org/pdf/1205.5073)
