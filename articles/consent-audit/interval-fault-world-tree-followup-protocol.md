# 用贪心采购和任务自身的树作进一步对照

在看到主回放的完整复查成本和求解分支数后、计算下面两项指标前冻结。保持主协议的全部样本、库存、价格和故障合同不变。

**采购对照。** 对所有可判的歧义配置，从全异结论世界对重建不同的极小来源支持集。每步选每单位价格覆盖尚未达要求位置最多的一份来源。并列先选价格低者，再选来源编号小者。得到安全清单后按价格和编号从高到低去掉可删除项。用准确的整数比交叉比较选择，逐项核验最终清单覆盖所有原始异结论世界对。报告精确方案与这一同库存贪心方案的成本、严格节省的配置数及分预算结果。若总节省至少 5%，称达到这一额外基线的成本门槛。主协议门槛仍单列。

**目标自己的树表示。** 即使全部来源没有同答连通树，任务的极小来源支持集仍可能都由某一棵世界树的异结论边重现。对每个极小支持收集所有代表它的异结论世界对。要求从每组取一条，且取出的边不构成环。用图秩条件核对存在性：任意若干组的全部代表边并集，其图秩至少为组数，图秩等于全部世界点数减去连通分量数。记录无同答连通树却有此任务树、以及仍完全无法由树边表示的数量。在冻结的随机小目录上枚举完整生成树，独立核对图秩条件。另检验三个世界各有一个单点识别支路、各世界结论相异时，三项极小支持不能同时出现在同一棵树，但每份来源只出现在两个支持集中，仍可匹配求解。此项为结构解释，并不改变主求解器的合同。
