# 不同价格的顺序试验 · 验证口径

2026-11-23。在实现本轮算法、搜索最优决策树和运行模型试验之前记录。沿用前文的联合读数与跨历史总错误额度。每个菜单项可给出自己的非负整数单价和可用次数，同一精确报价可以有多种单价。一次只采购一份，未使用的容量不收费。宽报价试次只实现区间内一个未知价格。

候选结论：令 R 为全拒绝基线剩余错误额度，q_i 为仍相容单点 i 的剩余额度加一，A_i(k) 为该档最便宜 k 份的总价。令 U_i=A_i(q_i+R)−A_i(q_i)，W_i=A_i(q_i)−A_i(max(q_i−R,0))。猜测最优的最坏费用为各档 A_i(q_i) 之和，再加上按 U_i 降序时最大的 U_i 减去其后所有 W_j 之和。下界沿全拒绝路径选一个单点用完所有剩余错误；上界检查任意分摊错误是否可能更贵。若有反例，保留反例并修正。

独立核验将完整枚举小域所有稳定按价规则、联合读数、有限库存和每一步查询选择，精确比较可行性、根节点费用和工具所选第一步。包括常数单价、同档分层定价、免费及容量不足项、宽区间与历史错读。针对成本优先级让“下一份便宜就先买”和“下一份贵就先测”都可能出错，寻找能让使用者复算的小实例。实用演示复用先前的两个学习器及本地 SQLite 授权回调，试验费用是显式设置的合成预算单位，真实调用和日志分开保存。文献范围包括带谎 OR、加权决策树和调度顺序。未单独核定先例的综合结论只作候选增量。

在首次运行前将演示具体化：三档实际收益取 1、4、8，各有两份独立记录。各档文件尺寸以 64 字节为单位分别取 (1,3)、(2,12)、(5,6)。按清单核对归档的 SHA-256，统计读取的逻辑字节。文件大小是设计参数，读取量可实测。额外做一次树模型中档第一份请求位被翻转的对照，区分原始模型调用、归档里的读数和实际写入效果。此口径不计生成测试夹具和训练的费用。

增项：首次小域决策树核验后，从闭式解推导固定批次与顺序最优的费用比。拟用空历史、只容许一条错误、每档两份廉价记录和一份昂贵记录检查该比值能否逼近仍存活的单点数，同时核查它和已有自适应优势结果的关系。
