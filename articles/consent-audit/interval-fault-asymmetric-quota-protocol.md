# 故障解释不同时，使用不同的故障上限

本协议在运行本轮比较、合成枚举或查看新费用前冻结。沿用上一轮 NOAA 与 BART 的全部紧预算世界、目标、19 个模拟报价及各自机构。天气和计划时刻是真实源数据，原错报、机构归属和价格均模拟。对仍有多种目标向量的配置，分别给每个世界一套故障上限。世界的模式由其最小删除报告序号 i 决定，以 `<档案 ID>/asymmetric/<原预算>/repair/<i>` 的 SHA-256 首字节模 3 分派机构 g。若该世界为真，机构 g 至多错两份，机构 (g+1) mod 3 至多错一份，第三机构答复必须正确。总上限始终为两份。每个来源只可选一次，整个向量可以任意错。该合同是已知的故障假设，不能用来估计真实机构可靠性。

比较三种同库存的固定购买。主方法用逐世界配额的精确树判据。第一对照对每组和每世界对只用两方原始配额之和，要求至少一组的差异数越过该和，独立求其最低价格。它是精确判据的充分条件。第二对照把各组放宽至所有世界在该组的上限最大值，再求精确最低价。未跨配置选价格参数。报告三种可行数和共有可行配置的总价。至少 100 份有歧义的不同档案可在主方法与放宽对照下定案、总价降低至少 10%、全部复算通过，才称相比放宽合同达到预设效用；只有主方法比原始配额相加的对照降价至少 5% 才称树内条件达到其独立门槛。

主求解器从最便宜采购开始。若存在含异结论的共同回复，在现有差异坐标之上扩张出仍可分配给双方的最大包含集合，并加入至少购买一份剩余差异坐标的必要条件。核验器不使用树递推，直接枚举各世界允许的故障集合及异结论两方的两两并集。验证每条必要条件及其故障分配，并枚举所有比输出更便宜的子集。逐世界枚举主方案允许的全部故障位置及其他合法预测值、一个全异代表值，复验只剩一个目标标签。保留整份报价无法保证时的共同回复。报告每种方法的合同差异、松预算排除和没有实际价格意义的模拟边界。

合成部分以 `Random(104751)` 冻结 120 份 3 至 8 来源的同树异价预算。每份从根到两个子组、其中一组再分两支，两世界对同一批组分别赋 0 至 3 的容量。对全部差异子集枚举可分配集合，核对准确区分、成功分配，以及失败时两世界的树内上界证据。另核验原始容量全为正、原始和值逐组均不违约但无法分配的例子；也核验共享相同答复的世界若上限不同，直接拿同答树边缩减会漏掉问题。 [上一轮机构来源口径](interval-fault-laminar-protocol.md)
