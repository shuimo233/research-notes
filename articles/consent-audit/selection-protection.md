# 证词的内容安全，选择证词的规则也安全吗？

发布“事件 A 发生在某个时刻之后”，除了这条比较的字面含义，还可能告诉审阅者：优先级更高的比较都没有成立。一份证词可以单独证明原披露最少，并保留全部线性自由度，但它在公开选择规则下对应的实况范围可能更小。

本轮把选择规则也纳入核验。35 个已知公开信息缺口中，**21 项**可以发布一条由公开规则核验的补充比较，达到预设的 18 项门槛。固定顺序在实际选中的消息里有 **2 项**额外收窄了时间区间，本样本没有观察到新锁死的线性统计量。同一档案合同下的合成反例则确实出现了精确推断。[预登记](https://github.com/shuimo233/research-notes/blob/4e8fd8cc829d2b4bc511e9da29c445d3cb6b0033/articles/consent-audit/selection-protection-protocol.md) · [先例与证明](selection-protection-prior.md)

## 核验输出的全部可能来源

从原先公开域 C 出发，只利用已有的公开不等式找出全部方向上最松的有效分钟格点比较。每条比较必须在某个实况为真，能排除所有更短原证书，且逻辑支持保留 C 的仿射包。等价的比较留一个，得出固定公开目录。更强的同向比较能成立的地方，较松的这个版本也能成立，因此没有遗漏可用的单条补证。

按固定顺序输出第一条真实比较时，第 j 条消息对应的可能实况是 C 与该比较、以及所有更早比较的否定的交集。整数域里，`x[v]−x[u]≥b` 的否定仍是一条差约束，即 `x[v]−x[u]≤b−1`。可以直接用原始不等式重算该消息对应的区域，判断某个时间差是否被新确定。

在文章的六目标例子里，两条分别说明 `x≥1` 或 `y≥1` 的证词各自都充分，并且都让 x 和 y 保有多个可能值。但任一固定优先顺序的第二条消息都会额外表明另一条为假，从而锁定其中一个值。选择规则与证词内容必须一起核验。[同合同反例脚本](selection_protection_boundary_check.py) · [拒绝消息泄露先例](https://theory.stanford.edu/~nmishra/Papers/denialsLeakInformation.pdf)

## 两种可公开验算的确定性规则

**如果能重排优先级，就从最后一条开始选择。** 在尚未排序的目录中，某条消息可以放最后，恰好当它独自成立、其余全不成立时，仍保留原仿射包。若一个安全顺序存在，把任何符合此条件的标签移到最后，其他标签的实况范围只会扩大。重复选择即可找出有效顺序。若没有任何候选，当前剩余集合已构成无解依据。对 k 个标签至多检查 O(k²) 个独占区域。

**允许一般确定性规则时，可以给每条消息预留一组公开构造的假想记录。** 设原公开域的仿射维数是 d。每条消息应拿到 d+1 份仿射无关的合法记录，各组不得重合。这是必要的，因为每个成功输出在其逆像中都得有一个基。它也充分：遇到这些预留记录就采用指定消息，其余情况选第一条真实比较。第三方只需确认每组记录合规、互斥并且达到所需仿射秩，就能核验整个规则的精确线性保护。

即使公开域可能含指数多个整数记录，也可以建立多项式大小的候选池。设所有标签总共要预留 K 个记录。对每个标签反复提取 K 组互不重合的仿射基。若一个完整分配里有一份未进入候选池的记录，它仍位于这 K 组基的各自张成空间内。其余 K−1 份已用记录至多碰到 K−1 组，剩下一组可以提供一个独立替代。用坐标前缀把有限排除集合的补集切成多个盒，再与差约束区域求交，就能在每片上提取仿射基。最后用标准拟阵算法求解有限分配。[抽取、换元和原始文献](selection-protection-prior.md) · [可运行实现](selection_packing.py)

## 随机选择的保证

在所有真实目录消息中做一次均匀选择，任何满足某条消息的实况都有正概率发布它。收到该消息后的可能实况恰好就是该比较的逻辑支持。这可以保留完整支持，但选择概率仍随真实消息数变化。在上述两条消息的例子，重叠区域的发布概率是单独成立区域的一半。工具把一次选择缓存为可复用的发布结果。这里分析单次消息的可能实况，以及同一缓存的重复读取。[粗化数据的概率先例](https://arxiv.org/abs/cs/0306124)

## 使用与复算

Python 3.13，在本文目录运行。第一条只读公开材料。第二条由保管方在本地用一个 JSON 数组内的真实整数记录生成发布结果，参考位置 0 取零。同一公开场景重复发布使用同一个缓存路径。方法可以是 `bases`、`priority` 或 `random`。

```text
python -I -B selection_protection_inquiry.py check selection-protection-packets.json.gz
python -I -B selection_protection_inquiry.py publish selection-protection-packets.json.gz --record actual.json --release-file release.json
python -I -B selection_protection_run.py . reproduced
python -I -B selection_protection_check.py . reproduced
python -I -B selection_protection_boundary_check.py
```

隐含讯号、粗化机制和拟阵算法已有先例。当前候选贡献限定于最少原始披露的时间差审计合同、完整的输出逆像核验，以及在无需枚举所有整数实况时得出确定性发布的可核验分配。真实评估使用此前选定的条件样本，首创性仍待独立核查。[原始文献对照](selection-protection-prior.md)
