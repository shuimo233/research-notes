# 中英复核前冻结的实现与开发集更正

英德开发集中，全体 14,180 个片段都有三位评审。其中 583 个片段的实际行表不满足本工具的严格合同。160 个片段有一人超过五条，425 个片段有 No-error 与该人的其他行并存，两项会重叠。这是对已发布行表的观察，原因未经调查。严格合同将 No-error 视作独占行；论文明确写了 Non-translation 的独占要求，以及最多五个译文错误的要求。为保留原始记录，加了回退模式。该模式对三份非空打分单取消五条及标记独占约束，仍要求每个类型的行数和不同人数准确；补充编号按放宽模型重新计算。回退标记占用的 JSON 字节计入边际表。严格分析和回退计数分别报告。

截至本次代码冻结，已在英德文件核对全部官方均分，已从写盘档案回读 14,180 份多数打分；两份中英文件已下载并核实 blob，均分表的表头与覆盖已知，尚未运行中英多数和码长分析。将以本次提交中的实现直接计算中英结果。主表中的 No-error 行保留为一个无支持票的记录；没有评审多数语义的原始标量分仍用作对照。自然碰撞优先报告在同一系统中出现的两段；最强边际碰撞若跨系统，会在结果中明示。
