
# 冻结协议：分组共用运行档位能否在更严的审计下减少配置数？

沿用 2,508 个 MoNLI 目录和门槛组合。逐项的真实模型分数、目录及两实况门控、漂移证书分别固定为 Git 对象 e1002444bf4be9c91336a33b4c58358d6f48645c、30ce968781a96a0fd4542987de68778d2f9dd914、7ab8549962cc6f4af64229a9fd9f44682f89c754。两实况在运行时共用同一档位分布。参考标注用于核对本实验的合法答复。

## 候选策略与比较

一半批次仍逐项独立抽档。其余批次采用提前定下的请求分区，同一组共用一档，不同组独立抽档。每个所用档位都使用同一未知但固定的档位分布。允许比较固定概率混合的各种分区，分区抽签不能依赖本次档位分布或实况。保留完整的独立概率地板和每项档位边缘。要求在所有可能档位分布下，两个实况在每个窗口的全拒绝归一倍率相等。

主指标是八档等权时每批使用的不同配置种数期望。普通对照为逐项独立。较强对照为上轮只在整批共用一档与逐项独立之间抽签的策略，允许 5% 的双向归一偏差，并在较窄的上轮漂移集合内核验。用上轮夹逼界计算对照的成本区间。只有新策略的成本严格低于对照的成本下界，才计为已证省配置。新策略的成本严格高于对照的成本上界时计为对照更省，其余分别记作精确相等或尚无法区分。主要目录和压力目录都报告全部配置，主目录至少出现一项已证优于较强对照才算通过效果门槛。

## 独立复核和执行

每个目录发布一个可执行分区与一个同样大小的两两冲突请求集合。独立检查器从原始门控验证全部二项冲突、分区合法性和下界见证，回放被拒绝的篡改证书。用原子分布的有理数构造复核不同请求数、模式数和不等率值，以及比例相同但绝对拒绝率不同的输入。

端到端运行预先固定为主目录记录 1044 与 1168。每例分别试等权档位和其上一轮证书见证的档位分布，比较全独立、采用上轮安全共享下端的整批共用策略和新分组策略。每个组合用固定种子 10441168 顺序抽 24 个批次，两个实况复用档位向量以成对核对模型分数。逐项执行同一固定 ONNX 模型，验证所有输出分数的位模式与冻结档案一致，再按原先的参考标注门控和独立分支抽签做出答复或拒绝。记录每批使用的档位向量、配置种数、两个实况的拒绝位和重放摘要。配置种数仅计预设档位，不作为运行时间的测量。样本运行用于验证实现，精确概率保证来自证书。
