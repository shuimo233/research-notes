# 只留旧报告时，哪些读数必须重查？

一份旧报告只保留了观测区间和分类结果，后来阈值改了。可能有许多组原始值符合旧报告。一个区别是否重要，取决于它能否改变我们要回答的命题。这里把这句话变成可检验的问题：在看到追加读数前，找出对所有这些实况都有效的最小重读名单。输入是有界整数差分约束，新报告由若干两点差值的标签组成。输出是精确读数名单和可复核的标签。

**结论是只读新版仍有歧义的关系的端点，但要先合并固定偏移的点。** 若旧报告总能推出两个位置的差值固定，只需读取其中一个。若某组和已知原点保持固定偏移，它的值已经确定。把剩下每条歧义关系的端点组取并集，每组读一个，就得到最小固定名单。每个这样的端点组都存在一对实况作为反例，仅改变这一组就能改变报告。因此名单在组件层面唯一。

## 为什么两个端点都可能需要

将约束 `x[v] − x[u] ≤ c` 表示为有向边 `u → v`，权重为 `c`。最短路闭包 `D[u,v]` 给出差值的最大值，整个可达整数区间是 `[−D[v,u], D[u,v]]`。差值范围为单点的变量可以按其已知偏移聚在一组。收缩后，每条经过多个组的简单有向环权重都至少为一。否则零权环上的每个不等式在所有解里都取等号，环上的点已经属于同一组。这些性质来自整数差分约束和简单时间网络的已有工作。[Dechter、Meiri 与 Pearl](https://ics.uci.edu/~csp/r10.pdf) · [Knauer §1.4](https://pageperso.lis-lab.fr/~kolja.knauer/knauer_kolja.pdf)

设新标签基于 `x[v] − x[u]`，相邻两个可达差值 `k` 与 `k+1` 的标签不同。取 `v` 所在的非固定组，把所有进入该组的边权减一。这表示给该组预留整体加一的空间。简单环最多经过一次该组，因此收紧后仍无负环。每条从 `u` 到 `v` 的简单路径恰好经过一个收紧的入边，从 `v` 到 `u` 的简单路径则没有。因此在收紧后的网络中，差值区间从 `[L,U]` 变为 `[L,U−1]`，仍包含 `k`。选一个取值为 `k` 的整数解，再把 `v` 组增加一，就得到两份符合原档案的实况。它们只有这一组不同，新标签却不同。交换两端可为 `u` 的非固定组构造相同的见证。

每个固定方案都必须覆盖这些反例。读取名单上的全部组后，每条关系要么原本就确定，要么两端已确定，故名单充分。闭包需要 `O(n³)` 次距离更新；接下来只需检查固定偏移和差值区间。阈值标签适用这个结论；对于任意有限差值标签，只需能检查它在其中是否恒定。若读取价格因位置而异且可相加，各组选最便宜的代表即可。

这项保证适用于旧报告产生的单一整数差分网络。比如二元值满足 `|x−y|=1` 时，支持只有 `(0,1)`、`(1,0)` 两点，知道任一值就能判断差值的方向。这类析取约束超出定理范围。允许先读后决定后续位置时，最小固定名单也是预算上界。对构造的 `m` 项阈值任务，固定方案需读 `m` 项，先读共享参照值后至多再读一项。参照值本身没有出现在新版标签中。[构造与穷举脚本](conclusion_replay_check.py)

## 在 NOAA 历史温度上的回放

按[冻结协议](https://github.com/shuimo233/research-notes/blob/c93c324612b07ea87addf5ef87aa457169a672ca/articles/consent-audit/conclusion-replay-protocol.md)，两组各五个 NOAA 站点共 725 个合格的地区日期。先提供粗区间和六条 1.0°C 容差的旧报告，再生成包含全部十对站点的新报告。分别测试 0.8°C 和 1.2°C，两种版本共 1,450 份。这里用真实观测模拟历史报告和按需访问，两个新版阈值是事前规定的实验设置。[站点来源和快照](station-tmax-2025-sources.json)

| 方法 | 0.8°C | 1.2°C | 合计读取 |
| --- | ---: | ---: | ---: |
| 读所有位置 | 3,625 | 3,625 | 7,250 |
| 从粗区间重新做 | 3,302 | 3,401 | 6,703 |
| 单独应用各边的旧标签 | 2,983 | 3,183 | 6,166 |
| 使用完整旧报告的最小固定集合 | 2,923 | 3,161 | 6,084 |
| 仅在最坏预算会下降时先选一次探查 | 2,908 | 3,098 | 6,006 |
| 事后知道真值才能取得的最短证书 | 2,460 | 2,598 | 5,058 |

固定方案比从区间重做少读 619 次，比逐边方法少读 82 次。相对逐边方法的 1.33% 降幅低于事前设定的 5%。允许一次探查后，有 54 份报告的最坏预算进一步下降，合计实际又少读 78 次。读取次数衡量原始值调用，耗时和人员成本未测量。[逐报告记录](conclusion-replay-ledger.jsonl.gz) · [计数](conclusion-replay-results.json)

独立程序从冻结的原始温度和中位数重建旧档案，在两份约束网络里分别强制某个阈值的两侧。它核对了全部 14,500 个答案、1,450 组最优固定集合和 6,084 个漏读见证，以及事后证书的最小性与自适应的最坏预算。另对 350 个小幅整数网络和 2,232 个读数分支直接枚举可行实况。核验包括负温度、刚性偏移、违反归档的精确值和自相矛盾的档案。[独立核验器](conclusion_replay_check.py)

## 与已有研究的关系及使用方式

实例级查询决定性已覆盖用历史结果约束新答案的通用问题，独立区间排序也已有固定方案需读不确定两端的结论。这里可单独查新的命题是：在**相关的整数差分约束**下，任一可跨越的新阈值都能在两个非固定端点组各自构造只动一组的见证。它把固定名单从组合搜索化为一次闭包。检索找到了上述直接构件，尚未定位把这些构件用于这一精确输出合同的原论文。首创性仍待更广的查新和独立审阅。[查新说明与第二份证明](conclusion-replay-prior.md) · [实例级查询决定性](https://homes.cs.washington.edu/~magda/papers/koutris-jacm15.pdf) · [独立区间排序](https://arxiv.org/pdf/2012.09475#page=6)

在本文目录用 Python 3.13 运行。回放的输出目录需要是新目录。

```text
python -I -B conclusion_replay_run.py station-tmax-through-2025.csv.gz reproduced
python -I -B conclusion_replay_check.py station-tmax-through-2025.csv.gz reproduced
python -I -B conclusion_replay_inquiry.py conclusion-replay-example.json --probe --ask
```

[交互样例](conclusion-replay-example.json)是四个位置的合成输入。依次输入 `1` 和 `2` 就可以用两次查询确定三个标签。真实任务使用相同输入结构。`bands` 是各位置的闭整数区间，位置从 1 开始，0 为已知原点。`bounds` 每项依次给出 `u, v, 下界, 上界`，约束 `x[v] − x[u]`。`targets` 每项给出 `u, v, 递增阈值列表`，标签是达到的阈值个数。默认计算最小固定名单，`--probe` 会枚举首问的所有整数回答来比较最坏预算。成功返回时，每条标签都带有追加读取后的精确差值区间。
