# 三条回复合看时，还能保住每一对的最优保证吗？

在三条真证词都可能分别出现或不出现的情况下，答案取决于怎么分配保护。**若每两条合看的赔率倍率都不能超过它们各自的最优值 3，三条合看的最佳倍率就是 5。** 如果允许两条合看的界略微放宽，三条合看可以降到 $32/7$。在事先登记的 CI 和 BART 档案试验中，149 个可评分案例有 131 个面临这一取舍。 [事前协议](https://github.com/shuimo233/research-notes/blob/85cdbe8c2143a238d3d1cbd186668933f3c21fcd/articles/consent-audit/multi-odds-protocol.md) · [逐项证书](multi-odds-policies.json.gz)

## 真实性、服务与观察窗口

每个请求只有一条证词。证词为真时，以 $1/2$ 的概率发布；否则必定输出“未发布”。一次为所有请求抽出完整回复。读者可以看到其中任意固定子集。对同一明确可见消息，只比较仍允许它的实况。我们要求每种完整合法回复的概率至少为该实况独立抽签时的一半。这样，原来在语义上相容的配对不会因为修改抽签规则而变成零概率。

令 $B$ 为每两条合看的倍率上限。三条证词的真假如果能构成全部八种状态，最小的三条合看倍率为

$$
R_3(B)=\max\left\{\frac{32}{7},\ 4+\frac{2}{B},\ \frac{B+2}{B-2}\right\},\qquad B\ge3.
$$

$B<3$ 时连其中一对的要求都不可行。$B=3$ 时完整界为 5，$B\ge 7/2$ 时可降到 $32/7$。因此在三种观察窗口上分别优化，再要求所有最优值同时兑现，可能导致根本不存在合规的发布策略。

证明可对三个请求的所有排列平均。给定倍率时，概率比约束可写成线性不等式，所以平均保持服务、地板和各窗口的倍率。记双真状态的具体成功子集概率按成功数为 $(t,1/2-t,t)$，三真状态为 $(u,v,w,z)$。单项服务给出 $u=1/2-2v-w$。比较全拒绝、单成功和双成功在相容世界中的概率，可得 $u\ge1/R$、$v\ge1/(2R)$、$w\ge t/R$；下限还规定 $w\ge1/16$。两条合看给出 $t\ge1/B$、$u+v=1/2-v-w\ge1/B$。相加这些不等式得到公式的三项下界。取 $b=\min(B,7/2)$、$t=1/b$、$v=1/(2R)$、$w=t/R$，由服务和总概率重建 $u,z$，即可达到该值。[可执行闭式](multi_odds.py) · [边界与复算](multi_odds_boundary_check.py)

## 请求更多时，独立抽签的增长率可以降低

令 $R_n^*$ 表示完整真假组合下，**同一个界同时保护任意固定可见子集**的最小倍率。保持此前的服务率和半独立概率地板，有

$$
\tfrac12(3/2)^n\le R_n^*\le4(3/2)^n.
$$

下界可以只比较完整回复。任一成功集合 $A$ 在“恰好这些证词为真”的实况中，概率至少为 $2^{-|A|-1}$。在“所有证词都为真”的实况中，仍须至少给它 $2^{-|A|-1}/R$。对所有 $A$ 相加得下界。

上界用三种机制混合。以一半概率独立投公平硬币，以四分之一概率让每条真证词独立以 $1/3$ 的概率发布，剩下四分之一均匀抽取约三分之二的真证词。最后一项用随机取整保持精确均值。如果有 $t$ 条真证词，抽取数的期望是 $2t/3$，故单条真证词仍恰好有一半机会发布。公平硬币分支保留全部规定的概率地板。

这个混合使含 $a$ 个成功的任一完整合法回复概率至多为 $2^{-a}$。其中均匀抽取分支的单格界为 $(4/3)2^{-a}$，可把 $t$ 分成 9 的倍数和余数，用 $\binom{9}{6}\ge2^6$ 与九个余数直接验证。若看到的窗口有 $k$ 条请求，对隐藏成功集求和后，上界为 $2^{-a}(3/2)^{n-k}$。而 $1/3$ 抽签分支总给相容的可见消息至少 $(1/4)2^{-a}(2/3)^k$。相除即得上界，所有窗口用同一次抽样。

因此可达的增长率是 $3/2$；独立抽签的最坏比率是 $2^n$。该构造是一般规模的保证，小规模仍可采用精确闭式。若希望同一族发布器在任意规模上都按可见窗口自身的大小计费，则在两条合看的上限为 $3\le B\le4$ 时，大窗口的指数底数下确界为 $1/2+4/B$。从允许两条合看为 4 收紧到它的最优值 3，会把这个底数从 $3/2$ 推高到 $11/6$。这些下确界都可以逼近，各自无法由单一可扩展的策略族达到。代码提供有理的共同偏置分布，用于生成逼近该界并维持两条保护的策略。 [完整证明与原始文献](multi-odds-prior.md)

## 复算

```bash
python -B multi_odds_run.py public-optimality-packets.json.gz transit-optimality-packets.json.gz replay
python -I -B multi_odds_check.py public-optimality-packets.json.gz transit-optimality-packets.json.gz replay
python -B multi_odds_boundary_check.py --public-ci public-optimality-packets.json.gz replay/multi-odds-policies.json.gz
python -I -B multi_odds_inquiry.py check CI public-optimality-packets.json.gz multi-odds-policies.json.gz --index 8 --ratio 5 --lock
```

生成概率表使用 Python 3.13 与 SciPy 1.16.3。独立核验和发布抽样只用 Python 标准库。边界程序用直接概率约束交叉检查三请求闭式，并逐个窗口核对了最多 64 条请求的三种机制混合。

保管方可将最后一条命令的 `check` 改为 `publish`，并传入 `--record local-timestamps.json --sealed-file private-transcript.json --visible 3`。这里 `3` 的二进制位选择前两个请求，`6` 选择后两个。对同一场景使用同一份私有结果文件和配置，程序仅输出所选窗口。测试验证重叠窗口来自同一次抽样。

相关抽签、多份发布的联合保护和固定边缘的经典耦合已有原始研究。这里的增量是对真证词、可见拒绝和保留正概率的联合合同，分别给出可核验的三请求最优边界、多请求增长率，以及两个真实档案域的对照。结论限于明示的可见消息和可行世界。 [无损多次发布](https://proceedings.mlr.press/v267/andersson25a.html) · [原始论文核对](multi-odds-prior.md)
