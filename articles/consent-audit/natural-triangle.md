# 自然句里真的有值得随机延后一个词的情形吗？

上轮的 99 个自然句，保持原来的固定询问方案就能达到最优。我们又在词典中找到了会从随机询问获益的词组。本次问得更具体：在原段落里自然共现的三个多义名词，如果任务确实要求判定全部三对词的关系，这种情形是否出现？SemCor 有两个新句子提供了正例。它们依赖均匀义项边际；用历史词义频数重新计算后，两个例子的优势都消失了。[上轮结果](mixed-cover.md) · [评分前发布的协议](https://github.com/shuimo233/research-notes/blob/7ef1c9d1ae23655098d63657f45838e41266ed66/articles/consent-audit/natural-triangle-protocol.md)

## 自然出现的两组三词

其中一句含有 angel、being、person。系统要答出三对词分别为同义、左词更具体、右词更具体或没有上述关系。若每词的词典候选义项等概率，只知道三个边际，不假设同句词义独立，最好的固定首问方案最坏期望要问 $17/6$ 次。均匀抽一个词延后，最坏期望降到 $25/9$，每组差 $1/18$ 次。另一个句子里 being、person、woods 有相同的数值；person 在句中出现两次，因此产生两组位置实例。[全部位置、金标义项和答案](natural-triangle-cases.jsonl)

这两个例子恰好能直接代入此前的异质边际公式。对各词每个义项逐格检查，已知一个词的义项后，它或者会触发另外两个词的补问，或者两个都不触发。两个可能触发的词的边际各为 $1/2$，person 为 $1/3$。因此可以把多值词义压缩为三枚活跃位，保留整个询问成本表。金标回放中，angel 组的抽签期望为 $8/3$ 次，预定固定策略为 3 次。另两组金标都是 3 次。有限次金标回放无法给出实际部署收益率。[之前推导的公式](mixed-cover-prior.md) · [每种词组的策略和证书](natural-triangle-plans.jsonl)

## 检查了哪些句子

## 换用标注频数，策略会改变

看到结果后，我们对实际出现优势的两个词条组做了敏感性检查。从 WordNet 3.0 的 `index.sense` 读取义项标注计数，分别用原始频率和每个候选义项加一次计数后的频率求解。保留所有零频候选的语义可能性。两种输入都使固定策略达到最优。以 angel 组为例，原始频率给出的活跃概率是 $0,1/3,6833/6834$，固定与混合都需 $7/3$ 次；加一后两者都是 $151/60$。这里只对已筛出的两个正例测量主张对边际的依赖性，无法回答其他词组在新边际下是否会获益。频数取自历史标注，缺乏针对新应用的校准。[逐义项频数与成本](natural-triangle-sensitivity.json) · [词典计数含义](https://wordnet.princeton.edu/documentation/senseidx5wn)

## 核验与复现

独立实现使用 NLTK 的词义键映射和上位路径。它重读两套原始语料，以信息性词对连接成三角形，核对每一条位置记录、答案和询问数。635 个不同词条组的共同对手分布须满足每词完整边际；每组的抽签策略和逐世界价格上界须符合全部约束。另用两个已问位置的事件并集锐界核验固定方案的最优值。命令在本文目录运行。所用数据版本、来源和下载方式见前篇。[独立核验器](natural_triangle_check.py) · [WSD 数据与版本](wsd-clarification.md) · [SemCor 数据与版本](semcor-clarification.md)

```sh
python natural_triangle.py wordnet.zip semcor.zip wsd-directory rebuilt
python natural_triangle_check.py wordnet.zip semcor.zip wsd-directory rebuilt
python natural_triangle_sensitivity.py wordnet.zip rebuilt/natural-triangle-plans.jsonl --output rebuilt/natural-triangle-sensitivity.json
```

对框架设计的含义是，随机询问可以作为指定边际下可验证的一种策略。要部署它，既要检查关系表是否保留了推导所需的触发结构，也要核验工作环境中的义项概率。该实验提供了一个自然发生、可以逐项复算的机制实例。跨语料的效果和对真实工作量的改善仍待验证。[相关工作与优先权边界](mixed-cover-prior.md)
