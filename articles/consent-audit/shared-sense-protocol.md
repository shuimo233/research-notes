# 同一句话同时回答多个关系问题，一次词义询问可以被用几次？

本轮的两份材料都已做过逐词对分析。外部 WSD 中有两次 group/team 查询涉及同一个 group 词元，这个例子已经看过。在计算任何按句共享的计数之前登记。采用已有的验证查询与最小顶点覆盖方法；其在带不确定性的排序中已有直接先例。[排序查询的核验证书](https://arxiv.org/abs/2012.09475) · [外部逐对结果](wsd-clarification.md) · [SemCor 逐对结果](semcor-clarification.md)

**问题和代价。** 每个词元的名词义项在一句话中固定，可从其冻结词典候选中任取。一次付费揭示一个词元准确义项，同句所有关系查询均可复用。不同位置即使同词也分别计数。目标是同时返回全部词对的四类关系，提前停止必须对所有剩余解释正确。输入仅由词元、候选表和待答关系构成，规划时不提供词义金标。

**主集和迁移。** 主集取已发布 WSD 广集合中两端均有唯一金标的 324 处位置组合。迁移集取之前 SemCor 的位置组合，限定两端在 WordNet 均有至少两个名词义项。各自按句组包。主要比较只计同句至少两条查询共享至少一个词元的包；另列全部句子。主集和迁移集分报。多金标样本的联合义项选择留待单独验证。

**在线方案。** 对每个包依次比较：①每个词对各自独立执行先前关系表策略。②在处理下一个词对前使用所有已知词义，缓存同一个位置，按两端词元 ID 排序后的边顺序及逆序，分别搭配先前的关系表顺序和多义优先，构成四个强对照。③每一步选择预计能立即确定最多未决关系的词元，各自候选义项等权，平手选未决边数多者，再按位置 ID。④在初始非恒定关系图上求最小顶点覆盖，平手按顶点 ID 元组字典序；先在该覆盖里逐步用③的规则选未决词元，再补全覆盖之外仍然必需的端点。两端本来就已多义，不单列免费单义输入。

**下界和检验。** 在实际义项已知的事后分析中，将无单端证书的非恒定关系的两端强制；唯一一端可认证时强制那一端；两端都可单独认证时留下二选一的边。对未被强制端点覆盖的边求最小顶点覆盖。该值是准确回答整包的逐实例最短证书。用另一个实现穷举词元子集，检查证书最短性、所有交互轨迹的合法停止和最终结果。报告全部策略费用、事后下界与覆盖策略的两倍界。仅当主集中④的总询问数严格小于四个带缓存对照的最低总数且全部答案正确，才记为覆盖排程有额外收益。公布迁移成功或失败、共享缓存的单独收益以及所用的计量单位。
