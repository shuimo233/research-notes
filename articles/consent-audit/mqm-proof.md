# 三位评审对任意类别并集的多数查询

## 问题与等价关系

一份译文有三张非空评审单。Bᵢ 是第 i 张单上的类型多重集，每个类型由严重度与叶级类别组成。公开信息 M 给出每个出现类型 t 的总行数 kₜ 和不同报告人数 dₜ。无错占位 N 计入 M，查询不得选它。对任意查询类型集合 S，需要恢复

> Q(S) = 1，当且仅当至少两个 i 满足 Bᵢ 与 S 有交集。

同一人可以写多行，但对一个查询只贡献一票。查询忽略错误的文本跨度和行序，也不要求两人标到相同位置。严格模式要求每人至多 C 行、无错占位和整段非翻译标记各自只能独占其所在打分单。实测取 C=5。回退的宽松合同保留三人非空、M 准确这两个条件。上游把源文错误另表发布，本实验用译文主表。[WMT 协议](https://aclanthology.org/2021.tacl-1.87/) · [数据口径](mqm-protocol.md)

将 dₜ≥2 的可选类型放入 H，将 dₜ=1 的可选类型放入 L。按每个 L 元素的唯一报告者把 L 分为最多三块，记为 π。对任意 S，Q(S) 为真当且仅当 S 接触 H，或者 S 与 π 的至少两块相交。有 H 命中时至少两人已投票；否则各块各代表一个人。这直接给出充分性。

固定 M 时 H、L 都已知。两种不同的 L 分区必在某两个元素同块与否上不同，选这两个元素就得到相反的答案。L 只有零个或一个元素时只有一种分区。因此不同查询函数与可实现的无名分区一一对应。若同时发布的模式限定了允许的原表，也必须把该限定加入“可实现”的定义。单类和双类查询已经足以区分函数，这是实盘核对能够覆盖任意并集的原因。[单人与两人查询回放](mqm_receipt.py)

## 计数、排名和最短逐段字段

令 F(M) 是在选定模式下至少能由一种评审表实现的分区数。每段独立设定一个固定宽度的字段，编码和解码双方都知道 M、模式及查询语义。字段少于 ⌈log₂ F(M)⌉ 位时，至少两个可区分函数共用一码，它们的见证查询必有一个答错。按确定顺序给每个可行分区编号，即可恰好使用这一宽度。F=1 时用零位。此下界允许保留整个函数所需的最少逐段信息；联合压缩多段、带外字段、变长码和真实分布下的平均码长各有不同成本口径。[Cover 的枚举编码](https://isl.stanford.edu/~cover/papers/transIT/0073cove.pdf)

实际计数先按类型排序，第一次遇到的持有人编号为 0，第二个新持有人编号为 1，依次类推。每个分区因此有唯一的标准序列。递归把 L 中每个 t 的 kₜ 行全部放进对应席位，普通行消耗 kₜ 容量，独占标记要求 kₜ=1 且占满该席。到叶节点后，余下类型逐一枚举三个席位的行数分配，总数必须为 kₜ，恰有 dₜ 个席位取正数。独占标记的每个正席各只有这一行；其他类型仍受剩余容量限制。最终三席均非空则该分区可行。余下填写取“存在”，同一分区只记一次；前缀计数按分支相加。每张合法表会经过其对应分区及某条可行填写路径，反过来每条通过的路径都能构成合法三人表。顺序累加较小分支的状态数即排名，逆操作即解码。这是受约束投影计数和枚举编码的一个具体应用。[投影模型计数](https://arxiv.org/abs/1507.07648) · [实现](mqm_receipt.py)

取消容量及独占约束时，余下类型只需能覆盖空席。若已有 r 个席位持有 L 中的类型，余下类型的不同报告人数之和必须至少等于 3−r。该条件也充分，因为每一类型的 dₜ≤3，可以先用它的报告者名额覆盖尚空的席位，余下名额放在该类型尚未使用的其他席位，多余行任意放进已经使用的席位。完全忽略边际可行性的对照则只数 m=|L| 个元素分入最多三块的方法，m=0 时为 1，m≥1 时为 (3ᵐ+3)/6。后式可由三席置换的固定点计数得到。

## 标记本身也可能携带信息

冻结接口允许调用者为任意记录选择宽松模式，因此它忠实地为整个宽松空间排名。本次 WMT 导出器实际只在至少一人超出 C 行、或独占标记与另一行同在一张打分单时开启回退。若解码器知道这一更强的承诺，宽松空间中的某些函数可能只由完全合规的表产生，因而可以再剔除。直接从宽松状态数减去严格状态数也做不到这一点，同一个函数可能同时有合规和不合规的实现。

事后实现为每个候选分区选一个违规见证席。已定归属的单人类型确定三席初始占用、见证席的行数和是否含独占标记。对其余每个类型枚举三席分配；只记录哪些席位至少被填过、见证席收到的行数（超过 C 后截为 C+1），以及它是否收到独占标记。末态需使三席均非空，且见证席超过容量或有至少两行并含独占标记。所有可能的违规表都有一个这样的见证，任何通过的分配也确实生成一张违规表。对三个席位取“存在”，保留可行的旧编号并按序重新排名。在 1,910 张小域无名原表上逐表生成八个并集的真值，655 种边际对应的函数集合与此算法逐一吻合，包括没有任何违规实现的边际。[精确标记程序](mqm_flag.py) · [穷举和实测结果](mqm-flag-results.json)

## 只知行数时，主问题还有解析界

假设没有 dₜ，掌握每类行数、三席都非空、严格容量与独占规则。先给每条独占行单独留席。令 P 是其中选中的行数，Z 是未选中的行数，u=3−P−Z 是普通空席数，p 和 n 是所有普通行中被选中和未选中的行数。对可实现的公开行数表，不同赞成人数的全部可能值为以下闭区间中的整数。

> P + max(⌈p/C⌉, u−n, 0) 至 P + min(p, u)。

普通赞成席数 x 至少要容纳 p 行，且其余 u−x 席各需要一条未选中行。每个赞成席又至少要有一条选中行。反向构造先在 x 席各放一条选中行、在其余席各放一条未选中行。将剩余选中行放入赞成席，xC≥p 保证能放下。剩余未选中行填入任何剩余空间，原表可行保证总容量足够。因此上下界及中间各点均能取到；均分是各行权重之和再除以三，给定行数表后它没有进一步收窄这一范围。[逐表验证解析界](mqm_receipt_check.py)
