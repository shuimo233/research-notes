# 单一错报的位置能否用一条桥路径压缩？

在运行下述桥路径算法之前追加登记。上一试验已看到注入档案中的 124 项歧义，100 项可用非目标对补核解决。这些已见结果用于提出结构假说。复用同一数据检查算法一致性，并以另行固定的图与整数输入检验适用范围。

假说限定在连通、无桥的无向报告图。每条边记录定向精确差值，允许至多一条错报。档案本身含不一致的环，且删去某一条指定边即可令所有环一致。区间先保持独立，作为检查可能修复的公开上下界。删除指定边所得图仍连通。待检验的结构是，其余候选修复边恰为这张图中连接指定边两端所经的桥。沿路径枚举候选时，顶点位移只在其所在位置切换一次。任何探针对的数值至多有两个，变化位置构成桥路径上的连续区间。由各站公开区间删除不可行修复后，仍可用可行位置的排名区间核验目标与补问的等价分组。

先在完全相同的 NOAA 档案上逐日比较每个允许保留的错报位置、每个目标结果及各非目标候选。另以 Python `Random(281619)` 固定生成 480 个实例，顶点数在 3 至 9 之间。用环确保连通无桥，附加随机弦，允许随机整数正负位移与若干宽度为零的可信区间。每例至少注入一个错报，四分之一另注入一条记录偏移以检验假设失效和无法修复的处理。每例遍历可能作为参考的边，等价性只在该边的删除确实恢复精确差值时主张。独立程序对每条删边逐一恢复相对坐标，在所有探针对上核对其可行值，并对各值附近可能改变标签的门槛核对全部可保证一次答完的探针。零可行状态和常量决策也做核验。门槛为全数一致，无需重复计算上一轮已报告的实用性阈值。此轮分开报告预给参考边的路径复杂度和寻找参考边的费用。

另验证无需预给参考边的实现。由任意生成树计算基准坐标，再挑一条非零残差弦，以其树路径作为候选路径。其他弦的方向残差对路径切分位置产生必选或禁止区间。两种入口与独立枚举比较，同一判断可以由不同的基准坐标表示。合成集合每八例加一个只有一条接边的叶子，该叶子不参与构造错误。分别核对普通连通图和无桥图。算法复杂度以整数算术操作计，探针配对核验使用可行切分位置的前缀排名。
