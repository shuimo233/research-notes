# 三段副本的来源凭据实验口径

2026-11-23。登记方知道两个真实切点，先于事件写一次凭据。接收方已知可能切点数 n、预选同源检查的位置和凭据，以后逐事件收到 n+1 个二值。三个连续段分别来自三个不同的记录器，每段忠实复制同一次根观测；每个事件至多一个根失实。只需恢复三根多数。布局在凭据使用期间固定。候选贡献是给定任意现有同源检查时，求最少需补多少种标签的公式，以及可以回读的实现。

先查到单调最小完美哈希、移位图色数、零差错带边信息编码和区间组测试。无已有回执的最优标签由已有两键秩查询结果给出。仅用区间查询时，探索阶段对 n=3 至 16 用 RC2 跑过最小化，随后推导覆盖或遗漏端点的下界。任意给定区间菜单下的余量公式来自按已有答案拆开冲突图，写本记录时尚未执行其批量检验。

独立检验从三个根的全部八种位组合生成完整档案。按已有回执收集会在同一读数上给出相反结论的布局对，对小图直接着色，与公式和实际编码逐一对照。另枚举小区间菜单检查仅用回执的最低项数，并比较单条回执可容纳多少切点。工程试验沿用已有应用、工具入口、SQLite 授权回调采集，在实验导出器中制作连续忠实副本，故意让单一根失实；按打包文件实际字节比较提供额外标签、记录完整切点、只保留同源检查，以及按行多数。把标签位数、行数据读数、物理字节分开报告，保留少量事件或检查可按事件临时选择时的适用边界。
