# 世界依赖的层级故障预算与审计采购

核验日期 2026-11-25。研究对象是确定性记录、共享层级分组、按候选世界分别规定的整数故障上限，以及固定成本的一次性证据采购。

## 最接近的原始工作

- Ravagnani 与 Kschischang 将两个输入的可混淆性定义为它们的可能输出集合相交。例 2.2.5 使用不相交域上的对称错误预算。该信道框架也能表达依赖输入世界的允许输出集合。 [Adversarial Network Coding，定义 2.3.1 与例 2.2.5](https://arxiv.org/pdf/1706.05468)
- Fife 与 Oxley 给出层级容量定义拟阵独立集的标准模型。Edmonds 的划分定理已经覆盖不同拟阵，给出了以任意子集上的秩和为界的充要条件。Kundu 等在求解 Maximum Span 时明确给出单个层级拟阵从叶到根的局部秩递推。 [Laminar Matroids](https://arxiv.org/abs/1606.08354) · [Matroid Partition，定理 1](https://sites.math.washington.edu/~thomas/teaching/m514_web/50YearsIP.pdf) · [The Parameterized Complexity of Maximum Span on Natural Matroid Classes，第 3 节](https://drops.dagstuhl.de/storage/00lipics/lipics-vol386-mfcs2026/html/LIPIcs.MFCS.2026.95/LIPIcs.MFCS.2026.95.html#S3)
- Ortiz-Angel 与 Soto 明确写出同一个层级拟阵取 J 份时的规则，即每组容量乘以 J。证明依赖各份使用相同容量表。 [The Multiple-Choice Matroid Secretary Problem，第 5.2.1 节](https://arxiv.org/html/2607.15407v1#S5.SS2.SSS1)
- Ashlagi、Saberi 与 Shameli 将有各自层级类型配额的机构分配归约为整数最大流。Ford 与 Fulkerson 已给出最大流最小割定理。Wood 已将选择决策与容量割放在同一个整数模型里，用途是研究边容量可受干预时的网络流优化。 [Assignment Mechanisms Under Distributional Constraints，期刊版命题 1 前的流网络归约](https://web.stanford.edu/~iashlagi/papers/final-paper.pdf#page=8) · [Maximal Flow Through a Network](https://doi.org/10.4153/CJM-1956-045-5) · [Deterministic Network Interdiction](https://calhoun.nps.edu/bitstream/handle/10945/36730/WoodDetNetInt93.pdf?sequence=3)
- Moret 与 Shapiro 研究保持区分力的最低成本测试集。Laifenfeld 与 Trachtenberg 已经把共享全局错误上限 r 的容错识别采购化为 2r+1 重覆盖。水网故障定位也有真实系统中的最小测试覆盖研究，可作为将来构造数据基准的参考。 [On Minimizing a Set of Tests](https://epubs.siam.org/doi/10.1137/0906067) · [Identifying Codes and Covering Problems](https://doi.org/10.1109/TIT.2008.928263) · [Sensor Placement for Fault Location Identification in Water Networks](https://cs.vuse.vanderbilt.edu/koutsoxd/www/Publications/1-s2.0-S000510981630231X-main.pdf)
- Hooker 与 Ottosson 给出基于逻辑推导产生主问题割的通用分解方法。按需发现采购约束属于这一已有算法框架。 [Logic-Based Benders Decomposition](https://link.springer.com/article/10.1007/s10107-003-0375-9)

## 对判据的独立复核

两个世界在已购来源上的确定性预期记录存在分歧集合 D。共同观测要求每个分歧至少由一个世界改变。若两边都改变同一位置，可以只保留其中一边改变，并把共同值设为另一边的预期值。各组故障上限在删除故障时继续成立。因此，共同观测存在当且仅当 D 能划分成两个各自满足本世界容量的故障掩码。这个推导需要任意受损来源可以输出对方的预期值，且同一来源只计一次。

对组 G，令 c(G) 表示其分歧数，r_A(G) 与 r_B(G) 表示各世界仅考虑 G 及其后代约束时能容纳的最多分歧数。将直接挂在内部组的来源展开成单来源叶节点后，内部节点的秩等于本组容量与子秩和中较小的数。若每个子组均可划分，子组交给 A 的数量可以取从 c−r_B 到 r_A 的每个整数。子区间求和后再与父组自己的容量区间相交，正好得到父组的同型区间。故每个组满足 c(G) ≤ r_A(G)+r_B(G) 是充要条件。自顶向下在各子区间内分配目标数量即可还原故障掩码。

若某组数目超过两边的局部秩之和，可分别给出覆盖该组分歧叶的容量前沿。每条前沿由同一世界内互不相交的子组或单来源叶组成，直接核验其覆盖性及两个容量和即可确认无法划分。两世界的前沿允许不同。等价的通用核对方法是把每个分歧作为一单位整数流，二选一送入相应世界的来源节点，再沿该世界各组的容量边送达汇点。此方法也可用于各世界拥有不同层级的情况，共用分组的递推则只需遍历一棵树。

原始容量相加可能给出错误的混淆结论。根组 A、B 均为 3，下面三组 X、Y、Z 各有 3 个来源，容量依次为 (2,1)、(2,1)、(2,2)。分歧为 X 与 Y 的全部 6 个来源。逐组原始容量和都够用，但 X 与 Y 各迫使 A 承担至少 2 个故障。根组的两个局部秩实际为 3 和 2，两条前沿可以分别取根组及 X、Y。原始容量表中的根和三个子组在各自世界内均有独立约束作用，例如只移除根约束便能从不同子组取到 4 个允许故障。这个例子中的差异来自预算在分歧分布下的相互作用。

对只有根组和互斥子组的情形，令 A、B 表示两边总容量，aᵢ、bᵢ 为第 i 子组的容量，cᵢ 为分歧数。各子组分配给 A 的可达区间为 [max(cᵢ−bᵢ,0), min(cᵢ,aᵢ)]。因此共同观测存在当且仅当四类界均成立。每组满足 cᵢ≤aᵢ+bᵢ，总量满足 ∑cᵢ≤A+B，且 ∑max(cᵢ−bᵢ,0)≤A 与 ∑max(cᵢ−aᵢ,0)≤B。最后两个界等价于对每个子组集合 I 检查 ∑_I cᵢ≤A+∑_I bᵢ 和 ∑_I cᵢ≤B+∑_I aᵢ。任一越界直接给出固定来源池上的购买数量门槛。

## 对采购约束的独立复核

设 M 为一对相反裁决世界在全部可购来源上的分歧集合。若候选采购与 M 的交集可划分，逐个尝试加入其他分歧即可扩张为极大可划分集合 U。故障掩码可向子集限制，所以 U 的任意子集仍可划分，任何有效采购都至少要买 M∖U 中的一个来源。两份合法故障掩码已足以核验这个约束的有效性，极大性只用于加强约束。若 U=M，全集也无法解决这对世界的混淆。每一轮精确求解已有约束下的加权命中问题，再验证所有相反裁决世界对，首次取得可行采购便能证明全局最优。整体计算仍受最低成本测试选择的组合复杂度约束。

也可直接编译采购约束。各世界分别选择一组互不包含的组 P、Q，取它们所覆盖来源池的交集 K。若在 K 中采购的分歧数严格超过 P、Q 的总容量，便排除了共同观测。反过来，任一秩不足的见证集合都可用两组这样的覆盖证明。对单个世界，秩等于在某组集合内支付容量、在其覆盖池外逐个计入分歧时的最小总和。将两世界的秩不足式展开，只有位于两池交集的分歧贡献正一，位于两池之外的分歧贡献负一，其余贡献零。于是只留下交集中的分歧即可保留越界。这个结论也适用于两个世界分别有各自的层级树。

共用层级树时，至少可以用单个组代表其中一个世界的前沿。选择最深的越界组 G，若 G 为内部组，其所有子组均可划分，所以其子组秩和覆盖了全部分歧。本组越界必须来自至少一个世界的本组容量对可用秩的截断。若 G 为单来源叶，则其越界直接要求两边容量均为零。于是证书只需一个本组容量，加上另一世界在该组内的容量前沿。若要求计算必须删除多少分歧才能恢复共同观测，令 δ(G) 表示这个数量。根据交集超额的公式，两个前沿均略过 G 时，超额是各子组 δ 之和。若某个世界选中 G，则该情形的最大超额是 c(G) 减去该世界的本组容量，再减去另一世界的局部秩。对三种情形取最大值即可在线性遍历内求出 δ。当采购约束的超额至少为 k 时，之后任意丢失至多 k−1 个已购来源仍可区分这对世界。

可在一个混合整数模型中为每个相反裁决世界对选择两个容量前沿。为每个树节点引入选择变量和一条根到该节点的累计选择量，约束后者至多为 1。每个分歧来源引入 [0,1] 变量，分别受其采购变量及两棵树上的累计选择量约束。该对的分歧来源变量之和须大于两份前沿容量和，整数门槛用容量和加 1 实现。这样每对世界所需的变量和约束数随树节点与分歧数线性增长，模型规模仍随待区分世界对增加。见证可直接检查每个世界的组选取、交集和计数。
