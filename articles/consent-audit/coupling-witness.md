# 一句里先问哪些词，能在不知道真实相关性的情况下证明选对了吗？

SemCor 有一句话，position 出现两次，两个位置都要和同一个 attitude 判断关系。先问 attitude，按冻结模型有 3/4 的概率需要再问两个 position，1/4 的概率两个都不用问，平均恰好 2.5 次。若先问两个 position，每个各有 1/4 的概率使 attitude 需要补问。这两个触发若恰好错开，最坏平均也是 2.5 次；若假设独立，只会算到 2.4375 次。把两个触发错开就是一个具体证据，说明另一种顺序在最坏情况下也省不了。两种方案打平时，工具选第一阶段只问一个词的方案。[可直接运行的真实输入](coupling-plan-example.json) · [方案工具](certified_cover_plan.py)

这里采用严格两阶段合同。先付费揭示一个顶点覆盖中全部词元的实际义项，剩余位置只在其义项仍可能改变某项判断时付费揭示一次。每种方案都必须对所有词典解释正确。每词的候选义项边际均匀，句内联合分布可以任意变化。效用指标是最坏联合分布下的期望询问数。本轮对照的语料、证书构造、取样和方案选择在运行之前公开。[查分前方案](https://github.com/shuimo233/research-notes/blob/9978567328546d6fd34cb0ef0c0928f8904c959b/articles/consent-audit/coupling-witness-protocol.md)

## 一份上界证明长什么样

用同一个 0 至 1 的均匀随机数来决定全部先问词的取值。对每个词，把会引发同样补问的义项合并成一类，按固定的清单字典序排列，每一类占据与其概率等长的区间。各词分别选择正序或倒序。给定这些方向，就有了一份符合全部单词边际的联合分布。按所有区间端点切开数轴，就能逐段重放其预算；无需列出所有词义组合。[见证生成器](coupling_clock.py)

对每个待补问词，把各来源的触发概率相加。和小于 1 时，要达到逐项上界，触发区间必须互斥；和大于 1 时，必须覆盖整条数轴；和等于 1 时两者都要成立。对每一小段，某来源触发与否是常量或一个方向变量的正负文字。互斥条件写成两两子句，覆盖条件写成至少一个文字为真。若化简后每个子句至多有两个文字，就可用标准的 2-SAT 求解，并给出具体方向。对下界，所有触发事件应当被概率最大的那一个包含，只需二元蕴含子句。宽子句在登记的实现中返回“未覆盖”。方向选择无解，仅能排除这一族见证。共用均匀变量、重新排列边际及 2-SAT 均有直接先例。[先例与数学边界](paired-trigger-prior.md)

之前的 99 个固定方案中，有 15 个超出无环判据。此次方法为其中 **13 个**给出逐项上界可达的具体见证，其中 WSD 为 9/10，SemCor 为 4/5。余下两句的上界也可达，线性规划已经给出了证明。一个例子是三处词元各有 1/4 概率触发同一批七项补问。要达上界，只需把三段 1/4 放在互不相交的位置；仅用共同数轴的正序和倒序只有两个端点可选，放不下这三段。[244 个方案的见证与精确原对偶解](coupling-witness-ledger.jsonl)

**事后补了一个更简单的对照。** 如果两个目标在所有来源的每一种取值下都有完全相同的触发情况，就可合并成一个目标，成本按重复次数计。上述七项都能这样合并。合并后再检查依赖图是否无环，单独就能算准 **98/99** 个原方案的上下界；加上共用随机数见证，99 个上界全部得到解释。在下述全部 244 个备选方案上，合并无环法给出 236 个精确上界，两种方法合用为 238 个；其余 6 个交给联合求解器。合并规则在看过两例失败后提出，尚缺新数据的前瞻验证。[合并与无环检查](coalesced_forest_budget.py) · [分语料对照](coupling-witness-results.json)

## 把预算证书用来选方案

对同一句只需检查包含意义下极小的顶点覆盖。在已有覆盖上再提前问一个位置，有时能把一次补问挪到第一阶段，有时会白问。由于原覆盖外的任意两个位置之间没有非常量查询，新增位置的答案不能帮助剩余未知位置再省一次。因此每个世界里，超集的成本都不低于原覆盖的成本。

对每个极小覆盖，先算无需优化的逐项上界。选总上界最小的覆盖，再检查它的上界是否不高于每个竞争者的**可达成本下界**。独立耦合本身就是可行下界，明确的上界达成见证可以把下界提高。若这些不等式都成立，选择在所有确定性严格覆盖中已达到最优。工具也会返回未获认证的情况。覆盖枚举本身仍可能是指数级的；这一版应用于小句子批次。[无需 SciPy 的方案选择器](certified_cover_plan.py)

| 实际句子 | 极小方案数 | 原固定覆盖的最坏期望之和 | 选择最优覆盖后 | 冻结人工义项上的实际询问数，原方案→新方案 |
| --- | ---: | ---: | ---: | ---: |
| WSD，60 句 | 166 | 132.474 | 128.849 | 162 → 160 |
| SemCor，39 句 | 78 | 82.522 | 81.922 | 86 → 86 |

99 句的选择都经完整联合优化核对为最优。四舍五入的期望属于登记的均匀边际模型，最后一列属于语料中的实际义项。**独立期望最小的选择在这批数据上也全都达到同样的最坏期望最优值**，在 SemCor 的实际义项上还少问了一次。就证明选择最优而言，只用竞争方案的独立成本作下界能证明 97 句，独立加上旧的无环判据已能证明全部 99 句。目前看得到的额外价值，是解释含环实例的预算、给出可重放证据，以及认清什么时候可以放心采用简单办法。[完整排序与消融结果](coupling-witness-results.json)

## 复现

在本目录运行第一条命令即可重放开头的例子。只需要 Python 标准库。随后两条命令重建研究账本并独立检查。核验器通过 NLTK 重建词义关系、用另一种方法枚举所有极小覆盖，对 488 份有理数原对偶证书和 2,880 种方向赋值逐项核对。[独立核验记录](coupling-witness-checks.json) · [核验代码](coupling_witness_check.py)

```sh
python -I -B certified_cover_plan.py coupling-plan-example.json
uv run --no-project --python 3.13 --with scipy==1.16.3 -- python -I -B coupling_plan_audit.py wordnet-3.0-nltk.zip fresh-couplings
uv run --no-project --python 3.13 --with nltk==3.9.2 -- python -I -B coupling_witness_check.py wordnet-3.0-nltk.zip fresh-couplings
```

一个仍有意义的理论问题是，何时能判定“这些最坏情况根本不能同时发生”。对等概率二元来源，每项目标至多有两个触发来源，与每项恰有三个正向触发，计算难度出现分界。另一篇记录给出了证明、可运行的判定器，以及一个能生成精确损失值的构造。[可达性边界与反例](fair-union.md)
