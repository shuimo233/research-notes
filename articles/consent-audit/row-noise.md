# 知道日志来源，什么时候真的能少读几页？

2026-11-23

在我们的归档试验里，每个档案有 152 页。一个记录器可以失实，归档写完后还会有一页被改写、另一页缺失。若事先为所有档案定同一张读取清单，**104 页是最低数**，连把完整来源布局都告诉审计方也无法降低它。若先收来源回执，再为这个档案买页，八种回执所需的最低数分别为 **12、20、36 或 56 页**。

这一差别来自一项具体权限：审计方能否用刚收到的信息改变它实际读取的页。它也关系到我们最初的推理问题。相同的行为痕迹可以有不同解释；来源信息的操作价值，可以用它是否改变维持正确结论所必需的取证动作来衡量。[一般条件、证明与反例](row-noise-proof.md)

## 一页坏掉，为什么十行副本也可能一起失去作用

每次事件有三个记录器，各给出一位。它们在档案中依次形成三个连续段，每段复制同一次根观测。至多一个根失实，三根多数给出事件真值。两处隐藏分界的身份由可信回执部分披露。这里再引入一层故障：档案已经形成后，所读的一整页可以返回任意错误内容，另有若干整页可被标记缺失。

固定一个回执，考虑仍可能给出相反结论的两份原始档案。它们如果开头不同，整个公共首段就能作见证；若结尾不同，则是公共末段。排除这两种情况后，唯一可能的歧义是两档案都有一次同方向的跳变，在一个布局上跳的是第一分界，在另一个布局上跳的是第二分界。两个位置之间的行就是差异。反过来，每一种这样的差异都能用具体的三个根值实现。

因此不用列出所有相反记录。只需找到两个端部区间和排序后第一、第二分界交替处的区间，将它们映到归档页。若最多有 e 页错写、s 页缺失，每个这样的区间都必须读到至少 2e+s+1 个不同页，且这样就足够。接下来直接采用已有的有价区间需求击中算法，得到最低价清单。软件随结果给出算术证书，接收方可只用标准库复核最低价。纠错距离判据和区间优化各有明确先例；本次推导把带来源歧义的整套差异还原成这些区间。[函数纠错码论文](https://arxiv.org/abs/2102.03094) · [有价区间需求击中原文，第 4 节](https://web.iitd.ac.in/~minati/archive/HitCover.pdf) · [查新与独立审读](row-noise-precedents.md)

## 为什么提前披露完整布局也可能不省一页

把所有可能的分界位置画在一条线上。如果每对相邻分界都确实可能共同构成某个布局，而原有回执足以判读无损的完整档案，那么**所有固定清单的最小异类距离都与完整布局下相同**。原因在于，每个相邻单元中都存在一对同布局、相反结论的档案，恰好只在该单元上不同。即使知道布局，也必须防住这些实例。其他所有跨布局歧义，都会包含一个这样的单元。

这个条件可以被反例推翻。取 15 个单行页，只登记切点 (3,7) 与 (8,12)，缺少相邻对 (7,8)。若两个布局共用一个来源标签，最接近的相反记录只差一页，买全档也不能保证纠正一次改写。若给完整布局，最小差距变成三页，恰好能够纠正一次改写。工具也能对任意注册表检验：完整布局会不会改变某张固定清单的容错距离；若会，直接给出一张产生差别的清单和两份相反记录。[精确检验与反例费用](row-noise-proof.md) · [穷举结果](row-noise-checks.json)

## 三种实际读取方式

这轮沿用前次的 31 个候选分界与现有来源凭据，共 465 种布局，按可信回执分成八组。为在模拟损坏后仍保留可区分的独立归档页，每个原始行位置物化为 19 个连续记录。每页装四行、每行存四次模型行为的一字节观测，共 16 B。每页写成独立的普通文件。这里的“页”指应用归档格式的一个读取和计错单位。

在随机种子固定的 32 个布局上，我们从应用决定、工具入口和 SQLite 授权回调采集行为。每个布局故意翻转一个根，再把已经写好的一个购买页逐位覆写，将另一个购买页移出读取目录。两份既有档案清单在同一个布局上遭遇相同的两页故障。128 个模型决定中有 64 次提出写入请求，实际成功写入 0 行。[采集、故障注入与读回程序](row_noise_demo.py)

| 允许采取的动作 | 每个档案预订的页 | 32 个档案实际返回的总字节 | 正确判定 |
| --- | ---: | ---: | ---: |
| 原档案，所有回执共用预先固定的清单 | 104 | 52,736 B | 128/128 |
| 原档案，拿到回执再定这次清单 | 12、20、36 或 56，平均 18 | 8,704 B | 128/128 |
| 可重做导出，每页装同一组有序的三个根报告，分别保存四次 | 4 | 1,536 B | 128/128 |

预订页数包括那一页后来未返回的档案。第三行使用同样的 16 B 帧；每帧包含格式标识和三根对四个事件的报告。丢一帧、错一帧后，三份返回中仍有两份正确。只要可信元数据先于事件产生，且事件有两种可能结论，三帧最多只能让两个理想读数在三处不同，不能同时保证抵抗一次任意替换和一次缺失。四帧由此达到这种新格式下的最少帧数。对已有且不可重写的档案，前两行给出相应取证约定下的最低费用。这里没有计入改造导出器、建立来源信任、目录维护和系统缓存的成本。[完整逐项结果](row-noise-results.json)

104 页也能手算。32 个连续单元各需由 4 个所读页保护，一共需要 128 次“页覆盖单元”。每个单元长 19 行，每页仅 4 行，一页最多横跨一个分界。31 个分界中，7 个正好落在页边界上；另外 24 个分界各有一页可以同时保护两边。因此最多能省 24 次重复计数，至少应买 128−24=104 页。实测清单达到了这个下界，最优预订价为 1,664 B。

从这张清单再去掉第 1 页，在同一布局 (19,38) 下，根值 001 和 101 只在余下的第 2、3、5 页上不同。让第 2 页缺失，一种世界错写第 3 页，另一种错写第 5 页，审计方就会收到相同的剩余信息。来源身份再精确也无法消除这一对解释。[相反世界及其故障位置](row-noise-results.json)

## 复现

在 `articles/consent-audit` 目录运行。样例有不同的页价格，最低价为 50。第一条求解，第二条只用标准库核验费用下界，第三条解码一页已被改写的实例，结果应为 `some_request`。第四条检查完整来源布局对固定清单是否还有辨别价值。

```sh
uv run --no-project --python 3.13 --with networkx==3.6.1 -- python -I -B row_noise.py row-noise-example.json
python -I -S -B row_noise.py row-noise-example.json --verify row-noise-certificate.json
python -I -S -B row_noise.py row-noise-example.json --decode row-noise-observation.json
python -I -S -B row_noise.py row-noise-example.json --layout-value
uv run --no-project --python 3.13 --with networkx==3.6.1 -- python -I -B row_noise_check.py
uv run --no-project --python 3.13 --with scikit-learn==1.8.0 --with networkx==3.6.1 -- python -I -B row_noise_demo.py
```

独立检验直接构造三根所有原始答卷，逐页比对相反结论。421 个注册表、28,546 个固定页清单的最小距离与区间算法吻合，费用与子集穷举结果一致。在一个有两种回执的配置中，对所有允许干净答卷、每一个不同的错页与缺页选择及每种非平凡替换内容，10,472 次解码都恢复了原始多数。[检验程序](row_noise_check.py) · [试验口径](row-noise-protocol.md)

这份保证针对三段有序的忠实副本、已登记的布局、可信的回执和明确的整页故障上限。实验得到的是受控故障下的确定性保证，生产环境的错误频率、来源之间的共同故障以及跨多个文件的同一故障域仍需另验。
