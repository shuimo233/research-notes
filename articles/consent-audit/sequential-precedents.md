# 顺序审计的精确次数及其先例

核查日期为 2026-11-23。对照[本次顺序实验的协议](sequential-protocol.md)。一个收益点对应一个稳定的二元请求位，目标是在总共至多 f 条日志有错时，判定范围内的所有请求位是否都为零。每次追加观测成本相同，允许看完回答再选下一项。

**空历史结论已有完全相同的定理。** Maharjan 与 Watson 的观察 3 证明，容许 E 次对抗错误的 n 位 AND，最优顺序决策树高度恰为 n(E+1)+E。翻转全部输入位及输出位就得到本项目的 OR。原文引理 2 还明确给出，确认前一位时已耗掉的错误份额可以从后续复测额度中扣除。因此 n=20、E=1 时最坏 41 次的数学结果，以及顺序读取优于事先对每点安排 3 次，均应归于已有理论。[Maharjan 与 Watson，FSTTCS 2022，第 26:2–26:3 页，引理 2、观察 3](https://doi.org/10.4230/LIPIcs.FSTTCS.2022.26)

## 哪些模型早已覆盖

- **单价逐次查询、所有坐标共用一个对抗错误预算。** Kenyon 与 Yao 在 1990 年即研究这一模型下的布尔函数求值，并给出依赖最小证书大小的界。OR 的精确常数由上述 2022 年观察直接提供。[Kenyon 与 Yao](https://doi.org/10.1142/S0129054190000023) · [普林斯顿大学报告目录，TR-263-90 摘要](https://www.cs.princeton.edu/techreports/1993/405.pdf)
- **过去已读过某些确切坐标。** Maharjan 与 Watson 第 3 节的 pattern 记录每一坐标已经出现的 0、1 次数。给定输入 x，其必须消耗的错数是所有坐标上与 x 不符的次数之和。当前相容输入输出一致时即可停机。第 3 节还解释了为何再查一个坐标能改变对其他坐标的结论，因为错误预算共享。他们对一般真值表和有效模式给出动态规划；观察 3 的公式本身取空的起始模式。[Maharjan 与 Watson，第 26:3–26:5 页及定理 1](https://drops.dagstuhl.de/storage/00lipics/lipics-vol250-fsttcs2022/LIPIcs.FSTTCS.2022.26/LIPIcs.FSTTCS.2022.26.pdf)
- **事先固定所有位置。** 两个候选还可分别错 r、s 次时，未来诚实记录的最小汉明距离至少需要 r+s+1。等半径给出 2f+1。非自适应设计直接在完整签名之间核对距离；顺序树的不同回答可能触发不同问题，不能对整棵树套用同一组预定签名。[Hamming 1950](https://doi.org/10.1002/j.1538-7305.1950.tb00463.x) · [Zhigljavsky，固定实验及式 (3)](https://orca.cardiff.ac.uk/id/eprint/15201/1/Group%2520testing%2520lies.pdf)
- **邻近工作的区别。** Meng、Lin 与 Yang 的带谎小集合查询要找出唯一隐藏元素。常规群查询问一个池中是否有目标；本审计只需判定有没有风险，而且区间报价只实现其中一个未知价格。Feige 等的带噪布尔求值使用随机噪声及允许失败的正确率指标。Dagan 等研究有输入分布的带谎二十问，其平均询问次数也无法替代本项目对每条允许记录都成立的最坏次数。[Meng 等](https://doi.org/10.1016/j.disopt.2013.07.002) · [Feige 等](https://doi.org/10.1137/S0097539791195877) · [Dagan 等，§1](https://www.cs.toronto.edu/~yuvalf/Lies.pdf)

## 加入区间历史以后，原文能直接推出多少

记 S 为会请求的价格集合，d(S) 为解释历史最少要花的错数。空基线存活时令 R=f−d(∅)，令 Δᵢ=d({i})−d(∅)，再令 A 为还存活的单点集合。每个 i∈A 的剩余额度为 rᵢ=R−Δᵢ。区间历史的关键关系是

```text
d(S) − d(∅) ≥ Σ(i∈S) Δᵢ .
```

每一条正读数只需实际价格命中 S 中一个点，多个单点可能为同一条正读数重复取得信用。每一条负读数只有在所有允许价格都属于 S 时才强制矛盾。两种损失都是超模的，因而有这个不等式。仅有确切历史价格时它是等式。比如 [1,2] 上一条正读数使空集、两个单点、双点的损失分别为 1、0、0、0，这四项无法由一个逐坐标可加函数同时给出。集合值观测下逐样本选取相容实现，有既有的广义损失解释。[Hüllermeier](https://arxiv.org/abs/1305.0698) · [Maharjan 与 Watson，第 3 节的逐坐标损失](https://doi.org/10.4230/LIPIcs.FSTTCS.2022.26)

仍可构造一个经典 pattern 作为计算对照。对每个价格填入 max(Δᵢ,0) 张 0 票和 max(−Δᵢ,0) 张 1 票，将总容错额设为 E′=R+Σ max(−Δᵢ,0)。在合成模式中，空集与各单点的剩余额度与真实历史完全相同。所有多点 S 在合成模式中的误差余量为 R−Σ(i∈S)Δᵢ，根据上式至少和真实余量一样大。故一个能保证处理合成模式的策略也能处理真实历史。这个表示是为了推导最坏费用，可能容纳实际历史已经排除的多点行为。也不要求这些合成票数曾由原文定义的无冗余树生成。[Maharjan 与 Watson，第 3 节模式及第 4 节有效性的定义](https://doi.org/10.4230/LIPIcs.FSTTCS.2022.26)

若 A 非空，单位价下精确顺序上界为 Σ(i∈A)(rᵢ+1)+R，固定批次为 Σ(i∈A)(rᵢ+1+R)。两者都要求每个 i 有至少 rᵢ+1+R 次可用的确切报价。下面区分哪一步是原有论证的直接延伸。

1. **下界是观察 3 的同一个对手。** 先给所有问题回答 0。直到已问 Σ(rᵢ+1)−1 次，仍有某个 i 的确切报价得到的 0 不超过 rᵢ 次，否则总数会更大。接下来至多 R 次都按单点 {i} 回答，非精确报价可取不同于 i 的允许点并回答 0。此时 {i} 仍可解释全部前缀，空基线也至多接收 R 个额外的 1。还得再问一次。对单价 i 的容量条件，同样从开始就维持空集和 {i} 两种解释即可证明。在一棵自适应树上必要的单点容量，并不意味着某条路径要同时耗尽所有单点的最坏容量。[Maharjan 与 Watson，观察 3 的原始对手](https://doi.org/10.4230/LIPIcs.FSTTCS.2022.26)
2. **上界须兼顾多点风险集。** 一种策略是取得每个 i∈A 的 rᵢ+1 个 0，或先取得总共 R+1 个 1。后者排除基线；若前者成立，每个已购点的“0 的数量加 Δᵢ”至少 R+1，未入 A 的点天然有 Δᵢ>R。于是对任一非空 S，用历史不等式加上 S 内的后续 0 次数即可排除它。终止前得到的 1 至多 R 个，若最后一个回答使 1 总数达到 R+1，则还有至少一个 0 配额未完成。两种终止情形均遵守该顺序上界。逐项容量不足时，单点对手证明换用其他价位无济于事。空基线相容且 A 为空时，历史不等式已排除全部非空 S，所需次数为零。
3. **提前停止的数值有不同含义。** 基线真实且未来未再出现错误时，所有回答为 0，最短证书需要 Σ(rᵢ+1) 次；不能把它当成全树最坏次数。有足够多正读数时也可提前排除基线。对任何事先排定的问题顺序，即使允许根据回答随时停止，其最优最坏次数仍等于固定批次最优。若保证所有路径在第 t 次前后都已停，则该顺序的前 t 项必须分开两类候选，否则可取两类共同允许的一条长度 t 记录，此前的每个前缀也都无法正确终止。反向让固定批次在末项停机即可。因此当 R>0 且至少有两个相容单点时，固定方案与顺序方案的最坏差额 R(|A|−1) 来自能根据回答选择下一价格。两个实测轨迹只能报告各自的实际开销。固定批次总长度、某路径的实际长度和最优自适应树高度应各自报告。[Maharjan 与 Watson，第 2 节的树高及叶判据](https://doi.org/10.4230/LIPIcs.FSTTCS.2022.26)

截至核查日，已核实的原文直接给出空历史的精确公式、相应对手、逐点复测和确切坐标的历史状态。此次未找到原文明示**区间历史的超可加损失可以用单点余量替代，并据此给出对所有多点规则正确的闭式最坏次数及有限菜单条件**。这可作为观察 3 在本审计观测模型上的推论。仅给候选任意不同剩余额度则不够，例如两个单点都被排除但双点仍存活时，单点清单为空也不能认证全零。以上等式按单位试次数计价，逐价成本不同的最优顺序费用需另证。
