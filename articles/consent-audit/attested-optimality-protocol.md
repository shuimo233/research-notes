# 只有额外比较证词时，能否补足公开最优性？

协议在生成或评价补充证词之前冻结。对象是已经发表的 35 个信息不足个案，包括 BART 的 34 个及 GitHub Actions 的 1 个。选取此前公开补检文件中状态为 `shorter` 的全部任务。每项的原始最少披露数已经得到独立真值核验。本轮要求核验者借额外证词确认同一最少披露数。旧档案 A 固定，补充证词缩小可疑的真实记录范围 C。检验任何较短替代证书时，仍从同一个旧档案 A 出发。

## 字典、对照和主判据

每条补充证词说一个有向时间差至少达到某个固定格点。允许两个事件之间比较，也允许与已知的零原点比较。主字典采用 60 秒格点。报告同一数据上整数秒和 300 秒格点两个结果作为参照。证词由持有原始值的一方提供，公开核验器使用旧档案、已披露值、原报告和这些比较值。对每条方向选择仍成立的最强格点即可搜索最小条数，找到解后在不破坏证明时逐项放宽格点。记录每种字典返回的最少条数或不可行证人。将可推出精确值的新增位置总数单独报告。

主判据是全部 35 项先验证确实存在允许更短证书的相容世界，再独立核验补充证词和返回的边界。至少 21 项可用一条 60 秒格点比较复核最优，且闭包中此前未确定的时间戳仍至少有两个可能值。对照报告最多披露一个新原始时刻的成功率，以及一条原点比较与两个事件的比较各自覆盖。补充比较也传递信息，比较数和新增精确位置是本实验的物理量。

每项验证穷尽所有大小不超过原最少披露数减一的替代读数集合。可复用前序有效反例组剪枝，要求独立核验器从原始差分不等式复核。多条比较最少条数用反例驱动的覆盖求解并记录边界。任何达到查询或求解预算的项目都不记作已证。另在小整数网络中枚举所有实况、所有更短替代及部分最小修复问题，验证单条比较的上界判据，检查原始档案与补充后可疑世界的区分、比较导致精确值泄露和格点字典无解的情况。
