# 登记：用同一个随机数能否证明整句询问的最坏预算？

已知先前 99 句逐项上界全部可达，84 句的依赖图是森林。尚未看过下面证书在这些句子上的通过情况，也未评价这些句子的其他询问覆盖。沿用两套数据、同一份词典、各词义均匀边际和严格两阶段成本，完整记录成功与失败。[原始发布](https://github.com/shuimo233/research-notes/blob/93a443a67762f2fa63c1d35ed6d2abbb7d7d9b77/articles/consent-audit/cover-dependence.md)

**候选见证。** 每个先问位置的各类触发清单按其词元 ID 元组字典序排列，相同清单合并。用同一个均匀随机数落入各自按概率分割的区间，为每个位置选择正序或完全倒序。对上界，局部触发概率之和不超过 1 时要求各事件互斥，不小于 1 时要求至少一个发生；等于 1 时两者都要满足。对下界，指定触发概率最大的一个事件，要求其他所有触发都包含在该事件中。把每个区间上的要求翻译成方向变量的析取子句，消去常量和重言式。若均至多两个文字，采用已有 2-SAT；若出现更宽子句就报告未覆盖，不用枚举方向寻找最有利的结果。每份成功见证须由独立程序用精确分数重放边际和期望。方法失败不构成一般联合分布不存在的证明。既有的无环法作为对照。

**主要检验。** 先前词典序打破平手的最小覆盖保持固定。逐语料计数：在既有无环法无法覆盖的句子中，新方法是否至少各多认证一个可达到的局部上界。另列下界、两端同时认证、失败种类及与精确运输线性规划的差距。这是对已知结果解释机制的审计，单独报告。

**此前未评分的方案选择。** 对同一批中全部 60 个 WSD、39 个 SemCor 共享句子，枚举全部包含意义下极小的第一阶段顶点覆盖。以每句每种方案的精确最坏期望裁定最佳固定方案，和三项可执行的选择法相比：原先的最小基数覆盖、最小化独立期望、最小化逐项上界。选择规则费用平手时先取基数小者，再按位置 ID 元组字典序。比较各法的最坏期望和冻结真实义项上的实际询问数；不得用实际义项选方案。报告上界最优在多少句可用具体可行分布的下界认证为全局最优，不把“上界可达”独自当作方案最优证明。各方案的证书可使用独立耦合作保底。另公开所有方案中，新见证覆盖了多少无环判据遗漏的情况。计算资源若不足则列出未完项，不能将覆盖子集当作穷举。

多份答案共用一个随机数、反向耦合、有限支持运输、2-SAT 与边际拼接均有先例。研究归属以特定询问合同里的判据、实测覆盖、对照和可验证的最优方案为准。所有分布用于预算评价，准确回答仍要覆盖词典合法解释的全体。
