# 从 SemCor 迁出后，询问成本落在哪些判断上？

在读取本轮外部语料、运行筛选和计分之前登记。上一轮 SemCor 成本为 506→350，省下的 156 次全部是“均非”，44 个严格上下位正例节省为零。两个义项都未知并不自动意味着两个都要问；一次询问是否足够取决于其余所有可能解释是否同答。等价类判定、决策区域和布尔证书都有先例。本轮检验的是这个观测在新文档和不同问法下的适用边界。[前次实测](semcor-clarification.md) · [统一 WSD 语料](https://aclanthology.org/E17-1010/) · [决策区域](https://proceedings.mlr.press/v33/javdani14.html)

**外部输入。** 只读取原始 Raganato ALL 的一份合并文件，包含 Senseval-2、Senseval-3、SemEval-2007、2013、2015。锁定 WordNet 3.0，与上一轮相同。原始 XML 和 gold.key.txt 的 Git blob 分别为 `7d5cb8f9f6a1055091976a6816288a621475b41f` 和 `d5bd595ebb0d83a149f8a2dc09851f23fc1521f1`，两个研究团队的公开副本对应相同文件。数据复本提交为 `697cb66cf7ba874c276c863f2e9e2ea32b6c52d9`。不公布句子文本。[固定输入](https://github.com/akranlu/wsd-data/tree/697cb66cf7ba874c276c863f2e9e2ea32b6c52d9/data/ALL) · [GlossBERT 所用文件](https://github.com/HSLCY/GlossBERT/tree/master/Evaluation_Datasets/ALL)

**两个预定集合。** 取同句内不同位置、不同 lemma、标记为 NOUN 的 instance。要求该词的全部可接受金标都能映射为冻结候选中的名词义项，未能完整映射的词元记数排除。甲乙按原始 lemma 字母序排列，重复位置保留。主要复验沿用先前 208 个双向词对；另独立统计广集合，要求两端均有至少两个候选义项，且词典中至少有一种解释满足任一方向严格上下位。广集合允许只在一个方向能找到词义证据，允许多词 lemma；两个集合可以重叠，不相加。

**口径。** 精确成本主表使用两端金标分别归并后各只有一个义项的组合。在多金标补充表中，一处位置组合仍只计一次，枚举两端金标的笛卡尔积，对询问数与节省分别取最小和最大，再跨组合相加，同时报告由金标唯一决定四分类关系的个数。这些是逐组合边界；同一词元在多个组合中出现时不假定联合极值能同时实现。金标用作揭示义项的模拟回复和事后分析，规划时仍使用词典所有合法义项。

**主检验。** 使用上一轮的四类关系、等权行列选择法和提前停止条件。诚实询问一端准确义项记 1，单义端免费。报告逐来源和总表，列出机械问清所有多义端、关系表、先甲、先乙、先多义、先少义与等概率顺序的成本。对每个世界再报告所有合法顺序中的事后最低成本，即允许事先知道哪一端会较快的下界。核对所有结果及终止一致性。只有登记词对的外部单金标样本至少有 20 个严格上下位正例且正例仍无节省，同时均非项有节省，才称本轮主要复验达到预设条件；出现正例节省也按实报告。广集合单列，以检查选词造成的差异。

**改变问题。** 在同一批世界上，用相同询问分别问四类关系、甲是否严格下位、乙是否严格下位、任一端是否严格下位。对每种问法都重新计算候选义项能否提前确定。事后最少成本衡量某个真实世界能否有更短的证书；真实可执行策略另计。在只有一个四类标签能令二元问题回答“是”的情形，正例的最少成本在投影前后应逐项相等。对合并两个方向为“是”的问题，检验现实中是否至少有一个严格上下位正例因此有更短证书，把可实现的提前停止另列。即使两项均无额外收益也发布结果。独立词典接口和单独写的检验程序重建样本及真假结果。这里不测人的耗时，不把从 WordNet 导出的关系标签当作人对整句话的蕴含判断。
