# 遮蔽两个追问的联合概率后，预算区间还有多少辨别力？

本协议在运行下列语料评分前公开。固定两套已发表的任务，SemCor 与 Princeton WordNet Gloss Corpus。保留任务各自原有的独立词义先验与单位询问成本，只删除一处两个触发位的联合概率。触发位表示查询该词义后，是否还必须查询对应的邻点。[SemCor 任务与计分](frontier.md) · [Princeton 任务与计分](gloss-frontier.md)

## 输入与选择

- 枚举两套语料的所有已有任务。仅评分原规划精确、且每个规划类型只对应一个位置的任务。保留图和其他位置的全分布。
- 对每一个位置，枚举同一双连通块内的无序邻点对。把其余触发位合成条件掩码。在每个条件掩码内保留两个位各自的边际。
- 一项任务只删除一对。候选必须恰有一个条件掩码具有正的 Fréchet 宽度，这样可用一维求解器给出精确区间。选无条件宽度最大者，若并列，则按源位置和邻点名字字典序选择。选择过程仅使用将保留的概率和结构。
- 真实预算指删除前完整拟合模型给出的最优期望次数。Princeton 定义的模型只用 SemCor 计数估先验。评分不会用人工义项结果重新估算联合概率。这里检验合成的信息丢失，评估对象是真实语料任务的拟合期望。

## 对照和预定判据

比较三份输出。条件独立补全只返回一个点估计。Fréchet 参数中点加通用半径返回保证区间。精确求解返回所有与保留信息相容的触发分布上的最优预算区间。

主判据为两套语料合计至少 100 项可评分任务，完整预算均落在两个保证区间内，且至少四分之一的精确区间严格缩短通用区间。另枚举从 0 到总位置数的所有四分之一查询预算。区间上端不超过预算时判可达，下端超过预算时判不可达，其他时候判未定。对照点估计以同一不等式直接判定。公布点对照相对完整模型的错误次数、区间仍能裁决的比例，以及至少增加一次裁决的任务数。阈值枚举用于考察区间辨别力，各阈值是同一任务的重复比较。

所有未评分任务按原因计数。区间系数用有理数。报告精确区间的最坏点预测误差与单纯条件独立补全的最坏误差。方法不依赖保留原候选数、义项身份或原表结构，因此精确是指可行触发分布。已知实际词典的更多约束可使可行区间更窄。
