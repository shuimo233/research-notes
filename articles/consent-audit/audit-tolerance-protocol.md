# 带容差的低阶审计验收

冻结输入继续使用 [多标签试验](incomparable-odds-protocol.md) 的 CI 与 BART Git blob。按原排序，CI 各项目取第 13 至第 24 份，BART 取第 73 至第 144 份。这些样本与同一四请求构造的首段、末段试验不相交。标签仍取前四个合格时间差，早晚证词口径与多标签试验完全相同。每份从公开模式选字典序首对在四项都各自只有一个真证词、且两侧真标签相反的实况。无符合条件实况时记录并跳过。

在该两实况合同中，每项服务率分别固定为 1/5、1/2、4/5，独立地板为 1/2。待审策略把 7/8 质量独立抽样，1/8 按真实标签对应的公开时间端点分组。较早证词取该时间差的起点，较晚证词取终点；同组共用一次成功概率为该服务率的抽签，组间独立。使用这套受控策略给出各阶实际同向全拒比。对二项、三项的最大值分别至少取 1，记为观测容差。

核对两份配置。在观测配置里用实际得到的两项和三项容差；在宽三项配置中保留两项容差，并把三项容差放宽到当前值与 3 的较大者。对两配置分别求兼容该合同的完整窗口最坏倍率和达界概率表，比较保留两项证据与仅保留三项证据。第二份是验收容差的反事实，不代表档案产生过该发布策略。真实事实仅提供可行实况和端点结构。

主判据为至少 50 个档案评分，至少 10 个档案在宽三项配置中某档服务率保留两项证据能严格收紧完整界，所有结果经独立有理数核对。另报告观测配置中的收紧数量、支持结构去重、经验倍率收紧的最大因子，以及统一容差下最深阶是否已足够。一般异阶算法与公平闭式另做完整原子线性规划反例核对。
