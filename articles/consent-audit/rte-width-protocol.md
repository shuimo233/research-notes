# 稳定推理中的参考宽度：计算结果前的约定

已知原 RTE 开发集 277 条在最短单例与普通八条组批下的二元正确数分别为 194 和 203。这里检验另一个只依赖题目自身与固定校准数据的独立函数。此前未为 RTE 原训练文件计算过预测、准确率或参考宽度。本次训练文件不会用于更新权重。先算宽度再看新评估数据的模型输出。

按原 RTE/train.tsv 的整数 ID 取十进制字符串，在前方加 `rte-width-v1:` 后做 UTF-8 SHA-256。将摘要首字节模 4 等于 0 的题留作校准，只读取分词后的总长度；所有其他训练文件题均为主要的新增评估集，保持原文件顺序并按连续八条组批。原开发集单列，作为已经见过两端结果的次要比较。句对分词、最长 512、二元蕴含规则、INT8 权重及 CPU 环境延用前一实验。各子集按 ID 与原文核对，按句对内容检查校准与评估重合。若存在文本重合则原样列出，不将之称作跨文本泛化。这里的“新增评估集”指本项目首次评分，沿用上游训练分割标识。

预设由校准长度决定唯一整数 h。设 N 为校准题数，F(a) 为长度不超过 a 的校准题数；h 取使 2×C(F(h),7)≥C(N,7) 的最小校准长度。解释是从校准池无放回抽七条时，其最大长度的较小中位数。对长度 ℓ 的目标题，确定参考宽度取 max(ℓ,h)，右补齐后作为原模型单例。比较另两条独立策略：原长度单例与向上补齐到 32 的整数倍（上限 512）。自然八条组批作为比较对象，末批保留实际长度；其末批的自然宽度仍如实计入，另列尾批数量。第二个确定性对照使用常见的补齐到倍数接口。[分词器的倍数补齐](https://huggingface.co/docs/transformers/v4.28.1/en/pad_truncation) · [中位数与绝对损失的经典来源](https://www.maths.usyd.edu.au/u/jchan/GLM/Koenker%26Bassett1978QuantileReg.pdf)

对每种策略记录实际宽度与自然批宽度的绝对误差总和、蕴含判决和普通批不一致的条数、相对参考答案的正确数，逐题发布、不挑阈值。如果新评估集上 h 规则比原长度严格减少与普通批的二元分歧，并且正确数至少持平，才称它获得了预测层面的实用支持。另报与倍数对照的差值。开发集若由 194 提升到至少 199，称为回收旧净收益的一半以上，仍需分开报告原来那九条中挽回几条及其他题新增错误。宽度上的绝对损失最优性只针对所列随机比较对象，不外推为类别或准确率的最优性。

工程核对将同一 h 写入 Scan 单文件，在裁剪后补齐到 max(ℓ,h)，用固定填充值与真实 attention mask。按原序及 ID 哈希序各运行，核验每道题三项输出是否逐位匹配直接运行的对应单例。若精确导出失败，保留失败。没有根据评分挑选其他 h、校准样例或比较规则的步骤。
