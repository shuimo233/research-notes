
# 冻结协议：实际运行档位的使用比例偏离等概率时，怎样定出共享上限？

复用上一轮 2,508 个目录与分差门槛组合，主要目录和压力目录各 1,254 个。先核对发布档案的 Git 对象。逐项真实分数为 e1002444bf4be9c91336a33b4c58358d6f48645c，共享上限和题目方向表为 30ce968781a96a0fd4542987de68778d2f9dd914。沿用相同的参考标签核验、分差门槛、实验彩票和每项拒绝行为。上一轮不含本轮的档位分布实验。

## 分布、保证和对照

八档分布的中心取等权。任一次部署的概率分布为四分之三的中心，加上四分之一任意档位分布。四分之一是预设压力幅度，两种实况和两条路由共用同一份分布。独立路内逐项独立抽档，共用路内整组共抽一档。概率分布可随部署变动，给定分布后抽签规则如上。当前数据没有线上档位比例。

对所有至少二项的窗口，比较两个实况的归一全拒绝之比。沿用双向门槛 21/20 和共享比例操作区间 [0,1/2]。给出适用于整个允许分布集合的共享上限夹逼。下端必须保证在全部允许分布下可行，上端必须由允许分布下的约束证据或原操作上限给出。记录绝对夹逼宽度至多 1/1000 的比例，预设目标至少 95%。每个目录最多分割 96 次。对压缩前相同的风险条件复用计算。

- 对照一使用等权分布的精确许可比例。用一个允许的分布作为严格反例，才计作等权许可会超标。
- 对照二只检查允许分布集合的全部顶点。报告其比例是否经严格反例证实过高，保留零结果。
- 对照三用同一个分布集合分别计算各窗口的独立率乘积和共用路全拒绝率的简单边缘界，再对两份归一倍率组合计算保守比例。报告保留联合分布的证书是否收紧这组保守限制。
- 主效应用于全拒绝事件的归一联合影响，不涉及其他输出或整体隐私。报告主目录和压力目录的所有配置，无论结论是否支持原假设。

## 独立验证

用独立程序从模型分数重建按档拒绝率。它须逐个核对窗口模式的等价类，重建分割覆盖和有理多项式上界，代入最坏分布见证核对比例。固定率结果须与旧档案的等权全窗口结果精确一致。

额外检验一个不参加主评分的二档解析对照。实况一的两项随档位同时取拒绝率 1/20 或 19/20，实况二两项在每档均取 1/2。允许任意档位分布。两个纯档顶点没有联合效应，最大联合效应在非纯档处达到。用其解析最优值检查证书，另以边界和随机小例核对构造。
