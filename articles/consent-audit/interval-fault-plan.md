# 能核实的记录有限，何时值得按答案安排下一问？

一张报告图出现矛盾后，推理器需要知道自己能否取得足够证据，以及取得保证最多要花多少。这里的行动是判断一个差值是否跨过阈值。允许从事前给定的可信渠道取值，费用已知，答复等于真实差值。算法返回精确的最坏费用和可执行策略。如果全部可用渠道都不足以确定结论，算法返回两份仍然可行、结论相反、所有可用答复都相同的修复。 [实现](interval_fault_plan.py)

## 有序候选上的精确规划

当报告图至少需要修一条边而预算也恰为一时，既有的切点编译器按路径排列所有相容修复。任何可信点对的补核答复至多有两个。其中一个答复在连续的一段切点出现。因此一问等价于询问真实世界是否落在某一段区间。目标的真假标签也只改变两次。费用按询问收取，两种答案费用相同，优化量是最坏路径费用。 [单错报切点编译](interval-fault-cut.md)

**如果一个探针的整个区间只含一种原始标签，可以把它移到跨标签探针之后。** 在任一确定性策略中，这类探针命中区间就足以作答，只有未命中的分支还可能继续。沿未命中分支找到第一个跨标签探针。把它移到当前子树的根，两种答复下各重放原先的单色探针链。期间跳过不能区分当前任何两个世界的探针。原先经过跨标签探针的世界至多支付原费用。原先更早结束的世界至多支付原探针链与跨标签探针的合计费用，而原树至少有一个世界已支付该合计费用。对更小的子树重复这一交换，就有一个最优策略能把所有跨标签探针放在单色探针之前。这里跨标签以完整的原始世界顺序为准。

只使用跨标签探针时，一个探针与任一连续同色段的交只能是该段的前缀、后缀、全段或空段。取交集与取差集都能在每段中留下至多一段。设原序列有 $b$ 个标签分界，各连续同色段长度为 $\ell_i$，那么动态规划需考虑的跨标签剩余集合至多为

$$
\prod_{i=1}^{b+1}\left(1+\frac{\ell_i(\ell_i+1)}{2}\right)=O(n^{2(b+1)}).
$$

每个状态比较继续问跨标签探针和直接进入单色阶段的最坏成本。在纯单色阶段，最坏分支就是所有询问都未命中的分支。若它最终作出标签 $y$，那么沿路的单色区间必须覆盖所有仍属另一个标签的世界。可以只保留这些用于覆盖另一标签的探针，再按代价最小的区间覆盖安排，无须问支持 $y$ 的单色探针。按左右顺序做加权覆盖，尝试最终留下的两种标签，就得到该阶段精确成本。固定标签分界数时，整个算法的最坏计算量是多项式。两条错报的实验用一般有限状态求解，未使用这个多项式界。 [核心算法](interval_fault_plan.py) · [相关算法与查新边界](interval-fault-plan-prior.md)

## 什么时候固定清单已经最优？

如果某个标签的全部世界对所有可用探针都给出同一组答复，任何正确策略都需要在这组答复的路径上区分另一标签的全部世界。沿该路径使用的探针本身已经是一张能保证定案的固定清单。因此最优自适应策略和最优固定清单的最坏费用相等。这个一般论证与已有决策树文献里的集合覆盖构造同源。 [DFEP 第 4 节](https://arxiv.org/abs/1309.2796)

该条件适用于单错报模型中的任何**原报告点对**。要令它的阈值标签与报告本身相反，唯一可能的错报就必须是该条边。删掉这条边后的图仍连通，因此所有这些世界的相对坐标相同，只允许整体平移。任何精确差值补核都会给出相同答复。这个结论允许任意阈值、可信顶点区间和事前给定的补核费用。主回放的 223 项单错报歧义都核验了该条件。 [结果与条件逐项核对](interval-fault-plan-verification.json)

对于没有作为报告发布的目标，自适应可能严格受益。取四点环，路径 $0\to1\to2\to3$ 的三条读数都为零，弦 $0\to3$ 报告为 1，预算为一条。目标为 $x_2-x_0\ge1$，可补核 $1\to3$、$0\to3$、$1\to2$，每问费用 1。先问 $1\to3$。答零时，再用 $0\to3$ 区分；答一时，再用 $1\to2$ 区分。最坏费用为 2。三问中的任意一问若从固定清单去掉，都能找到真假相反却无法区分的两份修复，所以最优固定费用为 3。 [构造及完整答复表](interval-fault-plan-verification.json)

## 先例和复现

任意带费用的分类决策树、区间问法、按答复递推的算法都有先例。当前候选贡献是针对原始标签分界数给出的重排与精确状态界，以及该结构在有限可信渠道的容错判断中的运用。已核对的来源未发现相同的最坏费用结果，最接近的早期区间搜索论文目前只核对到元数据和摘要，发表优先权尚不能确定。 [原文核对](interval-fault-plan-prior.md)

在本文所在目录用 Python 3.10 或更新版本运行，无需第三方包。

python -B interval_fault_plan_run.py station-tmax-through-2025.csv.gz transit-optimality-fixtures.json.gz replay

运行时，先用结构化或一般有限求解器编译标签和候选值表。$0$ 费用表示证据已足够。无有限费用时 `counterexample` 给出证据不足的两个世界编号。有可行策略时，用 `start()` 开启会话，`next_probe()` 返回下一项询问，`observe(answer)` 纳入可信回复，直至 `label` 有值。与所有允许世界都矛盾的回复会显式报错。
