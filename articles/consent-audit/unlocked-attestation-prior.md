# 公开最少读数证明，同时保留每个原有未知时刻的不确定性

设 $A$ 是原档，$C$ 是加入原始公开读数后的非空有界整数差约束域，$x\in C$ 是保管人掌握的实际时间表。新增的真实比较集合 $Q$ 只缩小公众认为可能的真值范围。它须同时满足两项要求。第一，剩余的每份表都无法用比原证书更少的读数在 $A$ 下证实报告。第二，在 $C$ 中有多种可能值的每个受保护坐标，在 $C\cap Q$ 中仍有多种可能。以下费用按新增比较条数计算。

## 已知的几何与保密机制

- Benedikt、Bourhis、Jachiet 与 Tsamoura 已在数据库视图设计里同时要求支持一个效用查询，并阻止从发布视图确定受保密事实。其定义用不可区分的数据库实例和查询决定性描述这两项要求。这里采用的是同一类发布目标，具体的效用命题是原读数是否达到最少，保密对象是整数差约束中的原始坐标。[效用与非披露并存的视图设计](https://doi.org/10.1145/3488370)
- 数据库统计披露研究早已分别定义能否推断某个精确值、能否将其限于过窄区间。表格隐藏研究也用图上的回路保护敏感单元格。因此，保护每项可能值区间和用图检查推断披露都有直接先例。判定本次证明包蕴含什么，并不覆盖外部观察者可能掌握的附加资料，若发布与拒绝的策略本身可被观察，还可能有额外信息。[区间披露保护](https://pubsonline.informs.org/doi/10.1287/ijoc.10.3.309) · [表格单元的精确披露控制](https://www.sciencedirect.com/science/article/abs/pii/S0305054804000863) · [发布与拒绝策略的信息泄露](https://theory.stanford.edu/~nmishra/Papers/denialsLeakInformation.pdf)
- 差约束闭包给出每对坐标的最紧上下界。刚性类收缩、图势的可行移动、按约束排除反例的最小溯因已有研究。以下候选贡献聚焦于按阈值压缩字典、证明公开选读费最少，以及避免新增精确推断这三者同时成立时可验证的结论。[Miné 的闭包与投影定理](https://arxiv.org/pdf/cs/0703073) · [Knauer，第 1.4 节](https://pageperso.lis-lab.fr/~kolja.knauer/knauer_kolja.pdf) · [隐式击中集溯因](https://arxiv.org/pdf/1604.08229)

## 每个方向保留的候选数

把原有或新增的每条 $y_j-y_i\le c$ 看成弧 $i\to j$，用真实势 $x$ 重加权，弧长 $s=c-(x_j-x_i)\ge0$。若闭包最短路长为 $D$（重加权前后下式相同），坐标 $i$ 的可能值区间宽度为 $D(0,i)+D(i,0)$。因此它被精确确定，当且仅当 $i$ 与原点在零余量弧图中互达。加入正余量弧无法构成新的零长往返，即使其他附加弧也一起加入。

对每个有向比较方向，保留真实值处恰取等号的候选（若有），再保留所有留有正余量的真实候选中最强的一个（若有）。任一成功方案中的较弱正余量候选均可用后者替代。新证词蕴含原证词，因此仍能排除全部坏世界，且其弧长仍为正，零弧图不变。合并同一方向的重复证词只会减少条数。由此压缩字典保留原问题的可行性和最小条数。若每级阈值有不同价格，更强候选可能更贵，需额外比较价格与蕴含关系。

同一推导也适用于较宽的保护要求。若每项要保留至少 $K_i+1$ 个可能整数值，设 $K=\max_iK_i\ge1$。每方向分别保留存在的余量 $0,\ldots,K-1$ 的候选，再保留余量至少为 $K$ 的最强真实候选，至多 $K+1$ 项。更强的最后一项也无法出现在长度严格小于 $K_i$ 的违规往返上。该结论保护的是可能范围的宽度；若额外要求在实际值两侧分别保留特定余地，应单独检查相应上下界。

## 怎样公开复核

对 $Z=C\cap Q$，有两份可以只从公开不等式生成的假想时间表。令 $\ell_i=-D_Z(i,0)$、$u_i=D_Z(0,i)$。三角不等式保证两表都可行且同时达到各坐标下、上界。只要提交两份可行表，且每个受保护的 $i$ 都有 $u_i-\ell_i\ge K_i$，公众就可用原始不等式逐行核查。整数区间包含中间所有整数。两表可以由从原点出发的正向、反向单源最短路得到。它们只是与公开材料相容的可能记录，不依赖保管人承诺它们曾经发生。[简单时间网络的距离图与可行解](https://www.sciencedirect.com/science/article/pii/0004370291900066)

在内部求解时，可对每个尚未被排除的坏世界加一条正子句，要求至少选择一个能排除它的候选；对每条新出现的零长原点往返加一条负子句，禁止同时选择其中所有新增弧。当保护所有原先未定坐标且 $K_i=1$ 时，也可静态编码无锁条件。把原本已定的原点分量标为 0，其他坐标各只允许 $-1,+1$ 两个层级，要求每条原有或已选零弧沿途层级不降。有这种标号就不可能从原点经受保护点又返回；反之，可将最终零弧图的强连通分量拓扑排序，按其在原点分量之前或之后赋号。这种存在性编码与上面的公开可行表证明可以独立核验。

## 即使原证书只要读两项，无锁修复也可能难以寻找

给定一个三均匀超图，判断能否将顶点分成两色使每条边都含两色，是 NP 完全问题。下面把该问题归约到是否存在任意条数的无锁补证。所有候选证词都为实际等号处的原点比较。[Schaefer 的布尔可满足性分类](https://doi.org/10.1145/800133.804350) · [Dinur、Regev 与 Smyth，三均匀超图着色困难性](https://cims.nyu.edu/~regev/papers/hyper_color.pdf)

- 每个顶点 $i$ 建坐标 $h_i\in\{-1,0,1\}$。每条超边 $e$ 建 $H_e,L_e\in\{-1,0,1\}$。对 $i\in e$，旧档加入 $H_e\le h_i\le L_e$。
- 报告只有两条 $S_l\le T_l$（$l=1,2$），端点均取 0 或 1。每条边、每个 $l$ 加入 $S_l\le L_e+1$ 和 $H_e\le T_l$。
- 真实表全为零，只公开 $S_1=S_2=0$。字典对每个 $h_i$ 包含 $h_i\ge0$ 和 $h_i\le0$ 两项。

**一读的坏世界。** 有某个 $L_e=-1$ 时，只读它就迫使两项 $S_l=0$；有某个 $H_e=1$ 时，只读它就迫使两项 $T_l=1$。若所有 $L_e\ge0,H_e\le0$，任一单读都能在原档中延伸为一份坏报告。具体可让某一对 $S_l=1,T_l=0$，若读的是报告端点，就选另一对。让各 $H=-1,L=1$，即可容许任意读到的 $h_i$。若读到一个 $L_e\ge0$ 或 $H_e\le0$，保留其值，令所有 $h_i=0$ 即可。故实际最少读数恰为 2；新证词需要堵住的正是上述两类极端取值。

**补证恰好对应两色。** 同时选择 $h_i\ge0,h_i\le0$ 会把原本能变化的 $h_i$ 锁在零。各点至多选一项时，其余保护要求也全部满足。所有 $h_i$ 可以同时先取零，再令 $H$ 全为 $-1$、$L$ 全为 1，使任一所考察的 $h_i$ 都能向被允许的一侧再变一个单位。每个 $H_e$ 可在全零表基础上单独降到 $-1$，每个 $L_e$ 可单独升到 1，每个 $T_l$ 可单独升到 1。$S_1,S_2$ 已在公开基线中固定。于是全部原先未定的坐标都有替代值。

要排除 $L_e=-1$，该边必须选到至少一个 $h_i\ge0$。若一个也未选，可令边内的 $h_i=-1$、其余 $h_i=0$，令该边 $L_e=-1$、其他 $L=1$、全部 $H=-1$，所有 $S,T=0$，得到相容反例。对称地，排除 $H_e=1$ 必须且仅须在该边中选到 $h_i\le0$；缺少它时取边内 $h_i=1$、其余为零，该边 $H_e=1$、其他 $H=-1$、全部 $L=1$、$S=0,T=1$。由此，一种无锁修复等价于一个可扩展为合法两色着色的部分赋色。取消保密要求后，发布所有候选就始终排除全部坏世界。

在此受限问题中，给定修复后可用闭包多项式检查每个保护坐标。能否排除所有一读替代也可多项式核验。对每个坐标 $i$，将两个报告违反区域在 $i$ 上的整数投影取并，再检查补证后 $i$ 的整个投影都包含在该并集中即可。因此不限制条数的存在性在这个受限类中已是 NP 完全。这个结论不评价一般 $p$ 的 NP 成员关系。

对于给定字典，即使每条证词都严格有余量，最少条数的判定也能编码集合覆盖。每个元素建 $e_j\in\{-1,0,1\}$，每个集合建 $z_s\in\{-1,0,1\}$。两条报告是两个布尔坐标 $T_l\le0$。在旧档案中加入 $T_l\le e_j+1$，对每项成员关系加入 $z_s\le e_j$。公开两个 $T_l=0$，真实 $e,z$ 均为 1。实际用单读无法证实两条，公开条件下的一读替代当且仅当至少一个 $e_j=-1$。只允许 $z_s\ge0$ 时，排除这些世界恰好要求覆盖全部元素。任何选择都保留 $e,z$ 全为 0 和全为 1 两份世界。因而最少条数仍可困难，而保护条件在这一族实例中自动满足。[有限归约核验](unlocked_attestation_boundary_check.py)

此次核查涵盖刚性时间网、零余量循环、统计数据库精确披露与区间保密、最小谓词集、隐式击中集和组合披露控制。尚未定位同时给出上述原证书成本合同、每方向双代表、以及二读情况下无预算存在性困难的独立文献。最短路、区间保护和约束选择的基本原理均有先例。
