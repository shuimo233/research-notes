# 运行方式、选择性答复与联合全拒绝的研究先例

本次审计把两个可比较的事实情境、有限种运行方式和一次可重放的发布规则放在同一个实验里。以下按原文核对各部分先例。公开任务给出真标签，运行记录给出模型输出，运行方式的抽签及答复门控由实验规定。同一项有两个可能情境时，模型的输入及参考答案可以不同。概率分母按同一个固定情境与同一套抽签规则计算。

## 运行方式足以改变模型行为

He 与 Thinking Machines Lab 区分了计算核自身的确定性与跨批不变性，展示推理时浮点规约受形状和批处理方式影响，并给出跨批不变的浮点算子。Yuan 等在 NeurIPS 2025 用多种系统配置检验生成复现性，报告评估批大小、GPU 数和 GPU 型号均可影响生成。ONNX Runtime 的官方说明则给出动态量化的具体机制，激活的尺度及零点在执行时计算。前两项研究主要涉及生成模型与 GPU，ONNX Runtime 文档解释机制。对于具体的 CPU、INT8、DistilBERT 和待审题目，是否真的发生判决变化要查原始执行记录。 [Thinking Machines 的实验及实现](https://thinkingmachines.ai/blog/defeating-nondeterminism-in-llm-inference/) · [NeurIPS 论文](https://proceedings.neurips.cc/paper_files/paper/2025/hash/f80094a824ba5912d4a2de169c404a40-Abstract-Conference.html) · [ONNX Runtime 量化文档](https://onnxruntime.ai/docs/performance/model-optimizations/quantization.html) · [冻结模型的题级分数与运行方式](monli-direction.md)

Kasa、Kasa 和 Negi 的 2026 年预印本直接比较同一文本和检查点在不同服务配置下的分类表现。它特别区分分数稳定与标签稳定，也考察了批形状和精度的作用。另一份更接近保密问题的研究 Quantamination 报告同批输入可以通过动态量化的共享参数影响其他输入的分类输出。这个先例确立了同批量化本身可以造成可观察的信息传导。当前实验的共同状态是发布规则指定的运行方式，测量的是同一组任务的全拒绝事件及其条件赔率。 [分类运行方式不变性预印本](https://arxiv.org/abs/2610.09111) · [Quantamination 原稿](https://openreview.net/pdf?id=zVMRxHg0Zj)

## 带拒答的自然语言任务已有直接先例

Geiger、Richardson 和 Potts 提供 MoNLI，以词汇蕴含、否定和单调性测试神经 NLI 模型，也给出训练与测试构造和数据。任务中的特定标注可以充当离线事实约束。Xin 等将高置信度保留、低置信度弃答置于选择性预测框架。Varshney 等直接在 NLI 和重复检测任务中评估按置信度弃答，也比较域内与域外行为。Kamath、Jia 和 Liang 的选择性问答工作展示，域外错误会影响置信度作为拒答信号的有效性。测试时利用真标签核对输出，只能描述带该检查规则的实验机制。部署若希望保证合法答复，需要另外给出可用的验证器、覆盖面和失效条件。 [MoNLI 原论文](https://aclanthology.org/2020.blackboxnlp-1.16/) · [选择性预测原论文](https://aclanthology.org/2021.acl-long.84/) · [NLI 选择性预测](https://aclanthology.org/2022.repl4nlp-1.23/) · [选择性问答](https://aclanthology.org/2020.acl-main.503/)

## 同一个抽签与逐项独立抽签

可靠性研究已有共同原因故障这一直接概念。若多个组件受到同一外部状态影响，它们可以具有固定的逐项失效率而出现不同的共同失效概率。Wang 和 Li 研究边缘分布和相关约束下的系统可靠性，报告不同依赖模型所得系统失效率的差异。将共同运行方式视为一个有限变量、计算同一运行方式下的整窗门控结果，是这一思路在已记录推理行为上的实例。 [NASA 技术报告](https://ntrs.nasa.gov/citations/20160005837) · [Wang 与 Li 的可靠性研究](https://doi.org/10.1016/j.ress.2017.12.018)

若两种路由对任一请求都有相同的方式分布，而共享分支只抽一次、独立分支逐项抽签，则两种路由的逐项拒答率相同。设情境 \(X\) 在同一运行方式下整窗共同拒绝的概率为 \(C_X(S)\)，逐项拒绝率乘积为 \(I_X(S)\)，独立分支权重为 \(\gamma\)。对固定窗口 \(S\)，实际全拒绝概率为 \(\gamma I_X(S)+(1-\gamma)C_X(S)\)。因此固定整窗的双向原始赔率门槛，可写成对一个 \(\gamma\) 的两条线性不等式。多个窗口、多个目录的可行权重是这些线性条件与 \([0,1]\) 的交集。这个关系直接来自混合分布，并且只要两条路由的单项分布保持一致就成立。在逐项拒绝率为正且独立分支权重为正时，提高独立分支权重会让归一赔率靠近 \(1\)，原始赔率则趋向两边的独立基线乘积比，可能经此上升。该计算也保留了率不相同所造成的证据。上一轮的区间证书允许不知道共享分支的完整概率表。若完整方式集合、抽样权重及向量已知，此处可通过枚举得到精确基准，以便检验低阶审计的效果。 [归一赔率模型及相关先例](audit-asymmetric-prior.md)

## 观测概率、赔率和可复验保证

Pufferfish 把不同秘密条件下同一个观察事件的似然比解释为后验赔率的乘数。它的完整隐私条件涵盖所有输出。StatDP 重复运行候选机制并统计检验可否证的失败事件。DP-Sniper 从两个输入条件筛选观察事件，再在独立样本上用 Clopper–Pearson 单侧区间和并集界计算似然比的高置信下界。Learn then Test 进一步说明多个候选规则上的有限样本风险控制可写成多重检验，候选选择本身需要计入统计保证。 [Pufferfish 原论文](https://doi.org/10.1145/2514689) · [StatDP 原论文](https://arxiv.org/abs/1805.10277) · [DP-Sniper 原论文及定理 1](https://files.sri.inf.ethz.ch/website/papers/sp21-dpsniper.pdf) · [Learn then Test 原论文](https://arxiv.org/abs/2110.01052)

有限已知面板的逐项概率和整窗概率描述规定的路由分布。估计未知线上方式占比、审计抽签只覆盖部分运行、用同一批样本选门槛和证明达标，都会增加统计问题。跨请求共享一个抽签时，同一个目录内的请求也不能当作相互独立的重复试验。若服务公开所用的具体运行方式，观察应包括该信息，并对相应联合事件重新审计。审计全拒绝事件也不能扩展到包含具体非拒答内容的观察。

## 查新范围

有限潜类模型早已使用给定共同状态后各项条件独立的乘积形式。若某项的条件概率不随潜类变，它可以直接从潜类混合求和中提出。这里采用该因式分解，消去归一化联合拒绝审计中不随档位变化的请求。 [潜类模型及条件独立的原始统计讨论](https://doi.org/10.1080/00273170802490673)

这次检索组合覆盖了批量推理数值可复现性、ONNX 动态量化、NLI 选择性预测、共同原因失效、已知边缘下的系统可靠性、条件似然比审计及有限样本风险控制。相邻先例已经涵盖每个组成方法。检索所见原文尚未给出同一 MoNLI 情境对、冻结量化运行记录、独立与共享路由的逐项等值对照，以及以真实执行记录枚举得到的整窗赔率来复核异质低阶证书的同一组合。候选新增证据限于实测组合与可复验的验收后果。文献检索不能确定优先权，也不估计真实服务中共享路由出现的频率。
