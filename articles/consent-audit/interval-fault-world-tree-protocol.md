# 无锚点时，自动找到更小的来源约束

本协议在运行新库存、合成测试或查看结果前冻结。用已经固定的 NOAA 气温和 BART 计划时刻。预算一时用既有单错报图及注入，预算二时用既有双错报图及注入，只在图上最少修复数恰好为二时采用有限世界。与原归档错报分开，允许至多一份新来源向量任意变化。库存、价格与错报模拟。阈值沿用 NOAA 的 1.0°C 和 BART 的 180 秒。

## 来源库存和对照

哈希文本 `<档案 ID>/tree/<原错报预算>/targets` 的首字节奇偶决定哪些原报告为目标。选择原列表中序号奇偶相同的边，目标为所有这些阈值的联合向量。可用比较为全部无序顶点对去掉目标对。所有点对由小编号向大编号。

每案提供 12 个小来源。对 `<档案 ID>/tree/<原错报预算>/offer/<序号>` 计算 SHA-256，首字节模 3 加一为所报比较数上限。将合法点对按 `SHA-256(该摘要 + 点对两端编号各一个字节)` 的字节序排序，首对的较小端点作为本来源锚点，从排序后仍以该端点为端点的点对中取到上限。实际条数可以更少。价格为 `3 + 第2字节 mod 8 + 实际条数−1`。合法点对为空则无来源。不同序号是不同模拟故障位置。

再提供三份完整复查。每份提供合法比较图按点对字典序贪心选出的同一个生成森林。每份价格为 `7 + 2×边数 + 哈希首字节 mod 7`，哈希文本同一前缀下使用 `full/<序号>`。完整复查都不直接核实任何目标。对照总价是购买三份完整复查，只有逐对核验它确实能耐一次来源错答才纳入费用比较。

## 算法和预设判据

独立优化仍对所有异标签世界对约束三重分离。识别是否存在每个来源的每个同答集合在其上连通的世界树。若有，用树上的异标签边生成候选约束，验证必要充分；若无，取全体异标签对。对候选约束去除重复和严格包含较小来源集合的约束。每份来源覆盖不超过两个保留约束时用带容量匹配，全局覆盖更多的来源按相同覆盖分组枚举，再解剩余的匹配问题。同组若买若干份取最便宜的不同来源，单组购买上限为需求。不可判输出两个异标签世界及一份兼容回复。记录持有世界树的数目、无树仍能走纯匹配的数目、约束压缩、较宽来源数及确切成本。无共同物理锚点指所有非常量来源的顶点集合交集为空。

核对完整回复中的零份和一份来源错答，替换为任一其他可行向量或一个全异向量的等价类。独立程序重建世界和库存、用所有异标签对重算最便宜价格、复验拒答证据。实用门槛为至少 50 份起初歧义且完整复查可判的不同原档案，联合最优累计节省至少 10%。结构门槛为至少 20 个起初歧义、无共同物理锚点、可判且实际纯匹配求解的配置。两者分开报，列明双错报松预算未入组情况。本协议预算二下的价格含义与预算一相同。

合成检查用 `Random(984177)` 生成 80 个四至六世界、各来源二至四个取值的小目录。逐棵穷举世界生成树，独立核对最大权树识别与失败情况。另以一个确实须分叉的四世界、三二值支路来源族，核验树压缩不依赖路径顺序；用四世界交叉二值划分构造无树但目标约束仍可纯匹配的明确例子。 [上轮共锚合同](interval-fault-joint-source-protocol.md)
