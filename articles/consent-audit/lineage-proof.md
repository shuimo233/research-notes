# 来源分区未知时的判别与共同记录

同一组报告别名有 $p$ 张显式给出的可能来源图，每张图把每个别名映到一个采集根。实际使用一张固定的图。每个情境的行为为稳定一位，目标为“所有情境均为零”或“至少一处为一”。在每个可能世界中，历史和未来共享至多 $f$ 个可任意错报的根。两种相反解释可以对实际的图和坏根有不同判断。所有健康根在每次行为读取中都如实报告。可信的关系查询返回两个别名在实际图中是否同根；这类查询的正确性另行保证。并非每个系统都有这样的可信通道。

一个菜单能保证判别，当且仅当不存在一对输出相反的世界及它们都能解释的完整菜单答案。若有，共同记录可依询问顺序交给任何策略；若没有，最迟读完整份菜单即可判定。有限输入中，两张图、两个真值、坏根和完整答复构成多项式长度的不可判别证书。证书核验只需重放原始记录，并检查同源答复和每个世界的强制错误根数。

## 空历史、一个行为位：行列覆盖给出精确条件

固定有序图对：在左图中真实位为零，在右图中真实位为一。历史为空，且两图在可信关系查询上的答案完全相同。建一个二分图：一个行为报告是从它在左图的采集根到它在右图的采集根的一条边。若这两个端点都诚实，同一份报告必须同时答 0 和 1，矛盾。因此一组共同报告存在，当且仅当能在左右各选至多 $f$ 个顶点盖住所有边。反向构造是在一边诚实的每条边上取其诚实值，两边均失实时任选。预算分边承担，单看最小点覆盖的总大小不够。这正是经典的带两侧配额二分图点覆盖。[Jansen，定义与已有复杂性](https://doi.org/10.4230/LIPIcs.STACS.2016.45) · [Kuo 与 Fuchs 的备件分配问题](https://doi.org/10.1109/MDT.1987.295111)

**强限制下的归约。** 当 $f$ 是输入的一部分时，判断整份报告菜单**是否仍可能有相反解释**是 NP 完全的，即使历史为空、只有一个行为位和两张显式图，且每张图单独都覆盖严格多于 $2f$ 个根。是否保证可判别则是其补问题。

从点覆盖实例及左右额度 $a,b$ 出发，先把额度截断到本侧顶点数。令 $f=\max(a,b)+1$；在左侧加 $f-a$ 个新中心，在右侧加 $f-b$ 个新中心，每个新中心连向对侧 $2f+1$ 个互不相同的私有叶。任一中心若未入盖，就须选超过对侧预算的叶，故两边余下额度恰为 $a,b$。反过来，原盖加所有中心就是新盖。为新图的每条边生成一个别名及一次查询，第一张图按左端点命名其根，第二张按右端点。构造大小为多项式；两边都有至少一个中心，故两张图实测到的根均超过 $2f$。若图身份已知，从每个不同根各取一票即可判定真值，因而同一图内不会存在相反解释。跨图的两种方向只交换左右，额度相同，是否能覆盖完全相同。这给出困难性，证书给出 NP 成员资格。结论针对**没有提供区分两图的可信关系读取**的菜单；若另给一问就能得知实际图，上述实例当然可以判定。

## 带历史的多情境：至多三根的冲突足够

先排除与已见可信答复不符的图。在每一有序图对上，若有可购买的可信关系读取会给不同答案，这两图无法共享完整记录。否则，固定一个情境 $j$ 作为右世界中值为 1 的见证。令 $L_u,R_v$ 分别表示两个世界里相应根允许失实，左右分别最多取 $f$ 个。建立下表的约束，每行要求列出的至少一个根可失实。

| 证据 | 必须命中的根 |
| --- | --- |
| 左世界历史中一条正记录，左根为 $u$ | $L_u$ |
| 右世界同一情境的正、负历史报告来自 $p,z$ | $R_p$ 或 $R_z$ |
| 右世界在 $j$ 有负历史记录，右根为 $z$ | $R_z$ |
| 未来读 $j$，左右根为 $u,v$ | $L_u$ 或 $R_v$ |
| 某情境有来自右根 $p$ 的正历史记录，又能在该情境读左右根为 $u,v$ 的一份记录 | $R_p$、$L_u$ 或 $R_v$ |

必要性逐条来自健康报告的约束。例如最后一行中，若 $p$ 健康，右世界在该处必须取 1，故左右未来根不能都健康。充分性可直接构造：右侧取 1 的情境恰好是 $j$ 加上全部健康右根报过 1 的情境；其余取 0。第二、三行保证健康右根没有与此矛盾的历史负读数。第四、五行保证每当未来两边的预测不同时至少一边失实。用健康一侧的值填入读数，即得完整的共享答复。枚举见证坐标和有序图对即完备。这个构造也可由经典 Davis–Putnam 变量消元推出。[Davis 与 Putnam](https://web.stanford.edu/class/cs357/DP60.pdf)

在固定的坏根指标上，三项有时不可省。取两个不同情境 $j,c$，已要求右世界在 $j$ 为 1；在 $c$ 有一条历史正记录，左右根是 $H,p$，未来还能在 $c$ 读左右根为 $l,r$ 的一份记录。取 $f=2$，令 $H$ 已失实，$H\ne l,p\ne r$，其余无关根健康。三个可变根全健康时存在矛盾；只让 $p$、$l$ 或 $r$ 其中任一个失实就能解除。任何只含这三个原始指标的正二项子句，只要能拒绝全零，就会同时拒绝某个应当接受的单点赋值。因此用同一组根指标直接写成单调合取范式时，确有必要保留三项约束。此例不排斥使用辅助变量或不同编码。

任选一项尚未满足的约束，分支选择其中一个根，左右总共最多选 $2f$ 个。固定图对和见证坐标的树有至多三路分支、深度至多 $2f$（超预算子节点直接终止）。令 $n$ 为情境数，整菜单可判定性检查的时间上界是 $p^2 n\,3^{2f}\,\mathrm{poly}(|I|)$，其中 $|I|$ 是显式输入长度。构造过程还能返回二世界证书。在未确认任何未来读数时只需判定当前历史，与上一轮的已知映射检查逐图一致。取决于难例和 $f$，这个界仍可能很大。[带组额度的命中集](https://doi.org/10.4230/LIPIcs.MFCS.2023.55)

## 成本与验证

完整菜单可判别时，用不同前缀仍相容的**所有**图及行为决定能否停机。每个未买项目的最坏费用为该项价格加两个可能答复中较大的最优后续费用，取最小即得精确解。已定或不可达分支计零。实现按已读与两个答案缓存，至多 $3^k$ 个状态，$k$ 是菜单项目数。可判别性的参数界没有消去这棵费用树。按其中任一张图把同根同情境的别名删重也可能出错，因为它们在另一张图中可属不同根。[程序](lineage.py) · [逐字枚举小域的独立求解器](lineage_check.py)
