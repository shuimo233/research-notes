# 稀疏真证词目录的全窗口核验

冻结 CI 与 BART 输入，使用与 [三请求试验](multi-odds-protocol.md) 相同的档案 Git blob 和相同的抽样顺序，各取 108 份。按旧报告中的 (u,v) 字典序找尚有不确定性的差值。若其公开整数差范围为 [L,U] 且 U−L≥2，令 h=(U−L−1)//3，构造两个请求“差值至多 L+h”和“差值至少 U−h”。如果加入这两个请求后仍有所有已选请求都为假的实况，就保留这两个请求。取前三个这样的差值。少于三个记录并跳过。每份评分档案恰有六个请求，其中任一实况最多三条为真。只读公开档案，不读取原始记录。

每种真证词仍以 1/2 概率发布；每种合法完整回复保留本实况独立概率的一半。主试验用整数精确列出所有真集合，用透明的按真证词数分表的策略在 32/7 或 93/20 的目标下核验所有观察窗口。若无两组真三元组共享两项，则用 32/7；有则用 93/20，后者是固定的有理上舍入界。若最大真数不到三，则用相应的 1、2、3 上界。记录看同一消息的有序实况对，比较枚举所有窗口和按分母实况的真请求集合只选一个窗口的精确结果。计数只含两实况都允许的消息，与运行时无关。

主判据为至少 40 个包评分，所有档案在两个核验法上的实际最大倍率完全相同，目标证书全通过，且对应窗口不等式总数减少至少 4 倍。另记录能从实际可行模式提供数学下界锚点的数量，包括是否能由重叠三元组证明阈值 2+√7。有限样本以事前构造的档案为单位，汇总去重真集合结构及实际独立对照。完整向下封闭情形的锐界另用小实例和直接概率规划交叉检查。
