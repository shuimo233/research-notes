# 来源分区未知时，怎样判断一组报告足以排除风险

查证日期为 2026 年 11 月 23 日。第一轮核对来源依赖、可信同源查询及带价测试模型。第二轮单独检索两张候选分区造成的共同记录、计算复杂性，以及有历史记录时的参数化算法。这里的“来源”指共享一个故障额度的上游根。坏根可以在不同报告中任意作答，每个可能世界的同一批坏根贯穿历史与未来。

**最接近的直接前人结果是 1987 年的备件分配。** 一张矩阵的标记单元要由指定数量的备用行和备用列覆盖，与固定两张分区、固定一对相反真值的审计子问题同构。带历史的多坐标算法还用到 1960 年的布尔变量消元，以及已有的带组配额命中集。值得单列的是这些已有工具如何给出来源审计的两个可验证结论：每张分区单独有足够的独立来源仍可能无法合并判断，以及寻找任意非空风险集合时只需处理至多三个根的局部冲突。[Kuo 和 Fuchs，1987](https://doi.org/10.1109/MDT.1987.295111) · [Jansen，2016，第 1 节](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.STACS.2016.45) · [Davis 和 Putnam，1960，第 210 页规则 III](https://web.stanford.edu/class/cs357/DP60.pdf) · [Inamdar 等，2023](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.MFCS.2023.55)

若固定菜单同时读出所有答案，给真值 x 配上其可能答卷集合 Ωπ(x)，未知分区所得集合就是对 π 取并。于是“每张分区分别可解”只排除了同一 π 里的相反世界，还需要排除跨分区答卷交集。这一原则直接落在对抗信道并集及零错识别理论内。只需分隔不同函数值，在函数纠错编码中也已有明文规定。[Ravagnani 和 Kschischang，第 3.2 节定义 3.2.1](https://arxiv.org/pdf/1706.05468) · [Function-Correcting Codes，第 II 节](https://yaakobi.net.technion.ac.il/files/2024/02/80_FCC_IT23.pdf)

三别名例可以把额外核验的价值说清。设只有一个真值位及一个坏根额度。候选分区为 `a | bc` 和 `ab | c`。别名 b 在历史中先后报 0 和 1，a 报 0，c 报 1。b 所在的根必坏，于是第一张分区的真值只能是 0，第二张只能是 1。以后即使反复询问，也可以始终让 a 报 0、c 报 1、b 在两个世界中作相同回答。一次可信的“a 与 b 是否同源”即可确定真值。这个例子需要给定历史。若所有可以区分任意两张分区的可信检查都能买到，且每张分区单独可识别，买完整菜单当然能识别；最小花费仍取决于检查价格和可提早结束的答卷。

## 第二轮：两张分区为何足以产生困难

固定左世界为全零，右世界的风险坐标集为指定的非空 X。先检查两张分区都符合已有可信核验，且对全部待购可信核验给出相同答案。各世界的历史记录与该世界真值有冲突的根必须列为坏根。对每一条查询风险坐标的未来报告，从它在左分区所属的根向在右分区所属的根连边。完整报告串可在两世界同时出现，当且仅当每条边至少一个端点可坏，左、右各自的坏根计数都不超过 f，并包含本侧全部历史强制根。两侧即使根名相同也要分别记账。给定这样的覆盖，逐条选择健康端要求的答案即可生成共同答卷。

这一覆盖问题在图算法中称为 **Constrained Bipartite Vertex Cover**。对两个部各自设一个上限的判定已知为 NP 完全。Jansen 第 1 节明列定义并将困难性归于 Kuo 和 Fuchs 的备件分配。Jansen 亦给出高次数顶点强制进入解的规则和至多 2kₗkᵣ 条边的核。Chen 和 Kanj 的标题相近，但他们论文的主定理还要求该覆盖在全图中具有最小基数，引用这一定理时须保留该条件。行列故障错误码也会用覆盖，但经典 cover weight 最小化选中行和列的**总数**，这里左右有独立预算。[Jansen，第 1 节与文献 17](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.STACS.2016.45) · [Kuo 和 Fuchs，IEEE 原文](https://doi.org/10.1109/MDT.1987.295111) · [Chen 和 Kanj，原文](https://www.sciencedirect.com/science/article/pii/S0022000003001533) · [Martínez-Peñas，定义 1](https://arxiv.org/pdf/2203.07238)

**附加保证可以在归约中保留。** 从左右上限 a、b 的普通约束二部图点覆盖出发，将上限截到各侧顶点数，取 f=max(a,b)+1。在左、右两侧分别添 f−a、f−b 个私有星心，每个星心有 2f+1 个新叶。任一可行覆盖必须选所有星心，两侧恰好剩余 a、b 个名额供原图使用。两侧至少各添一颗星，因此两张分区都拥有超过 2f 个有实际报告的根。每条边造一个别名，分别按左右端点分块，全部别名仅在同一位上各产生一份报告。若分区已知，可按根的代表报告作多数判断。若分区未知，跨分区的相反真值能否给出共同记录，恰是原来的约束覆盖。反向交换两张分区可把共同答卷逐位取反。构造大小为多项式，猜两组坏根及答卷即可验算。故空历史、两张候选分区、一个真值位和上述各分区多数保证下，“存在共同完整记录”仍为 NP 完全，相应的“总能识别”判定为 coNP 完全。构造中没有能分开两张图的可用可信检查。强制星是已有的高次数点规则；这段推论保留的是审计输入的保证条件。[Jansen，第 1 节](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.STACS.2016.45)

## 任意风险集合与历史记录：冲突为什么只有三项

设 p 是显式候选分区数，n 是坐标数。枚举有序分区对，排除与历史核验矛盾或能被未来可信检查分开的组合。再枚举右世界一个必须为真的坐标 j。其余右世界真值记 x_c，根被列坏分别记为左侧 L(u) 和右侧 R(v)。以下为原问题的直接逻辑编码。

| 资料或要求 | 子句 |
| --- | --- |
| 左世界的一条历史正报告来自根 u | L(u) |
| 右世界历史在 c 收到来自 v 的正报告 | R(v) ∨ x_c |
| 右世界历史在 c 收到来自 v 的负报告 | R(v) ∨ ¬x_c |
| 同一条未来报告在两边属 u、v | L(u) ∨ R(v) ∨ ¬x_c |
| 右世界至少有一个真坐标，当前分支以 j 为见证 | x_j |

每个子句至多涉及一个真值变量。对每个 x_c 把每个含 x_c 的子句同每个含 ¬x_c 的子句归结，即可消去全部真值位。这是 Davis–Putnam 的原子消元规则。于是正负历史相冲得到两个右根的冲突；在 j 上的历史负报告强制一个右根，未来报告约束一个左根或一个右根；历史正报告与同坐标未来报告联合产生一个左根、两个右根的冲突。重合根只算一次。所有剩余条件都是“这至多三个根中至少有一个坏”。反向构造也很短：取 X 为 j 加上所有含健康右根正报告的坐标，二元历史冲突保证这些坐标没有健康右根的负报告，二元和三元未来冲突保证两端都健康时无需给出不同答案。整个消元在显式记录数的多项式时间内完成。[Davis 和 Putnam，第 210 页规则 III](https://web.stanford.edu/class/cs357/DP60.pdf)

把左侧和右侧分别作为上限 f 的组，所得问题直接落入带组上限的 Fair Hitting Set。任选一条尚未命中的冲突边，分支选其中一个仍有配额的根，深度至多 2f，分支数至多 3。总时间上界为 p² n · 3^(2f) · poly(输入长度)。这证明固定 f 时能有效判定整份菜单是否存在共同相反解释，并可恢复两个解释及共同记录。最便宜的自适应测试树需要另行优化，其计算代价不由这个上界给出。命中集、一致性诊断和有界秩分支均有直接先例。与输入有关的推导在于稳定真值位能够逐一消去、残余冲突的秩至多三。[Inamdar 等，MFCS 2023](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.MFCS.2023.55) · [Reiter，1987，定理 4.4](https://cse.sc.edu/~mgv/csce580f11/gradPres/reiter-diagnosis.pdf)

**有些历史确实需要三根冲突。** 设见证坐标为 j，另一个坐标 c 历史报过一次正值，两张分区将该别名分别映为 H 和 p；未来还要读一次 c，别名分别映为 l 和 r。同侧满足 H≠l、p≠r。取 f=2，固定左根 H 已坏，另外无关根均健康，且无其他记录约束。右根 p 单独坏时可以让 c 取零；左根 l 或右根 r 单独坏时可以让 c 取一。三者全健康则两个读数要求矛盾。因而在这三个可变指示量上，精确可行条件就是 R(p) ∨ L(l) ∨ R(r)。任何能拒绝全零的至多二项正子句，都会拒绝某个本应接受的单点赋值。此例证明了保持原有根指标、不加辅助变量、用单调合取范式直接表达可行性时，秩三界能取到。允许扩展编码或改变变量后，需要单独论证表达能力。

## 检索范围与归属

回看上一轮的 $n+2^a-1$ 紧界时，另以 *representative families, disjoint extensions, witness subfamily* 检索。Fomin 等保留一个子族，使得对每个允许的扩展集，若原族存在不交且可独立扩展的成员，则子族也有。这使“为所有未来选择预存见证者”有了直接的方法论先例。本文上一轮的扩展对象是覆盖菜单，兼容关系还包含两组根的故障额度；在所核对的定理中未见同一上界和逐菜单唯一证人的构造。这个比较既不排除其他等价归约，也没有把上一轮的界推广到本轮的未知映射。[原始定义与定理](https://doi.org/10.1145/2886094) · [上一轮精确命题](source-proof.md)

发布前还按混合策略例子的主张复查了有相关噪声的自适应试验选择。Golovin 等已研究在非等价、相关噪声测试中主动选择付费证据，Chen 等也研究给定目标后仍条件相关的测试。它们采用贝叶斯模型，与本文在全部相容世界上保证正确的最坏费用不同。故本文的 8、9、12 只作为一个可复算的实例，不把“下一次买什么可以因上个读数改变”列作原创。[Golovin、Krause 与 Ray](https://arxiv.org/abs/1010.3091) · [Chen、Hassani 与 Krause](https://proceedings.mlr.press/v54/chen17b.html)

- 第一轮使用 `same-cluster queries`、`truth discovery source dependence copying`、`paid provenance entity resolution active queries`、`diagnosis determination worst testing cost`、`adversarial channel union fan-out sets`、`Byzantine quorum fail-prone systems M-consistency` 等组合，核读了 VLDB、NeurIPS、PMLR、作者稿和期刊原文。
- 第二轮使用 `constrained bipartite vertex cover separate budgets`、`spare allocation rows columns Kuo Fuchs`、`cover metric crisscross errors rows columns`、`uncertain source partitions Byzantine conflicting majority`、`Fair Hitting Set group upper bounds`、`model-based diagnosis conflict hitting set`、`Davis Putnam elimination rule` 等组合，复核 IEEE、Dagstuhl、JCSS 原文及作者稿。
- 在已核对的材料里，逐图可区分仍可能在信道并集中混淆，已有一般原理；带价查询树、跨世界错误覆盖、两侧配额判定、布尔消元和有界秩分支均有明确前人。未找到同一篇文章针对“可购买的可信来源身份查询 + 稳定任意风险集合 + 历史和未来共用的坏根”同时给出上述强多数限制下的复杂性和三根冲突编译。这个检索缺口只支持将成果表述为该审计协议的具体归约、可核验证据与实现，不能据此认定优先权。
