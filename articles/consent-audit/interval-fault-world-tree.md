# 没有共同锚点，哪些证据仍能精确选？

之前的联合核验依赖来源共享锚点。这一轮直接从所有可能答复出发，就能核对能否减少约束，并让两条档案错报的任务走同一个精确求解器。236 个原本有歧义的回放配置中，有 **147 个既没有共同物理锚点，又只需一次匹配**。其中一、两条档案错报分别有 50 和 97 个。这不要求新来源彼此给出同一组比较。 [数据汇总](interval-fault-world-tree-results.json) · [冻结协议](https://github.com/shuimo233/research-notes/blob/f141c94dfa7d1ae7ceb582ea4d6814ba0d05f97f/articles/consent-audit/interval-fault-world-tree-protocol.md)

## 从答复找世界树

每份来源在每个允许世界下有一个确定的真值答复。答复可以是任意有限向量。对世界 $u,v$，以两者答复相同的来源数作为边权，求世界完全图的最大权生成树。如果一个来源在 $n$ 个世界上有 $K$ 个不同答复，它至多给树边贡献 $n-K$ 份同答权。因为同答的每一类只能含森林；一类的贡献恰达其大小减一，当且仅当这类在树上连通。所以若最大树权等于所有来源的这个上界之和，恰能找到一棵树，使每个来源的每类相同答复都连通。这里树的顶点是已经枚举的世界，不允许添加未知中间世界。这个识别方法是已有超图树支撑或对偶连接树的直接应用。 [Klemz 等，第 3 节](https://i11www.iti.kit.edu/extra/publications/kmn-mtshl-14.pdf) · [Berry–Simonini，Characterization 4](https://www.mdpi.com/1999-4893/14/12/347)

一棵这样的树足以代替全部世界对。任意不同目标向量的 $u,v$，其树路径至少有一条目标向量改变的边。如果某来源能区分那条边，便能区分 $u,v$，否则该来源的同答类必须跳过路径中的不同答复。于是只需对树上目标改变的边要求至少 $2r+1$ 份不同答复。对一个来源而言，把各个连通同答类视作一个点，树只剩 $K-1$ 条发生答复改变的边。所以即使来源提供许多项读数，它实际只有至多三个不同答复时，至多命中两条需求边。条件取决于整个来源的答复如何分组。 [上轮共锚的路径条件](interval-fault-joint-source.md)

## 没有同答连通树，也可能只需匹配

令 $D(u,v)$ 为能区分两个异结论世界的来源集合。对所有异结论对，用同一个需求 $d=2r+1$。如果 $D(u,v)$ 包含另一个已要求覆盖的集合，满足较小集合也自动满足较大集合。因此只须保留不同且按包含关系极小的那些集合。一旦某个集合的库存少于 $d$，取这两个世界的答复，在相异来源间分配给两边，即可构造双方都能在预算内解释的共同回复。 [已有的覆盖支配规则与来源级见证](interval-fault-world-tree-prior.md)

把每项保留要求视为图中的一个顶点。如果每份来源命中至多两项要求，仍可用上一轮的带容量加权匹配找最便宜的清单。若有 $p$ 份来源命中三项或更多要求，枚举它们的购买量，扣掉覆盖后按剩余需求做匹配。对于命中集合完全相同的来源，最多需保留最便宜的 $d$ 份不同来源。若决定买 $k$ 份，只需买最便宜的 $k$ 份。这仍是按来源计错；两源恰好同答也保留为两条不同报价。分支上界为 $2^p$，实际实现进一步对相同覆盖分组。用树和直接用全点对，保留下来的极小集合相同。 [匹配补集的先例与实现](interval-fault-world-tree-prior.md) · [求解器](interval_fault_world_tree.py)

## 当前任务是否仍能由树边表示？

对每个极小区分集合，找出所有能实现它的异结论对，把这些对当作一组边。**存在一棵树能重现全部极小集合，当且仅当能从每组选一条边并使所选边构成森林。** 如果这样的树存在，每组至少有一个代表；反过来，任何这样的森林都能补成树，补边不会增加新的极小集合。这把“本任务能否由树边概括”化为独立代表选择。由图拟阵的独立代表判据，任意一些组的边并集的秩必须不小于组数。小样本核验逐组检查这个条件，并用完整生成树穷举交叉检查。此判据刻画的是按集合包含来重现约束。 [Rado 原始论文书目](https://doi.org/10.1093/qmath/os-13.1.83) · [Welsh 对独立代表定理的表述](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/F01356CBECD75DDB09C199FBCF127380/S0008414X00042735a.pdf/div-class-title-transversal-theory-and-matroids.pdf)

合成对照给出三个层次。一份四世界表的同答类迫使树分叉，任何路径都无法保持所有同答类连通。另一份四世界表采用两个交叉二值来源，没有同答连通树，但目标约束仍可由一棵树的边表示。第三份表有三个不同结论的世界，每种来源只单独识别一个世界；任两世界共享的极小区分集共有三种，任何树都只有两边。因此它连目标树也没有，但每种来源只命中两项要求，仍能精确匹配。80 份固定小目录穷举了 41,016 棵独立世界树，全部核对两种树判据。 [合成结果](interval-fault-world-tree-verification.json)

## 查新与复现

同答连通树的识别、受支配覆盖约束删除、图拟阵独立代表和容量匹配都有直接先例。这轮可定位的候选贡献是把这些条件接到同一个有限世界耐错采购合同，并在无锚点、一条和两条最少档案错误的任务上验证何时可直接匹配、何时还需精确分支。已核对的原文尚未定位到相同的联合结果。有限检索不足以确立发表优先权。 [查新记录](interval-fault-world-tree-prior.md)

在本文所在目录，用 Python 3.11 或更新版本、NetworkX 3.6.1 运行。工具以已完整列举的世界为输入，世界树本身不验证上游枚举是否遗漏。

```bash
python -m pip install networkx==3.6.1
python -B interval_fault_world_tree_run.py station-tmax-through-2025.csv.gz transit-optimality-fixtures.json.gz replay
python -B interval_fault_world_tree_check.py station-tmax-through-2025.csv.gz transit-optimality-fixtures.json.gz replay
```

把每个来源的各世界预测与价格写成 `Offer`，给 `world_plan(labels, offers, errors)`。其 `selected` 是固定采购清单，`witness` 是库存不足时的两世界与共同回复。获得实际答复后，`possible_labels` 返回仍兼容的目标向量。对预算内正确采购的答复，这个集合只有一个目标向量。
