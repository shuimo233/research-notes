# 档位占比不确定时的审计依据与先例

[上一轮运行档位实验](audit-runtime.md)固定了真实模型分数和每档的放行规则。这里研究的是另一项不确定性。模型与规则保持固定，同一档位分布在可声明的范围内变化。逐项独立选择和共用一档都用这个分布，两个实况也共同使用它。

## 混合分布与区间核验的先例

若已声明的基准档位分布为 \(u\)，允许的分布写成 \(w=(1-\delta)u+\delta v\)，其中 \(v\) 可以是任意档位分布。这是经典污染邻域的有限版本。该式等价于 \(w\) 属于概率单纯形且逐项满足 \(w_j\ge(1-\delta)u_j\)。它适合描述一部分调度能保证按基准抽样、其余构成未知的情形。虽然由此也能得到总变差上界，任意满足同一总变差上界的分布仍可能低于某一档的保底占比。实验指定的 \(\delta\) 属于压力测试设定，不能据此推断线上漂移范围。 [Huber 原论文](https://doi.org/10.1214/aoms/1177703732)

把共同档位视为有限潜类，给定档位后取得条件独立的响应概率，属于已有的伯努利乘积混合模型。在两个实况的相关窗口内，如果两档对每项给出的条件拒绝率相同，它们在条件乘积分布中的贡献可直接相加。把其占比相加也保留逐项独立抽档时的边缘率。对污染邻域，最佳与最坏问题都可以精确移到合并后的类别上。每个原档位分布产生一个类别分布，每个允许的类别污染向量也可在各类任选代表档位实现。这一约简依赖待比较的条件表和可用占比范围。若档位有不同的费用或额外的个别约束，需要相应保留信息。 [Allman、Matias 与 Rhodes 的条件独立混合模型](https://arxiv.org/abs/0809.5032)

参数化模型检验已经研究过重复参数带来的依赖。Junges 等的参数提升方法有意放松部分参数依赖来产生有保证的外包，接受结论可靠，但外包里的点可能无法由原模型实现。档位审计中若把两路的 \(w\) 分别优化，或者单独取每项概率的上下界，也要区分这种外包与实际可实现的反例。 [参数区域合成及参数提升](https://doi.org/10.1007/s10703-023-00442-x)

## 为什么可以用单纯形上的有理函数证书

记 \(S\) 为大小为 \(s\) 的窗口。对于实况 \(X\)，令其第 \(i\) 项在第 \(j\) 档的拒绝率为 \(r_{Xij}>0\)。定义

\[
A_X(w)=\prod_{i\in S}\Bigl(\sum_jw_jr_{Xij}\Bigr),\qquad
C_X(w)=\sum_j w_j\prod_{i\in S}r_{Xij}.
\]

给定 \(w\)，若共用档位概率为 \(\lambda\)，则归一化的全拒绝倍率为 \(1+\lambda(C_X/A_X-1)\)。正向归一化赔率不超过 \(B\) 等价于 \(\lambda [C_P/A_P-B C_Q/A_Q+B-1]\le B-1\)，反向交换实况。在单纯形上令 \(H=\sum_jv_j\)，把 \(w_j=(1-\delta)u_j H+\delta v_j\) 代入后，方括号是齐次的有理函数 \(N/D\)，其中

\[
D=A_PA_Q,\qquad N=(C_PA_Q-B C_QA_P)H^{s-1}+(B-1)D.
\]

分母是系数严格为正的线性因子乘积。对任一以允许分布为顶点的子单纯形，作重心坐标代入后也保持这个性质。将 \(N,D\) 写到同一阶的 Bernstein 基中，函数值可写成系数比的加权平均，权重来自分母的系数与非负基函数。系数比的上界于是能给出整块的安全 \(\lambda\)。反例则须交付一个可行分布，在原式上直接核对超标。核验完整证书时，既要查各块系数，也要检查划分的叶子覆盖原单纯形。固定数值点的最坏观察值只能提供反例一侧的界。 [Hamadneh 等的单纯形有理函数界](https://arxiv.org/abs/1906.11037) · [Hamadneh、Abu-Falahah 与 Alqudah 的期刊论文](https://doi.org/10.1016/j.cam.2022.114430)

对严格正的齐次多项式，Pólya 定理保证乘以足够高次的 \(H\) 后，各项系数为正。Powers 和 Reznick 给出了次数的显式界。用它解释证书的完备性时，应保留严格正的条件。最优共享比例处可能恰等于门槛，因此通常交付可保的下界、可实现反例给出的上界及其差距。 [Powers 与 Reznick 的定量界](https://reznick.web.illinois.edu/11200.pdf)

## 两项请求就能让均匀和顶点检查都漏判

这是构造例，使用与实验相同的两档条件拒绝概率。八档中五档让实况 \(P\) 的两项拒绝率为 \((19/20,1/20)\)，另外三档为 \((1/20,19/20)\)。实况 \(Q\) 的两项拒绝率在八档均为 \(1/20\)。以均匀分布为基准，令 \(\delta=1/4\)，并记 \(x\) 为第一类五档的总占比。基准 \(x=5/8\)，允许 \(x\in[15/32,23/32]\)。原八档污染单纯形的顶点只会投影到这两个端点。

此时 \(C_P=19/400\)，\(A_P=(19+z)/400\)，其中 \(z=324x(1-x)\)。\(Q\) 的归一倍率恒为一，绑定的是 \(Q/P\) 方向。令 \(B=21/20\)，给定 \(x\) 的共享上限为

\[
\lambda_{\max}(x)=\frac{19+z}{21z}.
\]

该表达式随 \(z\) 减小而增大。因此最坏分布在内部的 \(x=1/2\) 达到，污染向量可取第一类质量 \(1/8\)、第二类质量 \(7/8\)。两端与均匀基准的上限可以直接比较。

| 分布 | 共享上限 |
| --- | ---: |
| \(x=15/32\) | \(25519/433755\) |
| \(x=23/32\) | \(21631/352107\) |
| \(x=5/8\) | \(217/3645\) |
| \(x=1/2\) | \(100/1701\) |

例如共享比例取 \(147/2500\)，均匀与全部顶点均通过，仍有可实现的内部超标。这个例子说明在组成权重保持一致时，归一化窗口限制也不会因判断了所有顶点而自动覆盖内部。它给出顶点对照的可证伪基线。真实档案中是否发生同类漏判需要由归档门控表和实际可行的漂移分布检验。


## 第 1044 个真实门控表可直接求出全局最坏比例

这是在冻结协议发布后独立核对的补充解析。按既有概率档案的零基索引 1044，正极性主目录在分差门槛 \(1/2\) 时的四对题号为 \((544,545),(168,169),(427,426),(826,827)\)。从已发布 float32 位模式还原分差并重做标签门控，可得 \(P\) 的第二项只在宽度 64 的档位取拒绝率 \(1/20\)，第四项只在宽度 96 和 128 的档位取 \(1/20\)，其余档位两项均各取 \(19/20\)。\(P\) 的第一、三项与 \(Q\) 的所有项都恒取 \(1/20\)。因此只要窗口不同时包含第二项和第四项，两个归一倍率都为一，包含两项的窗口都给出相同限制。 [冻结模型分数](audit-runtime-logits.tsv) · [原目录顺序和题号](audit-runtime-policies.json.gz)

令 \(x=w_{64}\)，\(y=w_{96}+w_{128}\)。两个会降低拒绝率的档位类不相交，\(P\) 对活跃两项的独立全拒绝分量是 \((19-18x)(19-18y)/400\)，共享全拒绝分量是 \((361-342(x+y))/400\)。因此 \(d_Q=0\)，且

\[
-d_P=\frac{324xy}{(19-18x)(19-18y)}.
\]

该值随 \(x,y\) 分别严格上升，所以最大值用完两类的漂移总预算，即 \(x+y=17/32\)。固定和后，分母为一个正的常数 \(361-342(x+y)\) 加 \(324xy\)，分式随 \(xy\) 严格上升。最大值在 \(x=y=17/64\) 达到，这个点满足档位占比下限。具体可把污染分布的 \(11/16\) 给宽度 64，\(5/16\) 给宽度 96。

两项的 \(Q/P\) 约束给出共享上限 \(\min(1/2,1/[21(-d_P)])\)。均匀分布的 \((x,y)=(1/8,1/4)\)，\(-d_P=81/1943\)，共享上限为 \(1/2\)。八个顶点投影到 \((11/32,3/16),(3/32,7/16),(3/32,3/16)\)，最小上限是 \(25625/56133\)，约 \(45.65\%\)。全部允许分布的精确上限为 \(29575/70227\)，约 \(42.11\%\)。这份真实门控表的内点将只查顶点的比例收紧约 3.54 个百分点。漂移集合仍由实验设定。
