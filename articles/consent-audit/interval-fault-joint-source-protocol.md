# 多个阈值能否共用一张耐错来源清单？

本协议在运行联合采购或查看其样本结果前冻结。沿用前次 NOAA 和 BART 的单错报原始差值档案、世界枚举、可信区间、阈值和 BART 的四边或六边子环选择。来源合同仍允许最多一份新来源向量任意变化。每份来源一次购买，错报、库存和费用均模拟。

## 使用范围和采购规则

对每份原档案尝试每一个顶点作共同锚点。目标为该档案中不经过该锚点的所有原报告阈值，继续使用原来的有向报告门槛，整份目标向量一起定案。每个锚点构成一个档案配置，另按底层档案 ID 去重统计。所有来源只返回锚点到其他点的一或两项差值，没有目标边的直接查询。小编号向大编号定向。

对于每个非锚点顶点 u，哈希文本为 `<原档案 ID>/shared/<锚点>/one/<u>`。用 SHA-256 首字节模 4 加一作独立单比较来源数，第 j 个的价格为 `2 + 第(j+2)字节 mod 6`，j 从零起。对于任意两个非锚点顶点 u<v，哈希文本为 `<原档案 ID>/shared/<锚点>/two/<u>/<v>`。首字节模 3 为零则不开设；否则来源数为 `1 + 第2字节 mod 2`，各价为 `3 + 第(j+3)字节 mod 7`。独立来源可以返回相同真值向量，仍是不同的模拟故障位置。

## 比较与成功条件

比较在同一库存中一次性最优购买全部目标，以及每个歧义目标单独最优采购后去重合并的费用。单项解并列时使用程序固定的顺序。对照按这一实际并列规则计，无法外推为所有独立并列处理的最佳费用。只有两个或更多目标曾经歧义的配置才用于费用门槛。记录不可判的两世界、共同回复，对全部可行清单按允许的任意一个来源向量错答核验所有目标。独立方法枚举删边恢复坐标，使用所有异标签世界对的覆盖需求重算购买最优值，跳过相邻化假设。至少 20 份不同的原档案具有两个或更多歧义目标且能联合定案，且联合费用在这一组比去重对照少至少 5%，才称联合采购达到预设实用性门槛。未达门槛按实报告。

理论核验用 `Random(203594)` 固定运行 200 项每来源至多覆盖两个位置的有价覆盖实例，需求数为 1、3 或 5，对照独立的有限集合优化。再生成 60 个 4 至 7 点的简单最大度三图，原问题为最小顶点覆盖。在另一个单错报环中把图的每条边做成一个原边界，再为它设一个保护边界。使用两份覆盖原边界和保护边界的来源，加一份仅覆盖保护边界的来源。所有包使用共同锚点且每份至多三项比较，禁查目标边。对原图全部顶点子集检查耐错联合采购等价。另验固定四点反例，去掉共同锚点后，循环相邻比较可全达标而一对非相邻的异标签世界完全同答。已知目标全部免费。 [上一轮的来源合同](interval-fault-source-bundle-protocol.md)
