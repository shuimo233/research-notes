# 登记：知道各词的边际分布，能否锁定整句的期望询问数？

在读取逐句相关性成本和运行该项计算之前登记。候选理论已构造出一个三角形反例。真实句子的成本来自之前已公开的 60 个 WSD 和 39 个 SemCor 共享词元包，逐句最小覆盖也已经公开。保留这些包的全部四类关系、词典候选、原先按 ID 破平的最小覆盖。先询问覆盖中的**全部**词元，再问尚不能确定输出的覆盖外端点，各付单位成本。这是严格的两阶段策略；上次测量的在线版能跳过第一阶段已经无关的词元，两种成本分报。[冻结输入](https://github.com/shuimo233/research-notes/blob/14c3ee9bd316a7c18761ef21d01b8c75795a4b16/articles/consent-audit/shared-sense-ledger.jsonl) · [两阶段验证查询](https://arxiv.org/abs/2107.00572)

每个词的候选义项边际设为均匀，同句各词允许任意耦合。金标不用于拟合概率。比较（1）独立耦合，（2）所有匹配边际的联合分布中，期望成本的精确上下界，（3）把每个待补问词元单独取最坏概率再相加的上界。各句的敏感性分别计数，两个语料分列。若两个语料各至少出现一个句子使联合最坏期望严格高于独立期望，才认为真实词典关系结构在两套材料上均显示了相关性敏感性。另测逐词最坏之和是否严格过宽，若没有也报告。此处测预算与耦合假设的关系，没有观测真实义项概率。

将每个已问词义映至它会强制补问哪些相邻未问词元，相同集合可以合并并相加边际质量。枚举覆盖内这些类别的联合状态，目标是各状态下强制补问集合并集的大小。用有限边际线性规划求上下界。对每个解输出非负可行联合分布和对偶价格，用有理数校验所有边际、全部对偶不等式和原对偶等值。若规模超限，列明缺失句子，不能以抽样代替完整结论。已知的相关稳健优化、割多面体及属性询问均须查新。[相关稳健随机优化](https://arxiv.org/abs/0902.1792)

理论核对使用任意简单图的关联二部图。每个原顶点是先问的二义词，每条原边是可能需要补问的二义词。用高度二的严格偏序实现 AND 关系表。候选公式为公平边际下最坏平均补问数等于边数与最大割之和的一半；以最大割及其补的等权混合给出证书。这个例子针对指定第一阶段。一般图上不假设这批先问词元恰为最小覆盖。用独立线性规划对小图的完整标号枚举核对该公式。即使成立，也须区分已有的割几何和此处的词义查询归约。
