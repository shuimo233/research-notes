# 气温档案回放中，精确规划的读数节省很小

用 NOAA 的真实逐日最高气温模拟只预先公开粗区间的档案。每项任务要输出六对站点的精确温差类别，按需查询各站原始读数。两组共 **5,055 项任务**。完整自适应规划比贪心少读 10 次，比优化过的固定覆盖少读 3 次，**节省未达到事前设定的 0.5%**。只保留边际、按独立补全触发位的对照用了相同次数。这个结果给出了词义实验之外的实用边界。[事前公开的协议](https://github.com/shuimo233/research-notes/blob/7851736c91ec68d31183b06e3dc17c31f1ee5bea/articles/consent-audit/station-query-protocol.md)

| 站点组 | 任务数 | 全读 | 离线证书 | 固定覆盖 | 贪心 | 触发位独立补全 | 完整自适应 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 北加州 | 2,518 | 12,590 | 8,739 | 8,822 | 8,834 | 8,827 | 8,827 |
| 纽约与周边 | 2,537 | 12,685 | 11,039 | 11,059 | 11,054 | 11,051 | 11,051 |
| 合计 | 5,055 | 25,275 | 19,778 | 19,881 | 19,888 | 19,878 | 19,878 |

以两组同一个日历月为单位重采样 2,000 次，完整策略的查询节省区间相对固定覆盖是 −7 到 14 次，相对贪心是 3 到 18 次。完整策略在北加州比固定覆盖多读 5 次，在纽约组少读 8 次。这些读数差相对于 19,881 次基线很小。粗区间配合任何一种有效的按需查询策略已能省约五分之一的全读次数。[逐年结果和重采样](station-query-results.json)

## 块分解保持最优，但完整统计改善的机会很少

事后证明给出了更强的解释。这里的等宽整数区间保证每条边的触发集合为前缀或后缀，因此知道区间端点与边际概率就能精确重建联合分布。新编译器仅用这些字段复现了全部 5,055 项查询路径。[后三分类边界与复现](end-cut-budget.md)

3,870 种站点、月份和区间组合中，块内分布在每种上都给出同一最优期望成本。493 种在块之间换掉联合分布，最优值仍一致。只保留边际并作独立补全，在 3 种组合上给出了严格增加原拟合期望费用的策略，达到事前设定的机制门槛。该对照的预测比原模型多约 2.51 次，实际按原模型计算该对照策略的代价只多约 0.013 次。模拟档案中的精确完整策略总拟合期望为 19,771.66 次，实测回放为 19,878 次。分组统计对最优预算的影响、对策略的影响和真实回放上的读数差可以处在不同量级。[块分解和预算证明](pair-budget.md)

即使提前知道所有气温来挑选最短查询证书，仍需读 19,778 次，比固定覆盖只少 103 次，约 0.52%。因此，预先要求省 0.5% 已经接近该任务的离线极限。两地出现的差异不宜推成算法对各地或所有精度的结论。任务使用由真值生成的区间，量化的是已有粗粒度档案后的精确核验。拟合使用各站独立模型，计分保留同日关联。本实验未测量数据传输时间、费用或实时部署性能。

## 复现

数据来自 NOAA GHCN-Daily，站点和取样规则见协议。仓库保留经过质控筛选的 2000–2024 年 TMAX 快照，单位为十分之一摄氏度。来源清单记录了十个原始站文件和解压快照的 SHA-256。NOAA 原文件可能是更新版本。分析使用仓库内冻结的快照。[数据产品与 DOI](https://doi.org/10.7289/V5D21VHZ) · [原始文件格式](https://www.ncei.noaa.gov/pub/data/ghcn/daily/readme.txt) · [快照](station-tmax.csv.gz) · [来源清单](station-tmax-sources.json)

~~~sh
python -I -B station_query.py run station-tmax.csv.gz reproduced
python -I -B station_query_check.py station-tmax.csv.gz station-tmax-sources.json reproduced
~~~

独立程序从原站文件重新提取快照，按不查表的温差极值算法核查全部 5,055 项任务的查询证书，并用不分块的决策树递归复算了 3,870 种输入的完整最优值和边际补全预测。准备快照时可运行下面的命令，校验参数可用 `--raw-directory` 增加原始文件逐站核验。[回放代码](station_query.py) · [独立核验代码](station_query_check.py) · [完整决策台账](station-query-ledger.jsonl.gz)

~~~sh
python -I -B station_query.py prepare raw-directory snapshot.csv.gz sources.json
~~~
