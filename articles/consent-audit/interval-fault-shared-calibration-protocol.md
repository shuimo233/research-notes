# 共享校准偏差的证据采购预案

沿用 [上一轮预案](interval-fault-asymmetric-quota-protocol.md) 的 NOAA/BART 档案、世界、目标、模拟价格和逐世界机构容量。验证一个世界内所有回复使用同一个校准参数时，能否更便宜地保证目标结论。将每份报价看成通过同一套跨系统比对流程得到的读数，报价向量每个坐标的真值均加同一个未知偏差，同时各坐标允许独立的绝对残差。故障源的整份回复任意。天气偏差区间为 ±6、绝对残差为 1，单位是 0.1 °C。BART 取 ±90 秒、绝对残差 1 秒。偏差和残差参数都是预先固定的机制压力测试，不代表真实档案设备误差。不同假设世界可有不同的偏差。真实标签仍由未加偏差的候选世界确定。

- 主方法保留来源间共享偏差。
- 强保守对照允许每个来源自行取相同范围内的偏差，但同一来源向量中的各坐标继续共用偏差。这是每份完整回复的精确投影。
- 诊断性理想下界把偏差固定为零，仍允许同样的残差与故障；另外检查其最优报价是否经得住未知共享偏差，报告失败数。
- 主库存使用已有报价。另报校准参考采购情景，给每个机构新增一份跨系统已知零差的校准读数，三个价格为 4、5、6。参考同样服从机构故障上限及相同的偏差与残差。这是资源改动后的机制检查，独立于主门槛。
- 分档案源和故障预算报告有歧义配置数、可保证数、主方法相对保守对照新增可保证数，以及共有可保证配置的总价和严格降价数量。资料结构和基准数值来自公开档案。采购成本、机构、故障与校准过程均是构造的。
- 主库存实用门槛预设为以下任一结果，并要求独立核验全部通过。第一，在至少 60 个不同的共有可行档案中总价下降 ≥10%。第二，在至少 150 个有歧义的不同档案上，按配置计的保证率比保守对照提高 ≥10 个百分点。
- 主求解把每对异标签世界的共同回复约化成两个偏差之差，由允许相等的闭区间生成冲突坐标掩码，保留包含极小者。每个掩码必须在当前世界配额下不可拆分。沿用两层正计数求解，并记录最优采购或者完整共同回复和两边偏差。
- 独立核验直接枚举各世界故障位置，对每种允许的两边故障并集求未坏来源的闭区间交。它重建档案世界与报价，核对每个组合的安全性、所有更低价组合和全库存无解证据。允许对同一个冲突掩码复用枚举结果。对全库存、每个报告组合以及最小价格之前探索的子集核验，无须把所有可能观测值离散化。
- 在种子 68051 的 100 个 3 至 8 源小库存上，覆盖零长度偏差区间、点交、反向符号的读数差、双世界不同区间、闭边界同时进入退出和不同机构容量。枚举全部子集，用独立故障对加区间相交核对。另报告有保证的回放样本和解码结果。无运行时间优越性主张。
