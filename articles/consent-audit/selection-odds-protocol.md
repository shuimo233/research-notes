# 在公开比较目录上校准选择概率

协议在枚举目录的可行真值模式及计算概率前登记。输入是上一轮 25 份已公开目录，包含 134 条比较，冻结文件 `selection-protection-packets.json.gz` 的 Git blob 为 `4cfee872ef4246f25728b8aacd8ff0faf3d5eb87`。不读取实际时刻。旧档案、原证书和各比较的真实性及充分性合同沿用此前公开包。

对每个目录，将在任一与公开输入相容的整数实况上为真的标签集合记作 S。只比较成功发布的非空 S，要求只从 S 中选，每个可用标签的概率至少为 1/(2k)，k 是目录标签数。对同一消息 j，在所有它为真的模式之间取最大与最小发布概率之比。整个目录用两者之比最大的消息计分。其含义是，相对只知道比较成立，额外知道该消息被选中后，两个原本都相容的实况的赔率最多再变化多少倍。

对照是在所有真实标签间均匀选择。精确方案为每条标签求一个固定正权重，然后在当前真实标签中按权重归一化。使用公共差约束枚举可行的真值模式，以线性规划最小化最坏概率比。数值求解器为 SciPy 1.16.3 的 HiGHS，正式计分须在有理数上核对原始与对偶目标相等。另独立用原始差约束重算全部模式，并直接从实际归一化概率重算比率。报告模式数、整数公分母采样方式、均匀和最优的比率、达到比率一的目录数，并保留边界失败的完整记录。

主判据为全部 25 项都得到并通过精确证书，且至少 5 项严格优于均匀选择。公开包只包含用于核验的约束、比较、概率权重和证明，不含隐藏时刻。发布者持有实际记录，并在同一固定场景内复用一次有缓存的随机结果。用小整数时刻表穷举核对符号枚举，并验证所需计算的最坏情形、精确比率边界以及概率下限。拒绝事件、运行时间、重复重新抽取及不同场景的联立超出此单次实验。
