# 环上固定补核与自适应补核的最坏费用分离

这个补充在推导下述公式后登记，在生成及运行后续检验前冻结。取 2h 个点的简单环。路径边报告零，端点之间的报告为 1，可信区间统一为 [0,1]，预算为一条错报。按删端点边、删第一条路径边、删第二条路径边等顺序编号。把修复顺序写为 L_h,…,L_1,R_1,…,R_h。目标是真实修复在右半段，等价于未归档的点对 h−1 到 2h−1 的差值至少为 1。

准许两类单位成本探针。第一类含靠近中间的 j 对 L_i,R_i，1 ≤ j < h。第二类区分一个且仅一个 L_i，必要时取区间问法的另一答复。每项用原整数差值作答。检查 h=2 到 9 枚举式最优成本恰为固定 h，自适应 1+ceil(log₂ h)。再在 h=16,32,64 实际生成图和所有修复的数值表，核对结构化求解的最坏费用。大集合的固定最优性用逐对核验每个 L_i 与 R_i 之间唯一能区分的探针，不运行通用的指数枚举。另保留四点环的已公布费用表和真实回放结果。连续区间结构必须从实际点对差值复算。
