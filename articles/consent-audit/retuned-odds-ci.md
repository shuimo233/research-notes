# 联合发布可以有多少次直接跳过求解？

在六个开源项目的 CI 时间档案中，预先登记的拒绝预算检查排除了全部 **39 个不可行目标**，其余 74 个目标均有可核验的概率表。共抽取 72 份公开档案，41 份能构造两类关于原报告中时间差的更细请求，产生 113 个目标。实验只用公开差约束和已经披露的读数。 [事前协议](https://github.com/shuimo233/research-notes/blob/0ba5a1af18879dc0febb561f70912d25ba0ab705/articles/consent-audit/retuned-odds-ci-protocol.md)

最严格的单侧目标往往不可行。更有挑战性的中点目标在 41 份档案中有 3 份不可行，检查排除了全部 3 份。113 个目标均用完整规划复算。独立核验器从公开边重建证词、可行模式与原单侧最优值，用有理数核对可行方案或矛盾证书。[结果](retuned-odds-ci-results.json) · [逐项证书](retuned-odds-ci-policies.json.gz)

## 两边各只有一条证词

41 份可评分档案只有 6 种去重的真值模式与目录宽度，其中 37 份每边只有一条证词。这个简单结构允许直接求到最优概率表。设最低服务率与唯一证词的概率下限都是 $1/2$，每侧维持单独观察的最优赔率 2 倍，并且存在两边均无证词的实况。只要一侧可答，它的拒绝概率必须恰为 $1/2$。这是因为它不能超过 $1/2$，而与必拒绝实况的赔率约束又要求它不低于 $1/2$。所以该情形没有可以重调的边缘概率。

如果两边从未同时可答，各实况的联合表已由边缘确定，最优联合比率为 2。若存在双方均可答的实况，两个同向格“双方拒绝”和“双方成功”必须同占概率 $t$，两个只有一侧成功的格各占 $1/2-t$。若沿用独立基线各兼容配对最低概率的一定比例 $g\in(0,1]$，此处有 $g/4\le t\le 1/2-g/4$。双拒绝跨到全空实况的比率是 $1/t$。若某实况只有一边能答，相应的单边成功格还要承受 $(1/2)/(1/2-t)$ 的比率。两项在 $t=1/3$ 相交。

因此，当两边有时同时可答、但从未单边可答时，最优比率是 $4/(2-g)$。只要还存在一种单边可答的实况，最优比率就是 $\max(3,4/(2-g))$。这些公式沿用固定 Bernoulli 边缘的经典耦合范围，特殊之处是同时计算真实配对和全空拒绝的赔率。 [边缘约束下的概率界](https://repository.tudelft.nl/file/File_c6ea0c49-8eb3-4f3f-b5d8-d9b59fb6aa97) · [相关发布先例](retuned-odds-prior.md)

这条公式是在看到 CI 结构后加上的。对所有 5 种合规的二元模式族与 5 档比例，直接规划在闭式值可行、在略低的值不可行。公式也覆盖并复核了 CI 样本中的 101 个目标。对剩余档案再用拒绝预算排除 7 个目标，合计 **108/113 个**可直接判定。这个数字属于同批数据的事后核对，且依赖二元目录在样本中占多数。其余 5 个目标仍由完整规划处理。

## 复算

```bash
python -B retuned_odds_ci.py public-optimality-packets.json.gz replay-ci
python -I -B retuned_odds_ci_check.py public-optimality-packets.json.gz replay-ci
python -B retuned_odds_binary_check.py replay-ci/retuned-odds-ci-policies.json.gz
```

重求概率表使用 Python 3.13 与 SciPy 1.16.3。独立核验只用 Python 标准库。拒绝预算和二元闭式可直接调用 [retuned_odds.py](retuned_odds.py)，输入是公开可行的真假组合与合同参数。证据支持将拒绝预算用于公开可行性筛查，实际使用仍须确定请求结构是否满足方法的前提。
