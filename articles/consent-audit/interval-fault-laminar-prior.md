# 嵌套来源预算与机构分组采购的先例

## 共同答复与故障集合

固定已买的来源集 \(S\)。每份来源的完整答复是一项，两个世界 \(x,y\) 在所买来源上的差异集合为 \(D=\{i\in S:x_i\ne y_i\}\)。如果一份共同回复能由这两个世界产生，每个差异坐标必至少有一方出错。各来源的错误允许任意替换，且允许的故障集合对取子集封闭，因此存在共同回复恰当且仅当 \(D\) 可分为两个允许的故障集合。反向构造逐位置选取 \(x\) 或 \(y\) 的真值。在各来源可返回向量的情况下，同一份向量的所有分量仍按一个来源合计。定义两世界可混淆为可见答复集合有交已有明确先例。 [Ravagnani–Kschischang，定义 2.3.1](https://arxiv.org/pdf/1706.05468) · [此前的来源级距离](interval-fault-source-bundle.md)

Ravagnani 与 Kschischang 的定义 4.1.5 和评注 4.1.6 给出不相交坐标域分别受限的乘积通道。例 2.2.5 明确给出两个域各能错一项时，任意两条可分辨消息至少在一个域上相差三项。第 9.1 节允许多个对手先后改动彼此可重叠的可操作域；这里同时约束同一最终故障集合在各域的大小。两种合同应分别检验。 [Adversarial Network Coding，例 2.2.5，定义 4.1.5，第 9.1 节](https://arxiv.org/pdf/1706.05468)

## 同一套嵌套配额下的精确判据

若允许且仅允许 \(|F\cap G|\le b_G\) 对每个约束组 \(G\) 同时成立，且各组互斥或嵌套，那么共同答复恰在所有组都满足 \(|D\cap G|\le 2b_G\) 时存在。必要性由两个允许故障集合的并得到。对充分性，给组的包含森林补上一个根，把各来源放进最小含它的组，在深度优先顺序中使每个组占一段连续区间。删掉不在 \(D\) 的来源后，区间性质仍成立。将剩余来源依次交替分给两方，每方在任一组取得至多 \(\lceil|D\cap G|/2\rceil\le b_G\) 个。因此两个不同任务标签可保证分离，恰当且仅当至少一组在所买来源上给出 \(2b_G+1\) 个真值差异。任意给定一个能使各组都连续的共同顺序，同一构造也适用。 [Fife–Oxley 的层叠拟阵约束](https://www.math.lsu.edu/~oxley/LaminarMatroids_revised.pdf) · [Edmonds 的拟阵划分定理，定理 1](https://nvlpubs.nist.gov/nistpubs/jres/69B/jresv69Bn1-2p67_A1b.pdf) · [Doerr 的全幺模矩阵偏差](https://doi.org/10.1007/s00493-004-0007-x)

检查重叠边界时，可取三个来源，对三个二元组分别设配额 1。两世界在三个来源均不同，每组差异数恰好不超过两倍配额。任何允许集合却至多含一个来源，因为任意两个来源都共同属于某个受限二元组。两方无法分完三个差异，故无共同答复。两倍配额只是必要条件，任意重叠组需要额外检查。该精确判据也使用两种候选共享同一套配额。对于逐世界不同的嵌套配额，可以让红方在每组的差异数落在 \([\max(0,|D\cap G|-b_{G,\mathrm{蓝}}),\min(|D\cap G|,b_{G,\mathrm{红}})]\)，按组的包含树自底向上相加子组和直接成员的可行整数区间，再与此区间取交。直接加总两种配额会漏掉不同子树对全局配额方向不一致的情形。 [Adversarial Network Coding 的可混淆定义](https://arxiv.org/pdf/1706.05468)

## 两比较来源下的三域采购困难性

从三端子带权边多路割出发。将高于三度的顶点拆成一条链，每条原关联边挂在不同副本上。把每条链内边的权设为原图全部边权之和加一，每个原端子只固定一个副本。每个副本度至多三。不拆链的可行割费用至多为原总边权，所以最优割不断开任何链内边。这样得到仍具有三个固定颜色端子的最大度三带权图，并保留原最优割值。该增权步骤支持 NP-hard 结论。 [Dahlhaus 等原论文](https://doi.org/10.1137/S0097539792225297) · [Johnson 等关于三度图的另一条困难性边界](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.SWAT.2024.29)

把每个顶点作为待保证的需求行，颜色做成三个互斥来源域，各域最多错一份。端子只允许指定颜色，其余顶点允许三色。对每条原边 \(uv\) 和每个颜色，为允许此色的端点提供同一份价格为边权的来源。两端都允许时，来源同时覆盖两行。只有一端允许时，它仅覆盖该端。每个允许的顶点与颜色组合再加 \(3-\deg(v)\) 份价格为 1 的私有来源。于是它恰有三份来源，选此色作为该行的分离证据就必须全部购买。在此构造可设全局配额为 3，它由三个互斥域各至多错一份推出。判定每行仍是至少一个域三重覆盖。 [不相交域的分离条件](https://arxiv.org/pdf/1706.05468)

任何可行采购都可为每行选一个已满足的颜色。保留这些组的并已足够。反之，给各行指定颜色，购买相应来源的并即满足每行。先按顶点分开付费时，总价恒为 \(\sum_v(\sum_{e\ni v}w_e+3-\deg v)\)。同色相邻端点恰能省掉一份重复购买的边权。故最优采购费恰为
\[
\sum_e w_e+\sum_v(3-\deg v)+\operatorname{OPT}_{\mathrm{cut}}.
\]
每份来源最多覆盖两行，价格均为正整数。只有三域、每域错答上限为一、每份最多两项比较的限制都保留。根配额若收紧为 2，将多出全局五重覆盖这一可行选择，需要另行论证。 [三终端割的已知困难性](https://doi.org/10.1137/S0097539792225297)

将需求行物理地实现为单错报差值图的线性世界边界。若有 \(N\) 行，取端点 \(0,\ldots,M\) 且 \(M=N+1\)，沿路径报告为零，闭合边报告端点差 1，可信区间统一为 \([0,1]\)。每个删边世界均相容。按切点 \(1,\ldots,M,0\) 排序，审查路径边 2 至 \(M-1\) 的差值是否达到 1。切点 \(0,1,M\) 均为全假，其余每个切点仅翻转自己的目标。第 \(j\) 个需求边界可用锚点 \(0\) 至顶点 \(j\) 的比较实现，\(1\le j<M\)。任意含一个或两个需求行的来源用相应比较的单项或双项返回向量实现，查询都经过锚点，目标均避开锚点。每个异标签世界对之间有一个目标变化边界；能分辨该边界的来源也能分辨世界对两端，因此证明保留了域级覆盖要求，不会引入额外世界对限制。 [此前共锚相邻分离模型](interval-fault-joint-source.md)

## 两域的精确饱和情形

若只有两个可用域，每份来源最多覆盖两行，且每行的每个允许域恰有其阈值所要求的来源数，则同样可把每行指定为由一个域负责。购买费用可写成每行的单点代价减去共享来源所省的价格。忽略常数之前，一对行在选择颜色 \(0\) 和 \(1\) 时的共享项分别为 \(-w_0[00]-w_1[11]\)，其中缺少某颜色的共同来源时令其权为零。等价表达是
\[
-w_0+\frac{w_0-w_1}{2}(x+y)+\frac{w_0+w_1}{2}|x-y|.
\]
这只含单点代价和非负割边权，所以可由 \(s\)-\(t\) 最小割精确求解。乘二消掉半整数，单点代价整体平移成非负即可。锁定域的行直接固定标签。此证明使用恰足够的来源数，以便选择某域就固定选中集合。允许同一行域挑选部分报价时，还需处理这些额外选择；额外的非冗余总配额也会增加一类可行证据。 [Kolmogorov–Zabih，定理 4.1](https://www.robots.ox.ac.uk/~cvrg/trinity2005/kolmogorov_zabih_pami04.pdf)

## 查新边界

已核对的先例覆盖共同答复模型、不相交域的局部汉明阈值、嵌套拟阵和图割。值得单独审查的候选是将分域故障约束接入同一差值采购合同，并给出共享锚点、每包两项比较、禁止直核目标时的三域困难性及两域精确饱和边界。当前检索未定位到给出这些限制的同一来源。有限查新不足以确立发表优先权。
