
# 按拒绝行为分配共同档位的依据与先例

## 已有研究可直接采用的部分

Glasserman 与 Yao 研究了在不同仿真系统间复用随机数来减少比较方差的条件。Angel 与 Spinka 研究了如何在保留各自边缘分布的同时，使多个随机变量的每对不一致概率接近其总变差下界。共同随机量可以改变联合行为而保留边缘，这两项工作均已有明确结果。本文的调度合同固定各项的共同边缘，并比较两个实况的归一全拒绝倍率。 [共同随机数原论文](https://business.columbia.edu/sites/default/files-efs/pubfiles/4261/glasserman_yao_guidelines.pdf) · [多变量耦合原论文](https://arxiv.org/abs/1903.00632)

Allman、Matias 与 Rhodes 研究给定潜变量后各观测条件独立的有限混合及其可辨识性。这里沿用相同的条件乘积结构，把档位当作每组共享的有限潜变量。需要识别的是两份已知条件表在改变共同档位分布时产生同一个归一二项函数的条件。 [条件独立混合及可辨识性](https://arxiv.org/abs/0809.5032) · [固定档位和共同漂移的原实验](audit-runtime-drift.md)

Whittemore 关于列联表可折叠性的研究给出了边缘化后保留原交互项的条件。本文的两份表各自先对共同档位边缘化，再比较各自归一的联合拒绝概率。这个区别允许两个实况的共同档位诱发相同且非零的关联。 [列联表可折叠性原论文](https://academic.oup.com/jrsssb/article/40/3/328/7027572)

Halldórsson 与 Shachnai 将有冲突的作业组成独立集，直接采用冲突图着色来安排批次。Corneil 等建立了可由不交并和完全连接递归表示的图类及相应算法。本文导出的冲突图属于该类，已有图论结构足以计算其团数和着色数。推理系统方面，Punica 和 S-LoRA 已用配置感知的执行计划来处理带不同适配器的请求，并实际优化内核、显存和吞吐。此处的运行档位来自预先声明的随机分布，批内兼容性取决于归一拒绝合同。 [批次冲突着色原论文](https://csaws.cs.technion.ac.il/~hadas/PUB/batch_col.pdf) · [Cograph 原论文](https://www.sciencedirect.com/science/article/pii/0166218X81900135) · [线性识别算法](https://epubs.siam.org/doi/abs/10.1137/0214065) · [Punica](https://homes.cs.washington.edu/~arvind/papers/punica-mlsys.pdf) · [S-LoRA](https://arxiv.org/abs/2311.03285)

## 二项条件给出精确冲突

设有两个实况 \(P,Q\)，每个实况下请求 \(i\) 的条件拒绝率向量 \(r_i\) 各坐标严格为正。每组请求共享一次类别抽签，各组独立，抽签分布 \(w\) 在两实况相同。抽签后，请求的拒绝事件条件独立。允许在批次开始前随机选一个分组，分组选择的分布固定，与 \(w\) 和实况无关。逐项拒绝率记为 \(r_i\cdot w\)，一个窗口的联合拒绝概率除以这些率的乘积，即归一倍率。

若同组的两个向量为 \(a,b\)，把倍率齐次化得到

\[
L_{a,b}(w)
=\frac{H(w)C(w)}{A(w)B(w)},\qquad
H=\sum_jw_j,\quad C=\sum_j w_ja_jb_j,\quad
A=\sum_jw_ja_j,\quad B=\sum_jw_jb_j.
\]

若任一向量常数，倍率为 \(1\)。若两向量均非常数，\(A,B\) 都不与 \(H\) 成比例。\(C\) 与 \(A\) 成比例要求 \(a_jb_j\) 与 \(a_j\) 对每个 \(j\) 使用相同比例。因 \(a_j>0\)，这会迫使 \(b\) 为常数。交换 \(a,b\) 同理。因此有理式在实系数多项式环中已约分。

在单纯形上一个相对开集内等式成立，齐次交叉相乘后也在正比例缩放得到的实空间开集内成立。因此交叉差多项式恒等于零。两份约分式的分母线性因子须逐个匹配到实数倍，并保留重数。条件拒绝率的正性保证比例为正。把每个非常数向量除以它的首坐标，可以得到比例类的唯一表示。于是兼容的二项只有两种情况。

- 两实况都至少有一项为常数，二者的倍率均为 \(1\)。
- 两实况的四条向量均非常数，两个实况的比例类无序多重集一致。请求可以交换对应关系，比例因子会在各自分子与分母中消去。

不满足这些条件即为冲突边。对固定的一对请求，分开抽签时两个实况的倍率均为 \(1\)。如果分组随机选择，倍率之差恰为同组概率乘以同组倍率之差。只要某个允许的 \(w\) 能使同组时有差异，准确一致就要求该对同组概率为零。因此随机分组无法让某个正概率的分组违反冲突边。固定权重的独立分支同样只有倍率 \(1\)，组内共用分支权重大于零时这个必要条件保留。

## 所有兼容对足以保住整组

任取一组和其中的一个窗口。若两个实况各至多一个非常数请求，常数可从期望和乘积中提出，倍率均为 \(1\)。若某个实况至少有两个非常数请求，每对非常数请求在另一实况也必须都为非常数。另一实况多出非常数请求时，把多出的请求与任一已匹配的非常数请求成对，就会构成冲突。两个实况的非常数位置因而相同。

设有 \(k\ge 2\) 个非常数位置。把所有位置对的无序比例类多重集相加，每个真实位置恰出现 \(k-1\) 次。各对多重集一致，所以整个窗口的非常数比例类多重集一致。于是把各比例类向量逐点相乘之后取均值，以及分别取均值之后相乘，两者之比在两个实况相同。常数请求和向量的正比例不影响该比值。跨组独立抽签使整窗倍率等于各组子窗的倍率乘积。逐项边缘对分组方式保持一致，所以混合分组后的倍率是各分组倍率按原权重的平均。由此得到对全部窗口的充分性。

## 最少分组与最少期望档位数

以非常数比例类表示请求在两实况的类型。两个实况都为常数的请求是孤立点。只在 \(P\) 或 \(Q\) 有非常数率的请求分别各构成一个团，两个团之间没有边。两实况都有非常数率且比例类相同的请求组成独立集。两实况均非常数而比例类不同的请求，按无序类对 \(\{a,b\}\) 分桶。同一桶内，方向 \((a,b)\) 的请求互相冲突，方向 \((b,a)\) 的请求也互相冲突，两个方向之间没有边。上述单实况部分、比例类相同部分和不同无序类对的各桶之间都有全部冲突边。

若 \(p,q\) 是两个单实况团的大小，\(e\) 表示比例类相同部分是否非空，\(n_{ab}\) 是方向 \((a,b)\) 的请求数，则非空批次的最少组数是

\[
k_\star=\max\left(1,\max(p,q)+e+\sum_{\{a,b\}}\max(n_{ab},n_{ba})\right).
\]

每个允许两种方向共存的部分，把较小团逐项配进较大团的颜色。各完全连接部分使用不同的颜色。孤立点可加入任一组。最优性证据可取较大的单实况团、比例类相同部分的任一请求、各无序桶中较大的方向团的并集。该集合两两冲突，与构造的组数相同。全为孤立点时任选一个请求作为下界证据。

给定 \(w\)，用 \(b\) 组独立抽签，期望出现的不同档位数为 \(G_b(w)=\sum_j[1-(1-w_j)^b]\)。每多抽一个档位，原来出现的档位都保留，因此 \(G_b\) 随 \(b\) 不减。若逐项独立分支的固定权重为 \(\gamma\)，条件于组内抽签的分支取得 \(k_\star\) 就给出最小期望 \(\gamma G_n(w)+(1-\gamma)G_{k_\star}(w)\)。若 \(w\) 至少支持两个档位且 \(0\le\gamma<1\)，改善组数会严格改善该成本。若独立分支权重为 \(1\)，实际调度与分组无关。该优化范围是组内共用、组间独立抽签及其固定混合。允许组间使用其他耦合、成本取真实时间或每档费用时，需要各自新的最优性证据。

## 有限个分布可以给出精确反例

若把两实况的二项倍率交叉相乘，公因子 \(H\) 消去，得到齐次三次交叉差。对于污染分布 \(w=(1-\delta)u+\delta v\) 且 \(\delta>0\)，把右侧齐次化后代入，得到关于 \(v\) 的三次多项式。取所有 \(v=t/3\)，其中 \(t\) 为和等于三的非负整数向量，即可判断这个多项式是否恒为零。

一种直接证明使用下降阶乘。对每个指标 \(\alpha\) 满足 \(\sum_j\alpha_j=3\)，考虑 \(\prod_j\prod_{\ell=0}^{\alpha_j-1}(3v_j-\ell)\)。在节点 \(t/3\) 上，当且仅当 \(t=\alpha\) 时其值非零。把这些式子在单纯形上齐次化后，个数与三次齐次多项式空间的维数一致，因而在这些节点上逐点为零就等价于恒为零。于是每条冲突边都有一个精确允许分布的见证，污染部分只需分到至多三个档位。实验中合适的形状可用少量分布测试找到反例，连续分布保证仍以代数证明为依据。 [Scheffé 的混合实验单纯形格设计](https://rss.onlinelibrary.wiley.com/doi/10.1111/j.2517-6161.1958.tb00299.x)

## 查新与适用边界

检索覆盖共同随机数、多变量耦合、条件独立混合的可辨识性、列联表可折叠性、冲突着色调度、混合实验格点和配置感知推理批处理。已找到随机量共享、图着色形式和相应图类的直接先例。在这次检索范围内，尚未找到从所有共同档位分布下的归一全拒绝恒等式导出上述比例类冲突，并证明二项条件恰好刻画全部窗口条件的相同结果。现有查新不能确认发表优先权。

保证要求相同的共同档位分布、严格为正的条件率、声明的条件独立和固定的分组选择规则。若只检查一个档位分布，二项函数有可能在该点相等而在其他点分离。实验所得成本是预期使用的不同档位数。实际吞吐、延迟和未纳入审计的输出事件仍需各自的测量与验证。
