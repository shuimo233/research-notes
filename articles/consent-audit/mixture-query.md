# 读数相关时，先证明复杂规划值不值得算

## 一次观察可以同时改变证书和下一问

任务仍是精确返回有限关系表中的全部目标标签。所有候选的乘积支持保持合法，只把概率换成有限个独立模型的混合。给定未观测状态 $Z=z$，各位置独立，每个候选仍有正概率。一次读数有两种作用。首先，若某张边表给定这次读数后仍可取不同标签，对端成了必问位置。其次，读数的类条件似然更新 $Z$ 的后验，从而可能改变其他位置的最优询问顺序。标签的逻辑正确性由完整表支持检验，后验只影响购买读数的顺序。

规划状态由未读位置、已产生的必问集合和潜在状态后验组成。关系已经确定或必问的边对未来成本的作用相同，可用必问集合代替完成标签。给定未读位置，潜在状态若在这些位置上的全部条件分布相同，只需保留合计权重。一个位置的两个候选若产生同一触发集合，且其每个类的似然之比成同一个常数，两种回答给出同一后验，可合并成一个概率分支。执行时依然用原始值核验实际标签。

所有必问位置可先读。任意正确策略都会为它们付费，把该读数移到前面后可以模拟原策略，并让原先较晚才读到的值提前可用。若必问集合已覆盖全部未定关系，则剩余查询没有顺序选择价值。先读必问点，再补读其结果触发的其他点即可。某个额外位置 $j$ 能被跳过的概率，是对各潜在状态中“所有必问邻点都不触发 $j$”的乘积取混合平均。这个终止公式避免展开这些必问读数的所有组合。

## 目标之外的读数仍可能值得买

取 $k$ 对互不共享位置的二元 AND 目标，每个目标位置查询费为一。每对有一个独立的公平隐藏位，决定哪一端的活跃率是 $\epsilon$、另一端是 $1-\epsilon$。没有额外观测时，每对须花 $3/2$ 次。设一个没有任何目标边的辅助变量以代价 $c$ 提供全部 $k$ 个隐藏位的噪声副本，每位独立以概率 $\epsilon$ 翻转。若先买辅助读数，再在每对里先查推测较不活跃的一端，每对平均查询 $1+\eta$，其中 $\eta=2\epsilon(1-\epsilon)$。

在这族任务中，精确最优是 $\min\{3k/2,c+k(1+\eta)\}$。起初两者是可执行策略。在购买辅助读数前，如果先查询某对中的一个位置，该对已经可以确定答案或必须查另一端。因此任何策略都可先完成这个目标，再考虑是否买辅助读数。已经完成的目标读数不会改变尚未打开的目标或辅助各对应位的联合分布。等待只能减少购入后还能受益的目标数，最优是在第一问买或全程不用。取 $k=3,c=1,\epsilon=1/20$，最优成本从 $9/2$ 降到 $857/200$。所有候选联合实现仍具有正概率。

这一现象可以用已有的异或互补信息构造加强。给每个隐藏位另配一个公平遮罩位，两份辅助观测分别给出带噪声的遮罩与带遮罩的隐藏位。任一份单独都与**所有目标输入**独立。只准买其中一份的策略可以用内部随机性模拟该读数，精确最优仍为 $3k/2$。若两份都读，去遮罩后每位方向判断的总错误率为三次噪声中奇数次翻转的概率。取 $k=5$、每次查询费用为一、各次噪声率 $1/100$，这个明确策略花 $357351/50000$，低于 $15/2$。因此即使两份都没有单独预测价值，每个最优策略也会在某些路径购买两份。独立决策树另外穷举了 $k=2$、辅助费用 $1/10$ 的缩小实例，核对只查任一份都花 3 次，两份均可用时最优为 $2471/1000$。[穷举代码](mixture_query_check.py)

## 用已有独立策略给后验规划开上界

设 $L$ 是免费揭示潜在状态后，每个类分别采用原有独立规划器所得最优成本的加权平均。设 $U$ 是先把当前边际当独立来生成一份策略，再用混合模型逐类核算这份固定策略得到的真实拟合成本。对所有允许后验更新的精确策略，最优成本 $V$ 满足 $L\le V\le U$。

若 $U=L$，独立策略已经可证明最优。允许误差 $\tau$ 时，$U-L\le\tau$ 可保证这份策略的期望额外费用至多 $\tau$。否则仍运行后验求解器。对没有待答关系的辅助读数，若成本 $c>U-L$，它一定不应当作为当前第一问。即使先免费知道潜在状态，也还得至少付 $L$ 完成核验。这个排除结论针对当前状态，未来证据仍可能改变价格阈值。该界使用已有的完美信息价值松弛。原型把它用于约束逐边标签必须有证书的查询决策。[证书与自动调度](mixture_budget_bound.py) · [完美信息价值的原始论述](https://gwern.net/doc/statistics/decision/1961-raiffa-appliedstatisticaldecisiontheory.pdf)

## 留出回放与证书复验

原六边温差任务使用 2000–2017 年拟合、2025 年测试，共留出 725 项。所有策略均正确，且三种主策略读取次数相同。匹配边际策略在 677 种不同输入中有 7 种严格增加模型内期望成本，但所有任务加总只多约 0.0061 次。辅助站点分析只保留两个目标边。辅助站读数费用为 1 或 0.1，两次试验均未选择它，合计付费都是 1,683 次。这里的混合只有两类，先验由天温历史和当前公开区间估计。结果支持这套模型在此任务的预测价值很小，且未测量实际 API 或传输开销。[模型与回放](mixture_station_run.py)

事后筛查在 662 项上得到零区间宽度，在 722 项上保证额外费用至多 0.01 次，在所有 725 项上保证至多 0.05 次。使用零容差实际执行，662 项完全没有产生后验规划状态，其余项复算了精确预算。在两个目标边的子任务中，所有输入都可用上述界排除 0.1 成本辅助读数作为第一问。独立程序从原始十个站点文件重提数据并按温差极值核验 4,350 条查询路径，也对 80 个合成关系图作独立的完整历史精确求解。[筛查与回退核验](mixture_station_bounds.py) · [原始数据摘录清单](station-tmax-2025-sources.json)
