# 同一个请求有多条可发证词时，怎样审计部分可见的回复？

真实证词的选择规则已经公开，读者可能只看到某些请求的回复。可以缩减要核验的窗口，但**即使两边支持的标签严格包含，也可能必须同时比较显示和隐藏**。在预先登记的 CI 与 BART 档案试验中，精确规则把比较次数从 8,620,370 减为 3,681,108，逐个有向实况对保留了相同的最高赔率。 [事前协议](https://github.com/shuimo233/research-notes/blob/8a28f18df15192e9a013a2378e68414474e13da4/articles/consent-audit/incomparable-odds-protocol.md)

## 比较两个实况时，哪些窗口可以省去？

设分子和分母在第 $i$ 个请求中的可发标签集合分别为 $X_i,Y_i$。拒绝也视为一个标签。世界的完整回复必须对各请求可发标签的笛卡尔积中每个组合赋正概率。联合抽签可以相关。每次只比较两世界均允许的同一条可见消息。

| 局部支持 | 可确定的处理 |
| --- | --- |
| $X_i\subseteq Y_i$ | 显示 |
| $X_i\cap Y_i=\varnothing$ | 隐藏 |
| $Y_i$ 仅有一个标签且严格包含于 $X_i$ | 隐藏 |
| 其余情况 | 保留显示和隐藏两种选择 |

在第一行，原有可见消息细分后，所有分子项都能找到正的分母。概率和的比至多是其中最大的细分比。第二行的显示窗口没有共同消息。第三行中，展示时共同比较只能使用分母唯一的标签。隐藏它只会增加分子，分母相同。各坐标的操作可以依次应用。若实际只允许预定的窗口，可在这张名单中用相同规则删除被另一个可见窗口支配者。 [详细证明](incomparable-odds-prior.md)

一个请求可直接看出严格反向包含的问题。分子兼容拒绝、证词 A、证词 B，概率是 $(0.8,0.1,0.1)$，分母只兼容拒绝和证词 A，概率是 $(0.2,0.8)$。显示拒绝的赔率比是 4，隐藏该请求只留下比率 1。换一组概率，显示的最高比也可以小于 1。上一轮的二元规则能固定隐藏，是因为这种方向上分母只有拒绝一个选项。多标签的分母仍可有多种回复。

## 为什么不能再按支持或单项概率删掉所有未知窗口？

对任意指定的窗口 $W$，只要它含至少两个请求，就能造出两份固定单项概率的渠道，令 $W$ 成为唯一明显改变赔率的窗口。若每个请求的两个世界各有一种互不相同的真证词，两边都一半答、一半拒，则可让所有其他窗口的双向最高比为 1，而 $W$ 的最高比为 2。若 $W$ 是完整窗口，峰值可为 3。所有联合格仍保留本世界独立抽签概率的一半。

构造让一半质量独立抽签，另一半用窗外共享状态触发窗内偶校验或奇校验。窗口里少看一项时，两种校验的投影相同。显示任何窗外请求时，共同的全拒绝消息排除触发分支。只有恰好看到 $W$ 时，校验差异保留下来。严格反向包含的多标签例子也可以在保持各自单项边缘和逐格地板时，产生唯一的有向峰值 $3/2$。

因此，只看支持与单项边缘、尚未读取相关概率的一份通用核验清单，最坏要保留至少 $2^n-n-1$ 个窗口。已经读到整个概率表的算法可以利用其中的结构，预选清单的下界并未排除更快的算法。

只要求其他窗口的同向比率都不超过 1 时，单个窗口还能隐藏一个更大的峰值。在互不可比的二元支持下，公平边缘、独立概率保留比例 $\gamma$ 时，指定 $w\ge2$ 项窗口的最高孤立有向峰值恰为 $1+\frac{1-\gamma}{\gamma}\frac{2^{w-1}}{w-1}$。其余窗口的双向比率均为 1 是上一段的更严条件，对应的尖锐峰值依旧是非完整窗口的 $1/\gamma$ 或完整窗口的 $2/\gamma-1$。 [构造、上界与原始先例](incomparable-odds-prior.md)

## 在公开档案上会漏掉什么？

从每份报告取四个时间差，各生成“至多某值”和“至少某值”的两个真证词。两条可能同时为真。抽签规则在保留一半均匀基准概率的同时，允许更常发布晚到证词，用来检验多标签审计。公开档案决定真假可行结构，抽签规则与新请求是事前指定的实验条件。

| 数据 | 评分档案 | 逐窗口比较 | 精确缩减后 | 二元规则漏掉的有向实况对 |
| --- | ---: | ---: | ---: | ---: |
| CI | 22 | 383,442 | 161,999 | 94 |
| BART | 67 | 8,236,928 | 3,519,109 | 8,242 |
| 合计 | 89 | 8,620,370 | 3,681,108 | 8,336 |

二元规则在 82 份档案各漏掉至少一个有向对，这批数据的档案级最高倍率没有因此降低。只看完整窗口则在一份 pip 档案中低估了档案级最高值。完整窗口得到 $160/13\approx12.31$，而只看到第 2、3、4 项都发布较早证词时，两实况间的倍率为 $128/9\approx14.22$。若验收界是 13，只看完整窗口就会作出错误的通过判断。56 种去重支持结构全部完成了独立有理数复核。 [结果](incomparable-odds-results.json) · [逐项证据](incomparable-odds-policies.json.gz)

## 复算与审计自己的概率表

```bash
python -B incomparable_odds_run.py public-optimality-packets.json.gz transit-optimality-packets.json.gz replay
python -I -B incomparable_odds_check.py public-optimality-packets.json.gz transit-optimality-packets.json.gz replay
python -B incomparable_odds_boundary_check.py
python -B incomparable_odds.py local-table.json --limit 13
```

复算用 Python 标准库。命令行输入是 `{"worlds":[{"id":"x","outcomes":[{"labels":["拒绝","证词"],"weight":"1/4"}]}]}` 形状的 JSON，每个世界列全其正概率组合，每行权重按总质量归一化。增加 `--ordered-pair x y` 只复核指定方向。输出给出该表的精确最高赔率、达到它的窗口与消息。边界脚本另外核验了 108 份只在一个指定窗口出现峰值的构造，以及 192 个任意正概率的有向对。

同支持下的细分、真实粗化、奇偶校验与 Möbius 反演都有直接先例。此次查新所见的候选贡献是把这些原理用于真实且带拒绝的产品支持合同，给出可安全删除的窗口、反向严格包含的常数间隔反例，以及使用公开档案的证伪结果。 [原始文献核对](incomparable-odds-prior.md)
