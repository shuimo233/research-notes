
# 冻结协议：两个实况的拒绝率不同时，怎样审计完整赔率？

研究对象是两个合法答复集合不相交、仅共享拒绝的实况。每项在两个实况中的拒绝率可分别变化。每个实况的完整概率表至少包含本实况独立表的二分之一。对每个两项窗口，分别把全拒绝概率除以该实况的两个单项拒绝率之积。两种方向的归一赔率上限设为 51/50。完整风险按实际全拒绝概率比计。

## 固定档案与参数

输入是上一轮的 Git 对象 7ff77c48087929f54a1c9cda41bd984b14ec5edf（audit-parity-policies.json.gz），沿用全部 81 个评分档案。按原来配对记录的索引顺序选最前四项，两种实况的四项真答复均相异。截取四项用于固定主要对照的计算宽度。源档案约束可行的真答复，拒绝率取以下公开设定。

- 对每个选中索引令重叠量等于 1 减去早与晚标签记录各自的第三项之和。重叠量至多 5 时基准拒绝率为 9/10，至多 30 时为 4/5，其余为 3/5。
- 第一实况在基准率上加 1/40，第二实况减 1/40。两者第一项各留上下 1/20 区间，后面三项固定。两个实况的区间可独立取值。
- 双向分别核验。对每个方向做至多 16 次分割，以证书上界至多为已实现赔率的 51/50 倍为收敛门槛。要求 162 个方向都达门槛。
- 对照一是把两个实况的率都置于最低拒绝端点所得的已实现值。测量它是否严格低于一个已实现值。
- 对照二是用最低拒绝端点求归一倍率，再乘区间最大单项率乘积比所得的合法上界。测量分割能否更紧。
- 预定实际赔率门槛为 2、3、4、8。记录两种方法下能证实达标、证实超标、仍不确定的次数，并保留全部零结果。档案结果不承担自然出现拒绝率差的估计任务。

## 单独核验

另用三项有理数反例验证内部取值能严格超出两端，给出三处精确证据，并把整个区间夹至 101/100。扩大例只验证精确计算，主对照样本不使用该反例。用原始完整概率表线性规划对照程序中的固定率结论，以独立有理数检查器验证每个保留分割两边覆盖原区间、原始和对偶可行、目标相等。只有这些条件全部成立才把结果用于证书。
