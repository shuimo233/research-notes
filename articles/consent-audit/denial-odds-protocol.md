# 可观察拒绝时，校准赔率与最低发布率

协议于本轮求解前登记。仍使用 25 个 BART 公开目录，`selection-odds-policies.json.gz` 的 Git blob 为 `04d401ec5b65d519d224f26d12a907ea679f10ff`。以此文件记录的原公开归档和合法目录为准。公开归档确定所有可能的真实标签集合，独立程序重新核验，须包括没有任何合法标签的空集合。不读真实时间表。

每次选择输出一条真实合法比较，或输出同一种“未发布”消息。空集合必须未发布。对每个非空合法集合，单条真实消息的概率至少为 α=1/(2k)，k 为目录标签数。并且真实消息的概率合计至少为 s。分别核验 s=1/4、1/2、3/4，1/2 为主试验。赔率比包括未发布消息，仍只比较能够产生同一消息的实况。

主方案求全局最优最坏赔率比。在有理数上核对原始可行解与对偶上界，将具体的各项消息概率和未发布概率全部重算。另测两个对照。首先将服务率固定为 s 时求条件最优，若概率下限令该速率不可行则报告。其次问是否有任何恒定成功率、至少为 s 的策略能达到主方案的最优值。对这项判定只在主方案的有理候选值上验证必要且充分的容量条件。无法达到时，给出精确的严格差距证书。核验用 Python 3.13 标准库与此前冻结约束，重求权重固定 SciPy 1.16.3。

主判据是 25 项三个服务率的证书均获独立复核，并且在 s=1/2 时至少 5 项严格优于所有恒定成功率规则。公开目录可复核概率，实际发布只由保管方本地读取记录。空集合的强制未发布和非空集合的自愿未发布使用同一个缓存结果格式。只评价同一固定场景的一次公开输出。

在小目录上用直接逐模式概率规划交叉检查固定权重的全局最优性。另覆盖无可发布实况、最低真实标签概率、不可省略的随机未发布、常数成功率可严格较差及其最优值可为无理数的例子。实际发布的日志只能核对公开结果，统计合格判据不纳入未建模的额外计时信息。
