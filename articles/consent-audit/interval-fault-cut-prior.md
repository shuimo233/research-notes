# 有界错报下的温差阈值与一次补核的先例

## 成对读数和约束修复

Chen、Suh 与 Goldsmith 把成对差值组织成测量图，证明信道区分度与图最小割共同控制整体恢复。Lerman 与 Shi 用环路一致性估计成对同步的异常测量，分析对抗污染。两者都使边差、图割及环路故障成为已知工具。这里固定一份公开档案，使用可信逐点区间和确定性错报预算，只问一个有方向的阈值是否仍可能反转。 [Chen 等原论文，第 I–III 节](https://arxiv.org/abs/1504.01369) · [Lerman 与 Shi 原论文，第 7.3 节](https://link.springer.com/article/10.1007/s10208-021-09532-w)

Bérczi 等的最小可行性阻断集（MinFB）已研究通过删除最少的线性约束恢复可行性，并专门讨论差分约束与负环的关系。把可信区间与反向阈值设为必须保留、每条档案报告的双向差分约束作为一个可删除组，已经给出本问题的一般建模方式。任意整数差报告保留后的环一致性，也是整数加法群标记图的平衡性问题，删除边使图平衡已有 Group Feedback Edge Set 先例。可信区间和有方向的阈值仍须纳入判定。 [Bérczi 等原论文](https://arxiv.org/abs/2209.02017) · [Guillemot 的 Group Feedback Edge Set 原论文](https://doi.org/10.1016/j.disopt.2010.05.003)

## 一致档案的切分界

令初始报告由区间内的一组整数 $x_v^0$ 产生，偏移 $d_v=x_v-x_v^0$ 可取 $[-a_v,b_v]$。原报告在新世界中成立恰当且仅当其端点偏移相等。删除一组报告后，每个连通分量共用一个偏移，允许区间为该分量顶点区间的交集。若 $s,t$ 已分离，$d_t-d_s$ 的最大值是 $s$ 分量的最小 $a_v$ 与 $t$ 分量的最小 $b_v$ 之和。这个公式也可由已有的最短路解释得到。把保留报告设为互反的零权弧，可信区间由不可删的零点星形弧表示，反向阈值可行性就要求 $s\to t$ 最短距离至少达到缺少的幅度 $\Delta$。删边提升最短路有成熟的网络阻断文献。本模型的零权互反弧、成组删除和固定锚点给出特殊结构。 [Dechter、Meiri 与 Pearl 的最小时间约束网络](https://ics.uci.edu/~csp/r10.pdf) · [Israeli 与 Wood 的最短路阻断](https://onlinelibrary.wiley.com/doi/10.1002/net.10039)

对每个可行删除集，可以把 $s,t$ 的偏移收缩为 $-k,\Delta-k$，其中 $0\leq k\leq\Delta$，其余分量用零偏移。这利用了所有区间都包含零。给定 $k$，如任一目标端点不允许分配给它的偏移，则跳过这一情形。否则有一条预算保持的 Edge Multicut 约简。要求分隔 $s,t$，并分隔 $s$ 与每个不允许 $-k$ 的顶点、$t$ 与每个不允许 $\Delta-k$ 的顶点。反向取任意满足要求的切分，把两个端点分量分配到固定偏移，其余分量置零。候选 $k$ 的整数划分只在 $a_v+1$ 与 $\Delta-b_v$ 处变化。枚举 $O(n)$ 个状态即可采用既有图切分算法，复杂度无需随区间数值宽度增长。以删除条数为预算时，可直接沿用 Edge Multicut 关于切集大小的固定参数算法。

固定三个偏移值后，目标也正好匹配带允许标签集合的均匀度量标记。Boykov、Veksler 与 Zabih 的 Potts 势到多终端割转换已覆盖硬列表，可通过足够大的单点代价实现。该转换的附加成本可能随顶点数增长，上述 Edge Multicut 约简保留原删除预算。若 $\Delta=1$，整数分拆只有两种，每种只有一侧可能不允许非零偏移，约束可并入普通两端点最小割。若 $\Delta=2$，任取三终端割实例，将两端点分别限在 $[-1,0]$ 和 $[0,1]$，第三终端固定为零，其余区间为 $[-1,1]$，取全零报告，达到阈值就强制三个终端各占一类。于是三终端割的已知困难性立即给出这一特例的困难性。检索核对的文献已覆盖图割子问题与通用建模，未发现它们明确给出这个带可信区间的方向反例在 $\Delta=1,2$ 的分界和按区间端点移植到实际审计的结果。 [Marx 与 Razgon 的 Edge Multicut](https://epubs.siam.org/doi/abs/10.1137/110855247) · [Boykov 等第 7 节](https://www.cs.cornell.edu/rdz/Papers/BVZ-pami01-final.pdf) · [均匀度量标记的显式列表表述](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.MFCS.2024.25) · [Dahlhaus 等的三终端割](https://epubs.siam.org/doi/10.1137/S0097539792225297)

## 一次补核

Dechter、Meiri 与 Pearl 的 STP 直接求任意时间点对间的所有可行关系。Stergiou 与 Koubarakis 的 DTP 已使用差分约束的析取，Tsamardinos、Pollack 与 Ganchev 进一步显式讨论将 DTP 当作多个 STP 分量，以及在执行中淘汰不相容的分量。把可删除的报告集合当作有限选择，每个分支含可信区间、保留的差等式和一个固定真假标签的阈值约束。单分支的查询投影是紧整数区间，整个真假投影是对应的区间并集。整数性可直接核查。对上下界之间任意整数查询值，加入表示这个值的两条反向弧仍没有负环，整数最短路势给出见证。两类并集互不相交恰好保证每个可达答复下目标标签唯一。 [STP 原论文](https://ics.uci.edu/~csp/r10.pdf) · [Stergiou 与 Koubarakis 原论文](https://doi.org/10.1016/S0004-3702(00)00019-9) · [DTP 分量与执行](https://cdn.aaai.org/ocs/7769/7769-37858-1-PB.pdf)

这种按剩余世界标签一致而停止的原则是已有的决策区域判定。Javdani 等给出判定区域所需的信息条件，标签互斥时归入 Golovin、Krause 与 Ray 的等价类判定，其模型也处理有噪观测。Reiter 和 de Kleer 与 Williams 的模型诊断利用新增测量区分可行故障解释。此处允许故障身份仍有歧义，只要求给定预算内所有世界同意所问标签。后一差别与决策区域判定相符。 [Javdani 等第 3 节](https://proceedings.mlr.press/v33/javdani14.html) · [Golovin 等关于有噪观测](https://arxiv.org/abs/1010.3091) · [Reiter 原论文](https://www.cs.ru.nl/~peterl/teaching/KeR/reiter.pdf) · [de Kleer 与 Williams 原论文](https://www.vehicular.isy.liu.se/Edu/Courses/DocDiagnos/CourseMaterial/deKleer_Williams_1987.pdf)

对于本次精确差报告，每个删边分支还能用图遍历检查环一致性，并把每个一致分量收缩为一个偏移区间。设 $D_{ij}$ 为添加真假阈值前偏移 $j$ 减去 $i$ 的紧上界，对不同分量 $D_{ij}=U_j-L_i$，同一分量为零。阈值只增加单弧 $a\to b$ 权重 $c$，可行条件为 $D_{ba}+c\ge0$，更新后 $D'_{ij}=\min(D_{ij},D_{ia}+c+D_{bj})$。这是已知单弧最短路更新的直接使用。若只返回一个固定目标的真假可行性及 $q$ 个候选补核对的投影，每个删边分支可用 $O(n+m+q)$ 时间生成，之后另计各区间并集的整理开销。可核对特定档案中有多少非目标补核真的有用、有多少错误档案被误当作强证据，以及用精确投影能否改进保守的凸包替代。实验结论受可信区间、故障注入和补核可靠性的限制。 [动态最短路回顾及更新公式](https://publikationen.bibliothek.kit.edu/1000052742/3801174) · [本轮冻结协议](interval-fault-cut-protocol.md)

## 单条坏记录的有序候选

Zaslavsky 已把一个删后恢复平衡的边定义为 balancing edge，并描述含此边的符号图块可拆成由平衡子块串成的环。群标记图允许整数加法等更一般的边标记。Dinitz、Karzanov 与 Lomonosov 的仙人掌表示，以及后续的三边连通核验算法，已用循环顺序压缩二边割。在连通图中，若差报告不一致且已知一个图上修复位置 $e_0$ ，其他图上修复位置是 $G-e_0$ 中分开 $e_0$ 两端的桥，这一拓扑结论由上述边割结构即可解释。端到端网络层析也已有通过测量路径区分链路的研究，其路径可辨识性讨论了测量矩阵各列相同导致无法区分的情形。 [Zaslavsky 的 balancing edge 与块结构，第 1.1 和 3.1 节](https://people.math.binghamton.edu/zaslav/Tpapers/npc.pdf) · [群标记图原论文](https://people.math.binghamton.edu/zaslav/Tpapers/bg1.jctb1989.pdf) · [Dinitz 等原论文](https://www.alexander-karzanov.net/ScannedOld/76_cactus_transl.pdf) · [二边割表示的线性核验](https://algo.uni-rostock.de/storages/uni-rostock/Alle_IEF/Inf_ALGO/Publications/Mehlhorn2017.pdf) · [主动路径选择与链路可辨识性](https://pmc.ncbi.nlm.nih.gov/articles/PMC5049780/)

本轮可检验的强化是把结构直接变成可信区间和阈值查询的数值判据。选一个生成树和违反该树给定差值的一条非树边 $e^\ast$。设 $P$ 为它两端的树路径，$\delta\ne0$ 为顺路径定向的残差。任何修复都要改动这个失衡环上的一条记录，因此只可能是 $e^\ast$ 或 $P$ 的一条树边。给定路径切点，树路径后缀及其挂接顶点必须统一平移 $\delta$，以满足 $e^\ast$；路径前缀维持原来的相对坐标。另一条非树边按两端在 $P$ 上的投影位置及定向，对切点要求落在一个区间、排除一个区间，或直接否定全部树边候选。修复 $e^\ast$ 只在其余非树残差均为零时可行。可以通过区间交集和差分数组在线性时间获得全部图上可行候选。随后用各投影位置上原始坐标兼容的平移区间，做前缀和后缀的区间交集，过滤不能满足公开区间的候选。

任意两个顶点的差值只在切点落在它们的投影位置之间时出现同一个非零改变量，符号由查询方向决定。给定仍存在真假歧义的目标和合法的补核对，补核的两个可能数值正好划分候选。它能保证定案等价于该划分与目标真假划分一致，允许交换两类名称。用过滤后候选的前缀计数，只需检查两个区间的交集及差集是否还包含候选。附加的 $e^\ast$ 候选（若有）对应未平移，可作为区间外的独立索引处理。已核对的平衡边与层析先例明确覆盖拓扑和可辨识性的起点，有限检索还没有找到在此公开区间、数值残差和阈值合同下把它们合成同一查询判据的原论文。

检索覆盖了有噪成对差值恢复、差分可行性修复、均匀度量标记、多端点割、时间约束分支与主动诊断。先例足以确认基本算法和补核停止规则已有出处。窄的理论候选是零居中可信区间下的精确预算保持切分、阈值分界，以及一条坏记录时的区间补核判据。窄的实用候选是同一假设下真实档案故障演练的可复核证据。有限检索尚不足以建立发表优先权。
