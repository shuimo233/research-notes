# 用另一套人工词义标注复验：整句规划还能少问吗？

在 Princeton WordNet Gloss Corpus 中，沿用此前在 SemCor 开发的程序，用 SemCor 的历史频数给普林斯顿释义里的多义词安排询问顺序。**245 条合格定义的询问总数由旧缓存方案的 715 次降到 703 次，少 12 次，约 1.68%。** 同样能看到整条定义的贪心对照用了 705 次。评分前登记的两个条件均通过，和贪心的差额只有两次。[事前公开的复验协议](https://github.com/shuimo233/research-notes/blob/415f96aca64ffd3294c805bfc42ae9a3f329cd99/articles/consent-audit/frontier-gloss-protocol.md) · [精确结果](gloss-frontier-results.json)

## 检验对象

Princeton WordNet Gloss Corpus 的人工义项标记指明了定义中特定词在该处的读法。本次扫描名词、动词、形容词和副词词条的定义，只从定义正文中挑选有手工标记、可由词形字段独立确定词条、可唯一映射到 WordNet 3.0 义项的多义名词。词条的词性和被询问词的词性是两个维度。未使用例句、自动标记、多词组合标签或跨定义拼接。[官方发布说明](https://wordnetcode.princeton.edu/glosstag.shtml) · [原始团队以外对标注覆盖的说明](https://aclanthology.org/2023.gwc-1.30/)

在 117,659 条定义中取得 149,437 个符合词性和标注条件的位置。枚举 62,367 组三个不同词条的位置，其中 315 组的三张关系表都不能预先给出唯一答案。这些词组分布在 **245 条定义**；41 条有多个词组共用位置。每条定义产生一个任务，要给出其所有合格词对的 WordNet 关系。训练概率仅用 SemCor 计数，各候选加一。一次询问揭示一个位置的义项，已知答案可以在整条定义中复用。[筛选、拟合与执行代码](gloss_frontier.py)

## 只保存逐边概率，损失有多大

这里有两层概率。模型假定不同词元的义项独立，但同一个词义可以使几个邻居同时需要补问。只保留“问到这个词以后，某一个邻居还需不需要问”的概率，可能丢掉后一个关联。理论推导给出一条普适边界：对任意成对关系表和正询问费用，逐边概率在无环图上总是足够；一般图上，按双连通块保留联合触发分布即可安全规划。只提供互不重叠的邻居组的联合表时，不能保证把一个块里的邻居再拆开。[定理及同块必要性证明](frontier-prior.md)

| 提供给规划器的信息 | 模型最优预算有误的定义 | 策略在原模型下严格变贵的定义 | 金标询问次数 |
| --- | ---: | ---: | ---: |
| 每个双连通块内的联合触发分布 | 0 / 245 | 0 / 245 | 703 |
| 保持所有单边触发率，把邻居类型的触发当成独立事件 | 218 / 245 | 23 / 245 | 706 |
| 保持所有单边触发率，把触发事件完全嵌套 | 57 / 245 | 16 / 245 | 706 |

“严格变贵”把替代模型选出的策略放回原来的词义模型计费。两个只用单率的对照，全部定义合计的额外期望分别是 1.367 和 1.276 次。定义 `n10200781_d` 含有 action、course、event；保留真实联合信息的策略在金标上问两次，独立触发对照问三次。总体上保留结构信息的金标差额为三次。前表相对旧缓存少问的十二次还包括其他规划决策带来的收益。[分层统计和精确有理数](gloss-frontier-results.json)

## 可复现的范围

官方 zip 的 SHA-256 是 `a9233e1d0e1f4d11c5959c36fbe4d021aa4cb4e0bae0a348af118f4df6d558b6`。同目录运行下列命令，输出目录需尚不存在。独立程序使用 NLTK 3.9.2 重新映射词义、读原始标记并以词对连接生成三元组，核对 245 个根节点、850 个被要求的关系以及 490 个只保留单率的对照。229 个小任务还直接枚举原始候选观察历史，检查最优值。[独立核验器](gloss_frontier_check.py) · [Gloss Corpus 压缩包](https://wordnetcode.princeton.edu/glosstag-files/WordNet-3.0-glosstag.zip) · [NLTK WordNet](https://github.com/nltk/nltk_data/blob/gh-pages/packages/corpora/wordnet.zip) · [NLTK SemCor](https://github.com/nltk/nltk_data/blob/gh-pages/packages/corpora/semcor.zip)

```sh
python gloss_frontier.py wordnet.zip semcor.zip WordNet-3.0-glosstag.zip rebuilt-gloss
python gloss_frontier_check.py wordnet.zip semcor.zip WordNet-3.0-glosstag.zip rebuilt-gloss
```

这次复验提供了第二种文本来源，并且预先冻结了程序和通过条件。两个来源都使用同一部词典、相同的四类关系和专门挑出的多义词组，尚未证明在任意推理任务中都会节省成本。真实标注用来回放正确答案；没有计时真人操作，也没有把逐词往返或计算时延换算成收益。当前可以公开主张的是精确的统计充分性定理，以及它在两种标注文本上的小幅、可复现的询问数改善。[主研究、原有先例与可执行工具](frontier.md)
