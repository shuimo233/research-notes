# 为了决定下一问，哪些概率必须一起保存？

假设一个推理器要确定整句里若干对词的关系。询问一个位置会揭示它的词义，也可能同时消除好几对词的歧义。这时只记录“问了甲以后还要问乙的概率”，够不够？

**有一个精确边界。** 把每个待询问的位置画成点，把必须判断的一对位置连成边。假定不同位置的候选值独立、询问成本为正，且输出必须对所有合法候选正确。若要求对这张图上的**所有**有限关系表和正成本都算准最优平均询问费用，那么逐边保存触发概率足够的充要条件是这张图没有环。对于有环的图，仍可精确指出应当把哪些相邻边放在一起。这条结论针对最优规划需要的信息；要回答具体是哪一种关系，系统仍读原始关系表。[定义、完整证明与查新](frontier-prior.md)

## 两个看起来概率完全相同的任务

后续证明把查询代价和候选概率也固定了。即便各点都只有同样多的等概率候选，每次询问花费相同，只要拆开同一块中的两个邻点，仍能构造出统计相同、最优期望相差至少 0.47 次的两个任务。[单位成本定理与可执行核验](unit-block-proof.md)

三个位置各有两种等可能的取值，三对都要判断。两套系统里，问出一个位置之后，仍须补问任一指定邻居的概率都是一半。在第一套系统中，同一次回答可能迫使系统把两个邻居都问完，也可能两个都不用补问，只剩邻居之间的一道题。在第二套系统中，某个位置的两种回答分别只迫使系统补问左邻或右邻。选它作为第一问，每次都恰好有一个必问位置。

第一套的最优期望是 $11/4$ 次，第二套是 $5/2$ 次；所有定向单边概率都相同。证明给出了具体的三张二元表，以及用词义上下位偏序实现这种差异的方法。进一步，对每个 $k\ge2$，都存在单位询问成本、各位置候选等概率的例子：任取 $k-1$ 个触发事件，它们的联合统计在两套任务里都一样，最优期望却差 $4^{1-k}$。这个差距随阶数增加而衰减，结论涉及能否**精确**恢复预算。[可重放的决策树穷举](frontier_theory_check.py) · [偏序实现与有环图核验](block_boundary_check.py)

## 怎样设计规划器的输入

考虑即将询问的位置 $u$。临时移除它，如果余图分成若干个互不连接的部分，这些部分的后续最优费用可以相加。一个回答可能同时触发不同部分的补问，但求和时只用到它在每一部分内触发哪些邻居的联合分布。原因是，问过的位置不会再产生未知成本，尚未观察的输入在不同部分之间仍然独立。反过来，若两个邻居在移除 $u$ 后仍然连通，就能构造两个模型，将它们分开统计时提供完全相同的资料，却有不同的最优费用。

因此，如果接口约定为“将邻居划成若干不重叠的组，为每组提供完整的联合触发表”，**双连通块给出了普遍安全的最细分组**，桥边单独成组。树上只要单率；两个环只在一个点相接时，要保存各个环内的联合信息，两个环之间可以分开。特定实例还可能有更短的表示；该定理没有给任意编码的最少比特数。实现按剩余连通关系读入这些局部表，在分组之间任选一份保边际的联合法则来规划。原始输出仍由实际观察决定。[只接收块内统计的规划器](block_query_plan.py) · [可运行的树形输入](block-query-example.json)

## 这点联合信息在真实关系表里起了什么作用

看到主结果后又做了一项机制对照。保持同一词的每条定向触发概率，分别假设对不同邻居类型的触发彼此独立，或让这些事件按概率大小逐层包含。重复的同类目标保持一起触发。替代模型用来决定先问谁，实际成本重新按原始词义分布核算，金标回放仍用原始关系表。

| 449 个主分析句 | 算错模型最优预算的句数 | 所选策略在原模型中有严格额外成本的句数 | 金标询问数 |
| --- | ---: | ---: | ---: |
| 按双连通块保留联合分布 | 0 | 0 | 1,502 |
| 只保留单率，并将不同邻居类型按独立事件补全 | 391 | 72 | 1,504 |
| 只保留单率，并将不同邻居类型按嵌套事件补全 | 228 | 70 | 1,505 |

22 句确有可以拆开的邻居分组，其中 5 句在重组后实际改变了原有的跨组联合法则，最优成本和实测询问仍逐句相同。两个只用单率的对照在原模型中的总额外期望分别为约 1.29 与 1.32 次。结构信息在真实词典任务中确实能改变预算和选择；在这批金标上对最终次数的影响只有两三次。前面相对旧缓存少的 18 次不能全部归给保留联合信息。[机制对照逐句记录](frontier-information-ledger.jsonl) · [精确对照汇总](frontier-information-results.json)

## 使用与复核

前两条命令只需 Python 标准库。第一条读取块内统计，输出示例的最优预算 $27/10$ 和首问位置。第二条使用固定版本的 WordNet 3.0，交互询问词义并返回每个词对的关系。重放 soil、dirt 的金标路径时两次均输入义项编号 14498096。命令行的词义适配器接收至少有两个候选义项的位置，应用可以先处理已知的单义词。原始值一旦足以确定所有输出，程序就停止。[交互入口与 Python 接口](frontier_inquiry.py) · [WordNet 数据包](https://github.com/nltk/nltk_data/blob/gh-pages/packages/corpora/wordnet.zip)

```sh
python block_query_plan.py block-query-example.json
python frontier_inquiry.py wordnet.zip frontier-example.json --ask
python frontier_run.py wordnet.zip rebuilt
python frontier_information.py wordnet.zip rebuilt rebuilt-information
python frontier_check.py wordnet.zip rebuilt --information rebuilt-information
python frontier_theory_check.py
python block_boundary_check.py
```

验证使用 Python 3.13，词典交叉核验使用 NLTK 3.9.2。独立程序以 NLTK 重建关系表，核对 2,754 个句内词对；它保留所有可问位置作竞争动作，以完整触发集合重新求解，复核 462 个模型最优根值和 1,548 个沿实测路径选中的最优动作。另有 324 句直接按原始候选值展开历史，不做触发状态压缩。两个单率补全的 924 个预测与在原模型上的反事实费用也重新计算。对理论例另穷举 196 组路径表、2,744 组三角表、48 组异质代价星形，以及 161 个指定的同块邻居拆分反例。[独立语料核验](frontier_check.py) · [单率对照核验](frontier_rate_check.py) · [规划核心](frontier_plan.py)
