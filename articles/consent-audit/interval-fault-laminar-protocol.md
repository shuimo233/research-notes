# 机构内上限与全局上限同时成立时，核验需要多少？

本协议在运行新合同、合成检查或观察价格前冻结。沿用上轮 NOAA 与 BART 的固定世界、目标奇偶选择、可信区间、单错报和紧预算双错报定义，以及 12 个小来源的比较与价格。气温和时刻来自真实档案；原错报、来源域、费用和新答复故障人为模拟。对于无候选数字表示的松预算双错报仍按主口径排除。

在同一个不含目标边的生成森林上提供七份完整复查，价格沿用上轮完整复查的哈希公式，把序号扩充为 0 至 6。第 i 个小来源的故障域为 `SHA-256(<档案 ID>/quota/<原预算>/domain/<i>)` 首字节模 3。完整复查第 i 份的域是 i 模 3 加轮换量再模 3，轮换量为同一前缀下 `rotation` 哈希首字节模 3。这样每域有不同的模拟来源。一个来源只能购买一次，返回整个向量且可整体错误。主合同允许全局最多两个错误来源，并且每域最多一个。比较同样的全局上限但丢弃分域约束，以及保留分域约束但丢弃全局上限。只有地位相同的报价可比。不能把合同较强或较弱解释成算法在同一事故模型下自动省钱。

实现要求预算组嵌套或互不相交；从异结论世界对生成各组的分离计数条件。求每个对立对是否存在一个超出两倍组上限的组。对同一库存独立穷举来源子集，比较所有三种合同的精确最小成本。测试每个最优清单时，穷举允许故障位置集合、来源的其他可行答复向量和一个全异代表向量。对花费比只准一个任意错误的旧合同更少或等价的情形，不作省钱承诺。若旧合同在新合同允许的某份共同记录上不足，记录反例和两个失误集合。主效用门槛为至少 100 份不同档案具有原歧义且两种全局上限合同均可判，嵌套合同总成本低至少 10%，所有复算及错答校验通过。

合成验证如下。

- 以 `Random(302871)` 固定生成 120 个 3 至 8 来源的嵌套预算例，先按随机顺序切分根组，再随机将一块切成两块，容量 0 至 3。逐例枚举差异在两个世界之间的所有分配，检验倍数阈值及构造出的共同回复。另检验任意两来源的三组重叠各限一错、三个来源全部相异时的反例。
- 40 个 4 至 7 点、最大度三、随机正整数边价的图选择两个各指定不同颜色的终端；每行每个可选域恰有三份来源。用对照枚举顶点颜色和全部域的覆盖，核对二域最小割公式。另生成 40 个同类图、三个固定不同域的终端，核对采购最优价与三端割加常量。来源宽度至多二、每域最多一错。至少抽取十个三域小图在原先共锚环上从原差值重建全体世界和所有来源向量，校验物理嵌入。保留反例和求解器不适用的合同范围。 [上一轮的来源与世界口径](interval-fault-world-tree-protocol.md)
