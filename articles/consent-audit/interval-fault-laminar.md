# 同样最多错两份，机构上限为什么能减少核验？

两个来源都可能出错时，是否允许这两个错误集中在同一个机构，会改变哪些证据足以定案。这轮在相同报价库存下比较两种合同。两种都规定全局至多错两份，但其中一种还要求每个机构至多错一份。对 222 份不同的原档案的 236 个歧义配置，嵌套合同的精确最低总价为 **7,171**，只规定全局上限时为 **11,421**，相差 **37.21%**。气温和计划时刻来自真实数据，错误、来源和价格按协议模拟。 [冻结协议](https://github.com/shuimo233/research-notes/blob/05a4d006b674c0cd7fa52bb86b085a4ecec9edac/articles/consent-audit/interval-fault-laminar-protocol.md) · [回放汇总](interval-fault-laminar-results.json)

## 两个世界何时能给出同样的答复？

每个来源返回整个向量，允许整份被任意替换。预算规定一个故障集合 $F$ 在每个组 $G$ 里至多有 $b_G$ 个来源。这里各组嵌套或互不相交。两个世界在选中来源上真值不同的集合记为 $D$。共同回复存在，当且仅当 $D$ 能分成两个允许的故障集合。因为每个相异位置必须至少有一个世界算它错，且从各自故障集合删除多余位置仍符合预算。反过来，给每个位置选取其中一方的真值就能构造回复。

**对共同使用一套嵌套预算的世界，共同回复恰好在每组都满足 $|D\cap G|\le 2b_G$ 时存在。** 必要性是把两个世界的组内错答相加。充分性可以直接构造。沿组的包含关系把所有来源排成一列，使每个组在这列中连续。在 $D$ 的顺序中交替把相异位置分给两个世界。对每个组，落在其中的相异位置仍连续，两边各最多分到 $\lceil |D\cap G|/2\rceil\le b_G$。所以只需某个组里有至少 $2b_G+1$ 份真值相异，就能排除这两个世界的共同回复。 [乘积通道先例与嵌套判据](interval-fault-laminar-prior.md) · [层叠拟阵](https://arxiv.org/abs/1606.08354)

任意重叠会破坏充分性。例如三个来源，分别对三对来源设每对至多一错。任意合法故障集合其实至多含一个来源，两个世界不能用两份这样的集合覆盖三个相异位置。但每个二元组的差异都等于两倍上限。实现会拒绝非嵌套的输入合同。对冻结的 120 个小嵌套族共核验了 11,320 个差异集合，其中 2,307 个有共同回复，均与独立穷举一致。 [核验输出](interval-fault-laminar-verification.json)

## 嵌套预算改变了如何采购

一个异结论世界对可由不同组保证分离。于是采购约束的形式是“在这些组中，至少有一组达到它的分离需求”，而非单个统一覆盖数。求解器先选一个当前方案尚未分离的对，分别假设由每个可能的组负责。每个分支是若干固定需求的覆盖问题。已有覆盖的最便宜方案给该分支的费用下界。如它已经满足全体条件，就可直接更新上界。如果每份来源在分支内只覆盖至多两项需求，继续用加权匹配；对更宽的来源用离散需求向量精确求解。选择各组的搜索在最坏情形仍可指数增长。 [算法](interval_fault_laminar.py) · [已有匹配例程](interval_fault_joint_source.md)

即使每个来源只提供两项比较，**三个各允许一错的机构也足以使最低成本采购成为 NP-hard**。这里不另加会限制三个机构合计错误数的总上限，或设冗余总上限三。

从三端带权多路割开始。可把高度顶点拆成一条链，让每条原边挂在不同副本上，以高于全部原边总价的链内权重使最优割保持各副本同色。这样只需处理最大度三的图。每个图顶点变成一个分离需求，能选择其三种机构之一；三个端子分别固定不同机构。每种可用机构恰给每个顶点三份可区分来源，其中每条关联图边对应一份同价来源，其余用单位价单点来源填满。若边两端均可用该机构，同一份来源可覆盖两端；若只能用于一端，它在该机构内就是单点来源。

任意安全采购可在每个顶点任选一个已满足的机构。因为每个备选恰有三份来源，该选法决定必须购买的三份。它们的并集仍安全，且费用不会超过原清单。反之，任意机构染色都能这样买齐。其总价等于所有顶点的个别费用之和，减去同色边共享的价格。即固定的 $\sum_e w_e+\sum_v(3-\deg(v))$ 加三端割费用。用上轮的单错报零路径加闭合读数 1 的环，可把每个需求放在一个共锚边界上。选择内部路径边为目标，所有来源只报告一或两项从锚点到相应边界的差值，没有任何目标被直接核实。独立枚举复算了 40 个三域小图，并在其中十个用原差值重建了物理嵌入。 [Dahlhaus 等原论文](https://doi.org/10.1137/S0097539792225297) · [完整归约及查新](interval-fault-laminar-prior.md)

在同样的**每行每允许域恰有足够来源**条件下，只有两个域时可以精确用最小割。设相邻两个需求在域 0 或域 1 同时选择时可共享的价格分别为 $w_0,w_1$，都非负。双点项对异域的价格为零，对同域为相应负节省。这是二元次模成本。乘二后，可写成单点价与边权 $w_0+w_1$ 的割，再用终端固定不可选域。这使用已知图割方法，当前推导把上述采购条件变成了这个二元问题。40 个二域实例与独立枚举全部一致。该结果依赖恰好够用以及没有新增不等价的上层证据条件。 [Kolmogorov–Zabih，定理 4.1](https://www.robots.ox.ac.uk/~cvrg/trinity2005/kolmogorov_zabih_pami04.pdf)

## 复现和查新

不相交域的分离判据、层叠配额与图割有直接先例。当前候选贡献是把同一套嵌套故障合同、最便宜的来源购买及单错报物理环连接起来，得到带两项比较的三域困难性与严格饱和两域的最小割边界。已查文献未定位相同的采购边界，有限检索尚不足以确立发表优先权。 [先例对照](interval-fault-laminar-prior.md)

在文章目录用 Python 3.11 或更新版本及 NetworkX 3.6.1 运行。

```bash
python -m pip install networkx==3.6.1
python -B interval_fault_laminar_run.py station-tmax-through-2025.csv.gz transit-optimality-fixtures.json.gz replay
python -B interval_fault_laminar_check.py station-tmax-through-2025.csv.gz transit-optimality-fixtures.json.gz replay
```

接口 `quota_plan` 接收完整世界、报价及 `Quota` 列表，返回最便宜清单或两世界共同回复。选中来源的编号与实际答复交给 `label_options`，即可取得仍符合故障合同的目标标签。
