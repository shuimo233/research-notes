# 温差档案允许抄错一条，怎样保证一次补核就能定案？

北加州 2025 年 1 月 11 日的回放档案中，实验把一条温差记录调低了 1.5°C。审阅者知道五个站的最高温各在一个可信粗区间内，也允许六条温差中有一条错报。在这个合同下，B 站比中心 H 站高 0.2°C 或 1.7°C 都有证据模型支持，暂时无法判断温差是否达到 1.0°C。核实另一对站点的温差就够了。B 减 A 为 −2.6°C 时目标为假，为 −1.1°C 时目标为真。两种数值来自两类允许世界，补核前已经可以证明它们互不相交。 [逐项档案](interval-fault-cut-ledger.json.gz) · [固定数据和故障规则](https://github.com/shuimo233/research-notes/blob/e65fff8c73091886b5238d26f382d7405a228211/articles/consent-audit/interval-fault-cut-protocol.md)

## 回放结果

取 NOAA 2025 年北加州和纽约两组共 725 个完整站日组，每份档案判断六个定向温差阈值。每组原始档案配一份注入档案，按冻结的哈希规则在一条相对读数上加减 0.1、0.5 或 1.5°C。每种档案各有 4,350 项判断。模拟错报发生在温差归档，公开粗区间和补核读数按协议可信。 [NOAA GHCN-Daily](https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily) · [回放汇总](interval-fault-cut-results.json)

| --- | ---: | ---: |
| 只看可信区间 | 1,734 | 1,734 |
| 只看允许一条错报的温差 | 4,350 | 4,087 |

注入档案中，两类证据合用新增 139 个可确定判断，比最强单独对照高 3.2 个百分点，低于事先要求的 5 个百分点。在仍不确定的 124 项中，有 100 项可保证一次补核定案，占 80.6%，通过预设门槛。北加州解决 28/35 项，纽约解决 72/89 项。另 24 项的每个非目标候选仍至少有一个可能的答复与真假两类世界同时相容。校验器重新读取气温，由每一种删边修复直接枚举全局平移，并逐项核对真假、具体补核数值和反例。共核验 8,700 项判断及 1,040 项小整数域对照。 [独立校验器](interval_fault_cut_check.py)

## 为什么一个切点就能表示所有修复

假设报告图连通，边上记录精确的定向差值，原档案有一个不一致的环，允许至多一条错报。每点另有独立的可信整数区间。取任意生成树，从根出发由树报告累加出基准值 $r_v$。找一条非零残差的非树边 $e=(u,v)$，定义 $\delta$ 为该边报告减去 $r_v-r_u$。沿树上从 $u$ 到 $v$ 的路径给顶点编号。其余顶点按它在树上所接的路径点取得位置 $p(v)$。

任何单边修复必须删去 $e$ 或删去这条树路径的一条边，否则原矛盾环仍在。删 $e$ 保留基准差值。删路径上第 $j$ 条边时，保留下来的树边要求各侧只能共同平移，边 $e$ 又强制两侧平移差恰为 $\delta$。所以修复后的坐标一定可写成

$$
x_v=r_v+z+\delta\,\mathbf{1}[p(v)\ge j].
$$

其中 $z$ 是同一世界各点共享的自由平移。任意另一条非树边在 $j$ 落入两端位置之间时得到固定方向的残差修正，其他位置保持原残差。零残差边因此排除一个连续段，非零残差边要求落入一个连续段且幅度和方向必须吻合。通过差分数组和两端界的交，所有候选边只需沿路径扫描一次。可信区间给出的 $z$ 范围用前缀和后缀的上下界交集检查。图上找不到任何可行修复时，结果为空，表明当前档案与错报预算、公开区间不相容。

于是，在已通过检查的切点中，任何一对站的温差至多取两个值。偏移值出现在哪些修复上，能用切点的一个连续排名区间表示。若目标阈值在这两个值给出的标签不同，且两类都可能，一个补核刚好在它诱导的两组切点与目标真假分组相同或交换时保证成功。这是因为补核至多产生两种答复。任何一组若包含两种目标标签，答复这一组之后仍无法保证定案。预处理需要 $O(n+m)$ 次整数算术操作，随后检查给定目标和给定探针需 $O(1)$ 次操作。扫描 $q$ 个明确列出的备选探针需 $O(q)$。 [实现及答复后的精确更新](interval_fault_path.py)

桥路径版本可以由一条已知图上修复边开始。若其余记录一致，再考虑保留这条边、删另一条边，后者必须是删除原修复边后连接其端点的桥路径上的边。上面的生成树算法也直接搜索参考位置，并允许路径之外有桥。补充协议在看到 NOAA 实用性结果后、运行路径算法前冻结。两种入口在 725 份注入档案上对每个可行错报位置和每个候选补核都与逐边枚举一致。另核验 480 个合成图，其中 60 个含桥，83 个在可信区间和一条错报预算下没有可行世界。共比较 1,450,460 次目标和候选探针组合。 [路径检验协议](https://github.com/shuimo233/research-notes/blob/2e2fbb46d8334e6c08a34c8792a062d4d9b34f28/articles/consent-audit/interval-fault-path-protocol.md) · [核验输出](interval-fault-path-results.json)

## 档案一致时，反例最少要改几条

若原报告与公开区间已有一个共同参考世界，反证某个阈值还差整数幅度 $\Delta>0$。把每个读数写成相对于参考的偏移。原报告成立当且仅当两端偏移相同，公开区间允许偏移为零。可以把任意反例映射为至多三个偏移值 $-a,0,\Delta-a$，且保持错报总成本不增加。将原来等偏移的点作同样映射。若两个端点原偏移都非负，取 $a=0$；若都非正，取 $a=\Delta$；若一负一正，就向零缩短两端偏移，使幅度总和恰为 $\Delta$。把其余偏移族归零。每个新值都在原偏移与零之间，仍在允许区间，同值的边也不会变成异值的边。

合法标签列表只在端点容量触发的位置改变，至多检查 $O(n)$ 个 $a$。固定一份列表后，切断两目标端点之间，以及每个端点与拒绝它的偏移值的顶点之间的路径。留下的分量可以分别取端点偏移或零，切分完全保留原错报成本。$\Delta=1$ 只有两个二值场景，可用普通最小割。$\Delta=2$ 已包含三终端割。令原报告全零，把两个目标端点限制在 $[-1,0]$ 和 $[0,1]$，第三端点固定为零，其余点允许 $[-1,1]$。达阈值时三个端点必取不同值。实际原始档案中 4,350 项均与独立的删边成本穷举一致。此约简使用档案一致这一前提。 [先例与复杂度](interval-fault-cut-prior.md)

## 这个结果的边界

差分约束、单边修复的图拓扑以及以决策标签一致为停止条件，都有直接先例。这里值得独立审查的组合是，**把带可信区间的单错报修复压缩为切点，再从同一份数值编码精确求出阈值标签、非目标补核的成败以及答复后的标签**。文献检索找到了各环节的近邻，尚未确立发表优先权。实用性证据来自真实气温和模拟错报，且依赖区间、预算和新补核可靠。多条同时错报和带噪补核由别的模型处理，本轮的线性路径结论没有覆盖。 [符号图修复与块结构](https://people.math.binghamton.edu/zaslav/Tpapers/npc.pdf) · [差分约束网络](https://ics.uci.edu/~csp/r10.pdf) · [决策区域判定](https://proceedings.mlr.press/v33/javdani14.html) · [原文对照](interval-fault-cut-prior.md)

## 复现

在本文所在目录中用 Python 3.10 或更新版本运行，不需要安装第三方包。

```bash
python -B interval_fault_cut_run.py station-tmax-through-2025.csv.gz replay
python -B interval_fault_cut_check.py station-tmax-through-2025.csv.gz replay
python -B interval_fault_path_check.py station-tmax-through-2025.csv.gz replay
```

框架可以用 `compile_path(intervals, reports)` 返回候选路径。站点用零起始整数编号，报告项为 `(起点, 终点, 终点值减起点值)`。对存在矛盾环的连通输入，`outcomes(s, t, threshold)` 返回带证据上限的可能标签集合。对尚有真假两类的输入，用 `can_settle` 按候选顺序找一次补核。实际答复传给 `after_probe`，可得到新的标签集合，空集表示答复与输入合同冲突。
