# 可分离推理与归档复核的事前约定

先前锁定的 GoEmotions 单例与八条组批结果已知，INT8 有 465 条细类集合、417 条粗类集合不同。固定模型文件的静态图有 98 个 DynamicQuantizeLinear 与 98 个 MatMulInteger 节点。还未运行下面两个中间条件或 Scan 封装的推理，也未计算逐项路径。已有学者研究过组批与量化对独立样本结果的影响；ONNX 已提供 Scan 运算。这次只考察受控离线评测、重复性与部署接口。[旧版结果](go-model-ranking.md) · [量化运算定义](https://onnx.ai/onnx/operators/onnx__DynamicQuantizeLinear.html) · [Scan 运算定义](https://onnx.ai/onnx/operators/onnx__Scan.html)

对第三方提供的 5,427 个官方测试样例，文本顺序、八条一组、尾批实际大小、单例截断、CPU、运行时及阈值沿用旧研究。比较以下四种状态。S 用样例自己的长度作单例，P 仍单例但补齐到它原来所在真实批次的最长长度，R 在相同补齐宽度下将这一份输入复制满原批次数、读回它原来的行位置，M 是原有真实八条组批。所有复制都来自目标样例自身，所有自然组均沿用官方顺序。P→R 只改变同文重复及批形状；R→M 在固定形状、目标 token、mask 和位置下只替换同批的其他记录。包括末批，覆盖所有样例，逐细类、逐粗类给出完整四状态二值路径，分别报告三段中发生变化的样例数和最后又恢复的样例。判断依赖于这条预设干预顺序。R 各行若有差异单列。S/M 必须原样复现旧决策。

实用问题是怎样向批量调用者承诺独立评测的行为。试验将原图作为 ONNX Scan 的单样例计算体，按掩码裁掉右补齐，再调用相同权重。输出目标是与 S 一致，允许结果暴露子图优化或数值舍入的差别。仅对非空、连续前缀为 1 的二值右补齐 mask 规定此接口；保留输入顺序。按原顺序与打乱顺序（对样例 ID 按 SHA-256 排序）分别以八条组批，把结果按 ID 对齐。报告阈值决策、第一选择、与原参考的差别及运行时开销。预设成功要求是两种组法下全部 5,427 条的 28 类二值预测与第一选择均与 S 相同；若失败则报告确切数量及原样单例循环这一兼容基线。尝试一次单独模型文件可回读的修复，若未满足成功条件须注明区分原始封装与事后修改。权重许可证沿用上游，只公开生成工具、汇总与模型文件摘要。

不把测试集的一致性当作任意数值运行时上的按位保证。单人语句本身是可观察的目标，其他独立评论在该条标注语义中没有权重；这是把“改变无关信息应保持判断”的要求化为可证伪的行为测试。此实验尚不涉及开放式数学推理。
