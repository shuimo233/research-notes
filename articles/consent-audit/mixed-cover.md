# 三个词先问哪两个，抽签有用吗？

在同一句里确认几组词的上下位关系，常常只需向标注者问出部分词义。上轮研究给每句选了一个固定的第一批询问。这次允许系统私下抽签决定先问哪一批。两套自然语料中的 99 句全部保留原方案就能达到最优。我们也找到一种能从抽签中获益的关系结构，给出了最优策略，并在 WordNet 词义表上找到了实例。[事前登记](https://github.com/shuimo233/research-notes/blob/4a0e40d119d80879ce00b50ea3cec6de0b165bbc/articles/consent-audit/mixed-cover-protocol.md) · [上轮固定方案](coupling-witness.md)

## 什么证据允许系统少问一次

设有三个二义词 technique、method、ability。WordNet 3.0 给这三个词各列出两个候选名词义项。其中各有一个义项按从具体到一般的顺序构成严格的链。在这三个词的三个跨词表格里，每张表的另外三格都没有上下位或同义关系。先问出两个词义，如果两者都落在链外，第三个词无论取哪个义项，三组关系都能确定。只要先问的两个中有一个落在链上，就须补问第三个。这给“证据足以支持结论”一个可执行的判据：对剩余义项穷举，所有可能答案一致时即可停止。概率只用于安排先问谁，停问后给出的关系必须逐项正确。[词典扫描代码与范围](mixed_wordnet_chain.py) · [词义及频数说明](https://wordnet.princeton.edu/documentation/senseidx5wn)

先假定每词的链上义项概率都是一半，同一句里三个义项如何相关未知。任何固定的首问组合，都可能遇到那两个词恰有一个活跃的分布，每次都要问满三次。若均匀抽一个词延后，最坏平均是 $17/6$ 次，少 $1/6$ 次。一个达到界的分布是，三个词的八种状态中去掉全活跃、全不活跃的两种，余下六种等概率。任意固定选择都恰在一种状态下省一次。反向的上界也有证明，因此没有其他抽法能在给定边际下保证更少。抽签与隐藏词义独立，对手可以按规则选一份联合分布，但不能看到当次抽签后改动词义。若联合分布已知，直接选该分布下最好的固定方案就足够。[证明及先例](mixed-cover-prior.md)

## 自然句的确认性结果

采用事前固定的全部共享词元句，以每词候选义项等概率为边际。系统在每句话的所有极小首问覆盖之间选策略。表中“最坏期望合计”是逐句最坏平均询问数之和。金标回放的单位是词元询问次数。语料上两栏最坏期望完全相等，按事前规则，平局沿用原固定方案。[逐句分数和博弈证书](mixed-cover-ledger.jsonl) · [精确分数汇总](mixed-cover-results.json)

| WSD | 60 / 166 | 127.367 | 128.849 / 128.849 | 160 / 160 | 0 / 60 |
| SemCor | 39 / 78 | 79.334 | 81.922 / 81.922 | 86 / 86 | 0 / 39 |

每套语料至少有一句严格改善的事前判据未达成。79 句可由触发关系的无环结构直接解释。每个可能延后的词都有一个“必须补问”的最坏概率；在无环条件下，各局部分布能沿树拼成同一份联合分布，让这些概率同时达到上界。所以一个固定覆盖已最优。另 20 句由通用程序给出各自的共同对手分布。独立义项下的最优成本在 76 句恰好等于稳健最优值。两套语料均沿用早前任务的筛选规则，句数不能用来估计任意文本的获益比例。[森林情形的拼接证明](mixed-cover-prior.md) · [不调用优化器的句级独立核验](mixed_cover_check.py)

## 词典中有多少这样的结构

看到自然句结果后，我们穷举了另一类任务。在 WordNet 3.0 中取有正名词标注次数、由 ASCII 字母组成、经名词形态还原后恰有两个不同候选义项的 2,295 个词元类型。要求三个词两两都需比较、三张真实关系表恰好实现前述结构，共得到 **1,228 个从具体到一般的有序词组**。词组共享词和义项，这一计数不涉及自然共现；每个词组在均匀边际下都具有同一个 $1/6$ 的最坏期望差。[独立的 NLTK 词对连接核验](mixed_wordnet_check.py)

为检验“各半”假设的影响，我们从原始 `index.sense` 取得各词及候选义项的标注次数，用两项的相对频数作输入。每个词的两项均有正计数的只有 38 组；其中 10 组严格获益。按 38 组等权计算的最坏预算平均差是每组三词 0.0142 次。最大差是 concussion、accident、misfortune 的 $29/252$ 次。为避免只展示最大值，我们另选少见义项所获得的最小标注数最高的正例 religion、morality、attribute，三词的链上/链外计数为 63/9、8/5、1/2，最坏期望从 $115/39$ 降到 $2753/936$，差 $7/936$ 次。没有一个词组三个词的六个计数都达到 5。对频数稀疏的处理、词组筛选和这项分析均在自然句检验之后确定。[全部 38 组的频数、词义和精确预算](mixed-wordnet-chain.json)

再允许每项活跃概率在相对频数上下 5 个百分点内独立变化，并截到 $[0,1]$。对任一省问策略，逐位把 0 提升成 1 只会增加需要补问的机会。任何较低边际的分布都可用随机翻位提升到各边际的上端点，故区间的最坏成本精确等于在所有上端点求解的成本。区间下 38 组中有 11 组胜过区间下最佳固定方案，原有 10 组中的 9 组保留优势。这个人为设置的区间用于敏感性分析。它没有统计覆盖率保证，标注计数也没有给出目标工作流中的联合频率。现有证据支持这些输入下的预算决策，实际使用者节省的时间仍待测量。

## 可以直接使用的策略

当 $n$ 个词所有活跃义项组成严格链，其他义项在跨词比较中都不引入关系，最优策略只须把活跃概率从高到低排序，选择一个前缀，在其中均匀抽一个词延后。即使边际不同，排序加一次扫描即可算出精确的最坏预算和一份可重放的对手分布。这里的 $O(n\log n)$ 按有理数算术操作计，输出全部关系本身需要 $O(n^2)$ 项。异质公式是事前登记的齐次问题的后续推导。对 456 组边际做了 912 次独立线性规划比较，同时在三词与四词样例的 72 个询问轨迹上逐项验证了输出关系。[闭式、双向证明与相关工作](mixed-cover-prior.md) · [标准库策略及交互入口](chain_omission.py) · [穷举核验](chain_omission_check.py)

在本目录运行以下命令。第一条输出最优预算与证书，第二条真正询问词义并输出每对词的关系。交互示例只适用于上述词义结构。若要接入自己的标注界面，可调用 `compare(positions, probabilities, ask)`，由 `ask(batch)` 只接收这一批待问的 ID，并回传这些 ID 的布尔答案。

```sh
python chain_omission.py chain-omission-example.json
python chain_omission.py chain-omission-example.json --compare technique method ability
```

一般关系图可以用 `mixed_sense_game.py`。输入为每个词元的备选结果列表，每个结果给出会触发追问的其他词元 ID 及其边际概率。同一词元触发相同目标集合的义项可合并；在合并状态内按原各义项的条件边际分配，即可把压缩后的对手分布还原为合法的词义分布。零频但语义上可能的备选结果仍决定第一批必须覆盖哪些比较。在每个压缩世界中，成本等于第一批覆盖与被触发词元集合的并集大小。求解器要求同一份联合分布面对所有覆盖，同时用覆盖抽签概率和逐世界的加性上界核验相反方向。线性规划用于找候选，只有有理数复核成功才返回。通用实现枚举极小覆盖和压缩世界，适合小实例；不能从其运行时间推断普适的高效算法。[通用求解器](mixed_sense_game.py)

复现使用 Python 3.13、SciPy 1.16.3 和 NLTK 3.9.2。在本目录将下列 `wordnet.zip` 指向 NLTK 的 WordNet 3.0 数据包。脚本会检查发布时冻结的 Git blob 哈希。选择尚不存在的输出目录。 [WordNet 数据包](https://github.com/nltk/nltk_data/blob/gh-pages/packages/corpora/wordnet.zip)

```sh
python mixed_cover_audit.py wordnet.zip rebuilt
python mixed_cover_check.py wordnet.zip rebuilt
python mixed_wordnet_chain.py wordnet.zip --output rebuilt/mixed-wordnet-chain.json
python mixed_wordnet_check.py wordnet.zip rebuilt/mixed-wordnet-chain.json
python chain_omission_check.py
```
