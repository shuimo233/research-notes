# 八行上界、十三行实例与独立核验的先例

核查日期为 2026-11-22。对照对象是公开提交 `e5f1711` 的[证明](proof.md)和这次新增的[独立核验器](../../packages/stateful-identification/stateful_id/audit.py)。下文的“行”是带独立错配预算的确定二元签名。“最小”指基数最少，“极小”指删除其中任何一行都恢复可行。

**一般八行结论有比三维格点更宽的适用范围。已公开的两组数值实例却都能降到三个整数变量。** 十三行实例的重要性质是有一个对所有正奇重复次数都成立的五行最小证据。此前已经有论文报告了二元汉明球恰需五行才能说明无解的实验实例。独立核验器的计数盒、整数分支、边界传播、向下取整以及最小冲突检查，也都有原理上的直接先例。[Boucher、Brown 与 Durocher，SPIRE 2008，§3 表 2](https://doi.org/10.1007/978-3-540-89097-3_26) · [Cheung、Gleixner 与 Steffy，整数规划结果的独立查验](https://arxiv.org/abs/1611.08832)

## 十三行实例可以完全化简

Boucher 等研究 *decoy sets*，即所有行对都相容但整组没有中心的串集。其表 2 专门统计**基数最小**的不可行子集。六条长度八的二元串、统一半径三的一组实验中，每批一千组、十批取平均，最小子集基数为五的平均出现次数为 12.4。在其他长度也报出正数。因此“有些实例需要五行，而且任意四行相容”已经有直接观测。原文给四条二元串的精确算法。本轮没有从该文找到这里的十三行矩阵和任意正奇数重复的解析构造。[SPIRE 2008 原论文](https://doi.org/10.1007/978-3-540-89097-3_26) · [首作者学位论文，§4.1.2、表 4.2](https://dspacemainprd01.lib.uwaterloo.ca/server/api/core/bitstreams/4b3f3660-ff53-45f4-a09d-47202dd18501/content)

沿用[公开证明第五节](proof.md)的符号。每种探针重复 \(n=2k+1\) 次，角点预算为 \(R=3k+2\)。记前三个计数之和为 \(Z\)，后五个标签计数之和为 \(t\)。下面的归约对**任意所选子族**都成立。

* 若子族没有环边行，置零全部标签不会增加任何所选角点的错配。
* 若子族至少含一条环边行，任何可行记录在该行上的错配至少是 \(Z+2n-t\)，从而 \(Z-t\le R-1\)。从前三个计数合计减去 \(\min(t,Z)\)，得到 \(Z'=\max(0,Z-t)\)，同时把所有标签置零。对任一角点，前三个计数的修改最多增加 \(t\) 错配，而清除标签恰好减少 \(t\)。此时每条环边行的错配都是 \(Z'+2n\le R+2n-1\)，因此连未选择的环边行也一起满足。
* 反向取零标签直接产生原始记录。故在可行性意义上，任一非空环边子族都只增加同一个三维约束 \(Z'\le R-1\)。原表两球不包含的性质仍成立。该性质无法排除整组经过规范化后出现冗余。

现在可以列出全部包含极小核心。第一个是八个角点。其余五个都由 \(011,101,110,111\) 四个角点和任选的一条环边组成。若无环边且缺一角，取该角的三位补码 \(b\)，令前三个计数为 \(k+b_i\)，其余为零。若有环边且四个指定角点有一个缺失，取其补码 \(b\)，该补码至多有一个 1，故同时满足全部环边和其他七个角点。配合公开稿已证的两类空交，这说明极小核心恰好六个，最小基数是五。公式对任意正奇数重复数成立。

独立小规模核对取 n=1 和 n=3，各自在原始八块整数计数盒上枚举所有点，标记每个点能同时满足的行，再向下闭包得到全部 8,192 个子族的真实可行性。两个规模均与上述六核分类逐项一致。推广到任意正奇数依赖前面的证明。

五行不可行性的算术也有明确的经典解释。清零标签后，\(111\) 与环边合给 \(Z'=3k+1\)。每个含两个 1 的指定角点再与环边相加，可得 \(2z'_i\le 2k+1\)。将各式除二并向下取整得到三条 \(z'_i\le k\)，求和与前式矛盾。这是一轮 Chvátal–Gomory 取整切割。实数点 \(z'_i=k+1/3\) 同时满足原来的五条松弛约束，说明最后用到的确实是整数性。[Chvátal，1973](https://doi.org/10.1016/0012-365X(73)90167-2)

所以十三行实例给出了可复核的奇数权重测试族，且证明了具体最小证据。它和含 36 条恒真行的八角点实例都能用三维格点或固定方向直接分析。两者的运行时间反映当前两套取证流程在这些数据上的差异，不能据此量化一般分枝结构相对于专用三维求解器或其他冲突提取算法的收益。

## 独立核验器复用的既有方法

保证声明包含问题指纹和候选核心。核验器针对另行提供的问题，自己求解各核心的整数可行性，并逐行删除以检查极小性。未保证声明则给出一个计数向量，可直接核对预算和存活模型的共同动作。核验器有节点上限，耗尽时报告未判定。该接口见[实现](../../packages/stateful-identification/stateful_id/audit.py)。

1. **计数和行活动界。** 已有 non-uniform Closest String 的逐行预算整数规划。对于块次数 \(n_j\)、读到 1 的个数 \(z_j\in[L_j,U_j]\)，预测零的块对行错配最小贡献为 \(L_j\)，预测一的块为 \(n_j-U_j\)。各坐标独立，所以逐项相加给该行在该盒上的精确最小值。不同的行可由不同点达到各自最小值。利用单行最小值剪枝和收缩变量上下界，是标准线性约束活动界传播。[Rohwedder 与 Węgrzycki，ITCS 2025，非均匀 Closest String](https://doi.org/10.4230/LIPIcs.ITCS.2025.83) · [Savelsbergh，1994](https://doi.org/10.1287/ijoc.6.4.445) · [ZIB 论文，§3 对最小活动界的推导](https://webdoc.sub.gwdg.de/ebook/serien/ah/ZIB/ZR-13-03.pdf)
2. **盒二分和裁剪。** 整数坐标按 \(z_j\le b\) 或 \(z_j\ge b+1\) 分开，两个子盒无漏无重。任一行的盒内最小活动值已超预算时，可拒绝整盒。小核中两条符号行半和后右端向下取整，也是标准整数切割。VIPR 已能用分支假设与算术推理产生可由另一程序验证的整数规划证明。本实现传递行号，让核验器重新搜索，未输出逐步可回放的 VIPR 轨迹。八个行号也不意味着盒树必然很小。[Cheung 等，原论文](https://arxiv.org/abs/1611.08832) · [VIPR 作者实现](https://github.com/ambros-gleixner/VIPR) · [Chvátal 的取整规则](https://doi.org/10.1016/0012-365X(73)90167-2)
3. **核的空交与极小性。** 已证整组不可行，再证删除其中每一行后可行，就得到包含极小性，这是不可行约束子系统和约束诊断领域的通用定义与验法。基数最小性需要额外证据。本例凭前述解析下界建立五行的最优性。[Chinneck 与 Dravnieks，1991](https://doi.org/10.1287/ijoc.3.2.157) · [Junker，QuickXplain，2004](https://cdn.aaai.org/AAAI/2004/AAAI04-027.pdf)
4. **覆盖所有无共同动作的组。** 对动作 \(a\) 取拒绝它的行集 \(D_a\)。候选组 \(S\) 没有共同动作，当且仅当它与每个 \(D_a\) 相交。因此每个坏组都是该超图的一个横截集。对未命中的 \(D_a\) 按其中每一行继续分支，一旦选择集已包含某个验证为空的核心就可停止。这是 hitting-set 分支及单调覆盖检查。Javdani 等已将重叠决策区域的终止条件与切断全部冲突超边联系起来。本文的接口另须在固定计划及错读预算下独立检查每个核心是否真的空交。[Javdani 等，AISTATS 2014](https://proceedings.mlr.press/v33/javdani14.pdf) · [Fredman 与 Khachiyan，单调对偶](https://www.cs.tau.ac.il/~fiat/dmsem03/On%20the%20complexity%20of%20Dualization%20of%20monotone%20Disjunctive%20Normal%20Forms%20-%201996.pdf)
