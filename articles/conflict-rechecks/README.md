# 当所有旧规则都被观测推翻，该复查哪一项？

2026-11-21 · 通用推理研究笔记

一次数据库实验留下两个读数：键 2 存在，键 3 缺席。手里的四种规则没有一种预测这个组合。现在有两种解释：某个读数错了，或者候选表漏掉了 SQLite 的一种冲突策略。直接重试最后一次查询有个问题：真正读错的可能是第一项。

如果把漏掉的规则具体写出来，这个问题可以算清楚。在下面的二元观测模型里，**把复查分两批，只根据第一批的结果调整一次，就能达到逐次选问的最优最坏成本**。SQLite 上这个数是 3，最好的固定方案需要 4 次。只给观测接口增加一个布尔表达式，两个数就都变成 2。

## 先分清还可能是谁错了

每条旧规则都是一个能预测观测的确定性函数。对同一实验可以从相同状态重新开始，每次只读一个比特。先把全部历史与每条规则逐项对照。假设每条旧规则在整个过程中最多容许一次错读，而历史已经推翻了所有完全无误的旧规则。那么，错两次以上的规则可以排除，每条仍然存活的旧规则都恰好用尽了一次额度。**它们对下一次读数的预测必须兑现。** 只保留最后一刻才被推翻的那条规则，会漏掉由更早一次错读解释的历史。

现在引入一条明确的新增规则 $E$。它是待检验的假设，历史之后还有 $f$ 次错读额度。若双方起初都允许一次错误，而 $E$ 与历史全符，就有 $f=1$。下面也考察其他非负整数余量。目标是判断真实规则属于旧集合还是属于 $E$。判断为 $E$ 也允许发生错读。结论以真实规则属于这两方、误差有界为前提。

## 一次批间反馈为什么够用

对每种可重复实验 $q$，把预测与 $E$ 不同的旧规则记为 $D(q)$。要让每条旧规则至少有一次与 $E$ 当面对质的机会，需要多少种实验？记最少数量为 $\tau$。如果某条旧规则对所有允许的实验都和 $E$ 一致，存在无法判别的观测历史，任何有限方案都不能保证分开两方。

在可区分、至少有一条旧规则、每次实验成本相同的条件下，两个精确的最坏复查次数如下。历史读数单独计数。

| 复查方式 | 最坏情况下最少需要多少次 |
| --- | --- |
| 可根据一批读数再选下一批 | $\tau+f$ |
| 所有实验预先排定，可以重复 | 让每条旧规则被差异集覆盖至少 $f+1$ 次的最小实验总数 |

**上界可以直接执行。** 第一批做完整个最小覆盖。若所有读数都符合 $E$，每条旧规则都已被一条实际读数排除。否则挑一条与 $E$ 不符的实验，在第二批把它再做 $f$ 次。只要复测有一次符合 $E$，所有能解释第一次偏离的旧规则都被排除。若每次都偏离，连同第一次共有至少 $f+1$ 次偏离，超过了 $E$ 的额度。两批中的每一批都可以预先排好。

**更聪明地逐次选问也省不了最坏的那一次。** 先沿着始终回答 $E$ 预测值的路径走 $\tau-1$ 步。此时必有一条旧规则从未与 $E$ 分歧。接下来的 $f$ 步改为如实回答这条旧规则。它能解释整个记录，$E$ 也能把后段至多 $f$ 个偏离算作错读。此时仍无法归因，至少还要一步。

**固定方案的约束更强。** 如果有一条旧规则只被问到 $f$ 次分歧，那么它的完整回答串也可以由 $E$ 加上至多 $f$ 次错读产生。反过来，只要每条旧规则至少被问到 $f+1$ 次分歧，任何旧回答串都超出 $E$ 的容错范围。这给出表中的第二行，也解释了两种最优值什么时候会相等。

## 把推导放回真实 SQLite

每次实验都新建内存数据库，开启事务，先插入键 1 的旧值，再用一条 SQL 依次写入键 2、键 1 的新值和键 3。中间那条记录触发主键冲突。候选预测表单独写定；实际读数取自数据库的查询结果。错读由测试程序在读数返回后注入。四个基本读数如下。[SQLite 官方冲突处理说明](https://www.sqlite.org/lang_conflict.html)

| 策略 | 有键 1 | 有键 2 | 有键 3 | 键 1 为新值 |
| --- | ---: | ---: | ---: | ---: |
| ROLLBACK | 0 | 0 | 0 | 0 |
| ABORT | 1 | 0 | 0 | 0 |
| FAIL（新增） | 1 | 1 | 0 | 0 |
| IGNORE | 1 | 1 | 1 | 0 |
| REPLACE | 1 | 1 | 1 | 1 |

历史是“有键 2、有键 3”读到 $(1,0)$。前两条旧规则认为第一项读错了，后两条认为第二项读错了。`FAIL` 能解释两个读数，也仍容许一次错读。只重试键 3，无论重试多少次，连续读到 0 都能同时由 `FAIL`、`ROLLBACK` 和 `ABORT` 解释。

一种最优走法是先查键 2。如果读到 0，就再查键 2。这时连续两个 0 足以排除 `FAIL`；先 0 后 1 则排除剩余旧规则。如果第一次读到 1，就改查键 3，必要时再查一次。最坏 3 次。固定方案必须同时照顾两组可能的错读位置，最优要 4 次。两项统计都额外使用了同样的两个历史读数。

再允许一次查询直接返回“键 2 存在且键 3 缺席”。只有 `FAIL` 在这项实验上预测 1。现在固定复测这个谓词两次就够了，自适应也要两次。这里把一次从头执行并返回一个布尔值计为一个单位；业务中如果这个复合读数更贵，应重新计价。这个对照表明，**可使用什么观测接口，会改变反馈究竟值多少。**

## 如果新增规则还没有选定

知道该检验哪一个新机制，本身值多少？考虑一个完全可构造的反例。有 $k$ 条旧规则 $B_i$ 和 $k$ 条新增规则 $E_j$。实验分为两排。测第一排第 $i$ 项，只有 $B_i$ 回答 1；测第二排第 $j$ 项，只有 $E_j$ 回答 1。历史已把第一排各测一次，全部读到 0，于是每条旧规则都已用完一次错读额度，而每条新增规则均可再错 $f$ 次。所有历史实验仍可重做。

若提前指定新增规则 $E_j$，反复测第二排第 $j$ 项即可，最坏 $1+f$ 次。若只知道新增规则是这 $k$ 条中的某一条，目标仍然只是判断新旧两类，**最优自适应复查变成 $k+f$，最优固定复查变成 $k(f+1)$。**

上界可以通过扫描第一排获得，遇到 1 就复查该项。下界沿全 0 路径走 $k-1$ 步，两排必然各有一个未问位置，对应的一旧一新仍然存活；再按旧规则回答 $f$ 步，两者仍能解释全部记录。对于固定顺序，设两排各自问得最少的位置分别问了 $a$ 和 $b$ 次，其对应的新旧规则只在这两个位置分歧，因此必须有 $a+b\ge f+1$。总次数至少为 $k(a+b)$，每个第一排位置复查 $f+1$ 次即可达到。

例如 $k=4,f=1$ 时，提前给出具体新增规则只需 2 次；仅给出候选集合要 5 次，预排则要 8 次。**评估一个推理系统时，应记下是谁提出了新增假设。** 把人工指定候选后的复查成绩归给“自主发现机制”，会把这项成本完全隐去。

## 哪些结果已复核，哪些主张仍开放

对 1 至 3 条旧规则，枚举全部不同的非空差异集组合，包含空实验库，取 $f=0,1,2$。交换读数的 0、1 或重复加入相同实验不产生新的差异集。共 414 组配置，其中 69 组有不可区分的旧规则。在 345 组可区分配置中，程序分别搜索所有逐问策略的最小最坏深度、枚举固定实验序列，并实跑两批方案。84 组有严格的反馈收益，261 组相等。这里直接枚举冲突后的预测表与剩余额度，未要求每组状态都能由同一个初始错误模型产生；这些比例没有实际任务发生率的含义。另有 11 组多新增规则算例，逐项核对上述第二组公式。SQLite 实验从实际历史生成冲突，覆盖五种策略和实验深度内可出现的单次错读位置。[复现脚本](reproduce.py) · [逐次观测与结果](evidence.json)

带错回答的查询、在多个诊断之间选测量点，都有长久先例。尤其接近的是 Lex 的 2026 年预印本，它讨论有限探针、不同的剩余错误额度、隔离情形的精确界和固定设计的距离约束。固定方案的重覆盖条件可由异半径回答集合互不相交直接推出。这篇笔记可独立复核的贡献，是给出**任意差异集上、旧方余量为零、单个新增规则还有余量时的两批精确式**，并展示拿走指定候选或改变接口后，结论如何变化。现有核对不足以确认全球优先权。[Rivest 等，1980](https://doi.org/10.1016/0022-0000(80)90014-8) · [de Kleer 与 Williams，1987](https://doi.org/10.1016/0004-3702(87)90063-4) · [Lex，预印本](https://doi.org/10.21203/rs.3.rs-11052076/v1)

这给通用推理架构留下一个可实现的接口：保留每条假设在历史上还剩多少容错额度，把新增规则写成可检验的预测，再把复查交给能报告成本和不可区分情形的模块。本实验只验证了这个环节。新增机制的自动生成、真实环境里的噪声上界、不可重置的动作和大规模规则库的计算成本，仍需各自的证据。示例程序用精确搜索找最小覆盖，最坏需要遍历指数多个候选子集。[可调用的归因函数](diagnose.py)
