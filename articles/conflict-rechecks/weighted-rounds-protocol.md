# 三轮异价复查的跨档案留出

十组 PyPI 档案已用于提出三轮方案，任何后续回看都算探索。本次独立验证在读取 npm 归档和结果前固定名单、文件纳入方式、故障合同、成本和门槛。npm 档案只作为数据解档，运行被审计包的代码不属于试验。 [两轮实验](weighted-batches.md) · [npm 元数据定义](https://github.com/npm/registry/blob/main/docs/responses/package-metadata.md)

| 包 | 旧版 | 新版 |
| --- | --- | --- |
| lodash | 4.17.20 | 4.17.21 |
| express | 4.19.2 | 4.21.2 |
| semver | 7.6.2 | 7.7.1 |
| axios | 1.7.7 | 1.8.4 |
| chalk | 5.3.0 | 5.4.1 |
| js-yaml | 4.1.0 | 4.1.1 |
| zod | 3.23.8 | 3.24.2 |
| yargs | 17.7.1 | 17.7.2 |
| commander | 12.1.0 | 13.1.0 |
| webpack | 5.94.0 | 5.98.0 |

从官方单版本 JSON 取得归档 URL 及 SHA-512 完整性值，保留两个版本中同路径、非空、发生变化的普通 .js、.cjs、.mjs 文件。排除路径段大小写无关地等于 test、tests、spec、fixtures、docs、benchmark、benchmarks、examples 的成员。只取 package/ 下成员，保留 dist，包括压缩后的 JavaScript。两个版本中较大的未压缩字节数为本项每次预订的价格。异常归档或空目录报告，不能换包。每个旧解释指一份文件回到旧版本，其余文件为新版。旧解释零剩余错读，新解释容许 f 次单次翻转，每批全额预订，不允许批内撤单。翻转和版本混合是受控试验，不用于估计真实事故或持久损坏。

主分析 f=1，次分析 f=2。比较一次固定、精确任意两批、降序首批最优、降序三/四批和逐问最优。三批主方案只改变批次边界，降价顺序固定。逐例提供实际读数、实际字节上界或可复核最坏分支，独立状态核验每批计划可识别两类，以及最优性仅针对固定降价顺序。逐问最优为下界，任意两批精确为主要对照。逐包报告三批在预订字节上高于、等于、低于对照的数量。门槛为全部输出满足证书且零错误、至少七个包严格降低，且 f=1 在十组上合计的最坏预订字节至少省 5%。另外报告增加至四批的边际量。摘要不把批数换算成网络延迟。代码的通用保证另用完整答复树和穷举切分验证。所有源 URL、哈希、逐案及校验公开。
