# 旧解释影响多项证据时，两批复查怎么安排？

旧版本可能同时改变多个文件。对于有限个这样的旧解释，若它们已经用尽错读额度，而新增解释还能错一次，允许全局选择第一批以后，**只复测触发分歧的那项，也足以达到任意两批方案的最优最坏成本**。如果新增解释还能错两次，这一化简就有反例。

用真实 PyPI 发行历史检验，八个包均有交叉的文件差异，但最优两批、固定方案和逐问方案的一次错读成本完全相同。每个包都可以先用一个普适检查和一个成本下界证明继续优化不会省字节。本轮理论结果和预设效用门槛分别核验。 [冻结预案](weighted-overlap-protocol.md) · [逐案结果](weighted-overlap-results.json)

## 精确计费

相对于目标解释，每个探针 $q$ 的分歧旧候选为 $D(q)$。旧候选确定地回答 0 或 1，目标一般给 0，最多翻转 $f$ 次。给定第一批 $B$，将旧候选按预测的整批回复分组。某组 $S$ 的回复含 $d$ 个 1。在 $d>f$ 时，目标已被排除。其余情况下，第二批必须从各个旧解释的差异集合至少买到 $f+1-d$ 份报告。否则该旧解释的完整回复仍可由目标解释的一次或多次错读生成。这就是允许同一探针重买的带价多重覆盖。最坏成本是第一批费用加上最贵的后续覆盖。

若首批重复同一个探针，保留一次，其余移到第二批。根据首批保留位复制出原协议可用的完整回复，预订原协议对此回复的后续检查，并加入移走的副本。副本都一致时，仍可执行原判定。副本若不一致，旧解释已排除，再按真实回复消耗的次数判断目标是否相容。每条执行路径的最坏预订价不会上升。由此可用不同探针的集合搜索第一批。

还有一个删减规则。若入选的某项在所有包含它的旧预测里，都至少和目标分歧 $f+1$ 次，可把它从第一批撤出。撤出后新增的相容旧解释若还可和目标共存，必恰有 $f$ 处分歧，一次补查被撤出的探针即能排除这一组新增候选。在同一分支，其他旧候选仍由原覆盖处理。第一批所省至少等于多预订这一次的成本。$f=1$ 时，这等价于删去没有独占覆盖任何旧候选的证据项。对于两次错读，不能沿用这个更激进的独占覆盖规则。

实现把第一批的状态压缩成按已发生分歧数分层的旧候选分组。同层里组的名称不影响以后任何探针的分裂，也不影响停下时所需的覆盖价，因此可合并等价前缀。第二批覆盖按每个仍需命中的旧解释及其剩余额度求解。若某个旧解释与目标在所有可买探针上都相同，接口会报告无法区分。 [通用编译和可执行接口](weighted_overlap.py)

## 一次错读时的更简单精确式

对一个确定的第一批 $B$，记全 0 后仍存活的旧候选为 $S_0$，记只在 $q$ 上产生一次分歧的旧候选组为 $S_q$。记 $K$ 为精确第二批最坏成本，即全 0 分支的双重覆盖，与各个 $S_q$ 单重覆盖之间的最大值。

取首批最贵探针 $q$，价格为 $x$。若 $x\le K$，则第一批任何单一分歧分支都可以直接复测一次触发项，总代价不会超过原计划。若 $x>K$，把 $q$ 换成覆盖 $S_q$ 的最便宜一组测试。这组测试至多花 $K$，同时保持原首批覆盖过的每个旧候选。新的全 0 分支后续成本至多 $K$，新首批最大单价至多 $x$。于是直接复测后的最坏成本至多
$$
c(B)-x+K+x=c(B)+K .
$$
首批若要求覆盖全部旧候选，也保持这项约束。故一次错读的全局最优费用可直接写成
$$
\min_B\left[c(B)+\max\left(\operatorname{MC}_2(S_0),\ \max_{q\in B}c_q\right)\right].
$$
空首批的最大单价记零。$\operatorname{MC}_2$ 为最便宜的两重覆盖。这个式子只需要首批覆盖过哪些旧解释、首批最高单价及总价。实现在每档最高报价下，按覆盖掩码求达到该覆盖的最低首批价，省去枚举不同的非零回复分组。求解器仍适用于小型有限候选，掩码状态数最坏对候选数量为指数级。 [先例和独立推导](weighted-overlap-prior.md)

两次错读时，取价格为 3、11、10、5 的探针 $a,b,c,d$，旧差异为 $\{a\},\{b,c\},\{b,d\}$。可用首批 $(b,c)$，全 0 时查 $a$ 三次，$b,c$ 均分歧时查 $c$ 一次，仅 $b$ 分歧时改查 $d$ 两次。最坏成本为 31。若正分歧后只能复测触发项，即使重选第一批，精确最优也为 33。该差距由独立的实际回复分组枚举核验。 [核验记录](weighted-overlap-verification.json)

## 真实档案为什么没有节省

在一个旧解释真实成立且诚实作答的路径，目标解释可以模拟前 $f$ 条分歧。因此对每个旧解释，任何轮数的最坏取证费至少为 $(f+1)$ 乘以该解释最便宜的差异探针价格。若存在一项与所有旧解释都分歧的探针，且其报价等于各解释最低差异价格的最大值，固定买它 $f+1$ 次就达到下界。程序在这种情况下跳过组合搜索。这个判据也解释为什么多文件变化本身并不产生反馈价值。

这次的八组包只使用五个发行版均存在的源码路径。用真实旧快照作为候选，错读由程序控制注入。文件内容从哈希确认后用于实际读取，预订按同一路径各版本最大载荷收费。廉价版本声明或少数通用源码变化就可以达到上面的下界。允许读取分发元数据作为对照时，结论相同。一次错读下，各包峰值预订之和只读源码为 18,752 字节，加上元数据选项为 18,160 字节。二次错读分别为 28,128 与 27,240。没有一个包从额外反馈省费，因此没有通过预设的工程门槛。用真实发布文件不能估计真实线上差错发生率，重复读取也无法解决同一个持久性坏源。

独立程序从归档重新生成 369 条文件差异，核验 16 个可跳过组合搜索的配置和 624 次实际载荷回放。另用原始二元串、允许重复的首批候选和 Dijkstra 多重覆盖核对 258 个合成配置与 6,607 条具体答复历史。匿名回复组、异价诊断和带错多重覆盖均有明确先例。目前核查未发现同一异价合同中一次错读的复测等价和上述带两次错读的区分，尚不能确认全球优先权。 [查新及证据](weighted-overlap-prior.md)
